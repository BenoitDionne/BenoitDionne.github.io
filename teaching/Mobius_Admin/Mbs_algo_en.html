Algorithm Section

Introduction

You may use random variables and mathematical formulae, graphs (static or animation) produced with Maple, and event text formatted in MathML or \(\LaTeX\) to create your questions. You do all of that in the section Algorithm of your question. The general form of the expressions in this section Algorithm is


$variable_name =  code ;

You can use the object that you have created in the section Algorithm in the statement of your question, in the Answer box and the box Grading Code of the form to create a Maple Graded question, in the section Feedback, etc. You only have to write $variable_name and the result of the code associated to this variable is inserted in your document.

This document covers only the functions existing in Möbius. To use Maple in the section Algorithm, please consult the site .

Random Variables

The following examples illustrate the principal functions used to generate random numbers.

Example:

rint(n) randomly selects an integer between \(0\) and \(n-1\) inclusively, where \(n \geq 0\). For instance, $a = rint(10); is one of \(0, 1,\ldots ,9\).

Example:

rint(m,n) randomly selects an integer between m and n-1 inclusively, where n > m. For instance, %a = rint(1,10); is one of 1, 2,..., 9.

Example:

range(m,n) randomly selects an integer between \(m\) and \(n\) inclusively, where \(n \geq m\). For instance, $a = range(1,10); is one of \(1, 2,\ldots, 10\).

Example:

range(m,n,p) randomly selects an integer among \(m, m + p, m + 2p,\ldots , m + k p\), where \(k\) is the largest integer \(\geq (n-m)/p\) and \(m \leq n\). For instance, $a = range(1,10,2); is one of \(1, 3, 5, 7, 9\).

Example:

rand(m,n,b) randomly selects a real number between \(m\) and \(n\) inclusively with \(b\) significant digits, \(m \leq n\). For instance, $a = rand(2,3,2); is one of \(2.0, 2.1, \ldots, 3.0\).

In the present document, the number of significant digits is the number of digits in a number excluding the zero digits that may appear at the beginning of the number. Hence \(30.1\), \(030.1\) and \(30.0\) have three significant digits, and \(31\) and \(3.1\) have two significant digits. If there were zeros at the end of the number, then it is assumed that these digits are exact and count in determining the number of significant digits.

Example:

To get a random real number between \(a\) and \(b\) inclusively with \(k\) decimals, one uses a formula like


$a = decimal(k, rand(a,b,m));

where \(m\) minus the number of digits in int(b) is at least equal to \(k\).

Switch and Conditions

The following commands are often used to either add some restrictions or generate other random objects than number.

Example:

switch(rint(k), m1, m2, ... ,mk) randomly selects an element among m1, m2, ..., mk. The result of


$a = switch(rint(3),"sin","cos","tan");

is one of sin, cos or tan.

Example:

  • condition: eq($a,$b) means that the values of the variables $a and $b must be equal.
  • condition: ne($a,$b) means that the variables $a and $b must take different values.
  • condition: gt($a,$b) means that $a must be larger than $b.
  • condition: lt($a,$b) means that $a must be less than $b.

For instance,


$a = range(-5,5);
condition: ne($a,0);

generate a non zero random number between \(-5\) and \(5\) inclusively. Another way to get the same result without using condition is as follows.


$a = range(-1,1,2)*range(1,5);

Formatting a Fraction

Rational Numbers

Suppose that you want to display the reduced form of the fraction \(a/b\), where \(a\) and \(b\) are integers. If you use


$ab = frac(a,b);

then you will get a fraction of the form \(m/n\) corresponding to the reduced form of \(a/b\). For instance,


$ab = frac(9,6);

yields \(3/2\). There are two options to get the \(\LaTeX\) representation of the reduced form of \(a/b\). The first option is to start by reducing the fraction before generating the \(\LaTeX\) expression for the reduced fraction, This is the approach used in the following code.


$z = gcd(a,b);
$m = a/$z;
$n = b/$z;
$mn = if(eq($n,1), "$m", "\frac{$m}{$n}");

This code yields $m if the denominator of the reduced fraction $m/$n is 1 and \frac{$m}{$n} otherwise. There is a second option using Maple. The command


$mn = maple("latex(a/b)");

generally yields the same result as the previous code. We say generally because the \{\LaTeX\) code produce by Maple may not be the \(\LaTeX\) code that you wanted. For instance, maple("latex(1/2)") will yield \(1/2\) which is a perfectly correct \(\LaTeX\) expression. There is no way to tell the function latex( ) that you would have preferred an answer in the format \frac{}{}.

General Fractions

Everything that we have said so far is fine if you have a ratio of integers. However, how should we proceed to write a fraction of the form \(\displaystyle \frac{a\sqrt{b}}{c}\) in a simplified form? We cannot use the function frac(a,b) because it is only valid for integers \(a\) and \(b\). If you use the command maple("latex( a \sqrt{b} / c);"), then you will get a simplified form of the fraction but there is no guarantee that the command \frac{}{} will be used to format it. In fact, \(\LaTeX\) expressions generated by such a call are often really awful like \( 1/2\ 2^{1/2} \) for \(\displaystyle \frac{\sqrt{2}}{2}\). We have to proceed differently to get a nice fraction. We first use Maple to simplify the fraction (it is really good at that), and get the denominator and numerator in \(\LaTeX\) format. Then we create the \(\LaTeX\) expression for the reduced fraction. In the following example, $pq is a fraction like \(\displaystyle \frac{7\sqrt{24}}{10}\) which is not necessarily in reduced form.


$mfrac = maple("pq:=simplify($pq): p:=numer(pq): q:= denom(pq):
            [latex(p, output=string), latex(q,output=string)];");
$p = switch(0,$mfrac);
$q = switch(1,$mfrac);
$pqD = "\frac{$p}{$q}";

For instance, if $pq = "7*sqrt(24)/10";, then the value of $pqD produced by this code will be \frac{7\sqrt{6}}{5}.

Formatting a Year

Möbius uses commas to separate thousands, millions, etc. This is the normal practice for large numbers with one exception. For the years, the comma is not used to separate thousands. You do not write the year 2,020 but the year 2020. So, you need to format the years that you display in questions. Suppose that $y = 2,020. The command


$year = numfmt( "#", $y);

yields $year = 2020.

A lot more Functions

We list below all the functions that can be used in the Algorithm section.

condition

condition: stm imposes the condition defined by statement stm, which is typically constructed using one or more of the functions eq, ge, gt, le, lt and ne.

binomial

binomial(n, r) computes the rth binomial coefficient of degree \(n\). In probability, this is the number of ways of choosing \(r\) objects among \(n\), ignoring order.

decimal

decimal(n, x) returns \(x\) expressed as a floating-point number rounded to \(n\) decimal places. When \(n = 0\), commas are inserted to separate powers of \(10^3\). Trailing zeros are truncated.

eq, gt, ge, lt, le, ne

  • eq(a,b) returns 1 if \(a = b\) and 0 otherwise.
  • ge(a,b) returns 1 if \(a \geq b\) and 0 otherwise.
  • gt(a, b) returns 1 if \(a > b\) and 0 otherwise.
  • le(a,b) returns 1 if \(a \leq b\) and 0 otherwise.
  • lt(a, b) returns 1 if \(a < b\) and 0 otherwise.
  • ne(a,b) returns 1 if \(a \neq b\) and 0 otherwise.

erf

erf(x) is the value of the error function at \(x\). This is the probability that the random variable \(X\) with a normal distribution of mean 0 and variance 1 be \(\leq x\).

fact

fact(n) returns \(n!\). It can be used if \(n\) is not a non-negative integer but it should not be because the behaviour is not predictable.

frac

frac(a, b) returns the string form of the reduced fraction \(a/b\).

gcd

gcd(a, b) returns the greatest common divisor of \(a\) and \(b\).

if

if(a, b, c) return the value of \(b\) if \(a\) is nonzero and the value of \(b\) otherwise.

indexof

indexof(k, a, b, c, d, ...) returns the index of the item k within the list of items a, b, c, ...   Item a is in position 0, item b in position 1, ...

int

int(x) returns the integer part of \(x\).

inverf

inverf(z) is the inverse function of erf(x). Thus, this is the value \(x\) such that the probability that the random variable \(X\) with a normal distribution of mean 0 and variance 1 be \(\leq x\) is equal to \(z\).

invstudentst

invstudentst(k, z) is the inverse function of studentst(x). Thus, this is the value \(x\) such that the probability that the random variable \(X\) with a Students-t distribution of \(k\) degrees of freedom be \(\leq x\) is equal to \(z\).

java

java(cn, a, b, c, d, ...) evaluate a fully qualified java operator cn that takes as argument an array of strings [a,b,c,...].

lsu

lsu(n, x) returns the unit in the \(n^{th}\) significant place of \(x\). This is not the integer in the \(n^{th}\) significant place of a number. For instance,


$a = lsu(3, 3.14159);

is \(0.01\). This is the unit of the digit \(4\) in the third place of \(\pi\).

maple

maple(code) get the value produced by the last line of the Maple code.

mathml

mathml(f) returns a string consisting of the formula \(f\) typesetted in MathML. By default, mathml(f) automatically simplifies the formula. To prevent auto-simplification, use the option nosimplify. For instance,


$a = mathml("4/6", "nosimplify");

returns \(\displaystyle \frac{4}{6}\).

max, min

  • max(a, b, c, d, ...) returns the maximum value among \(a\), \(b\), \(c\), ...
  • min(a, b, c, d, ...) returns the minimum value among \(a\), \(b\), \(c\), ...

not

not(a) returns 1 if \(a = 0\) and 0 otherwise.

numfmt

numfmt(fmt, x) returns the value of \(x\) formatted according to the format used in the java command java.text.DecimalFormat. For instance, numfmt("#.###",3.14159) yields \(3.142\), numfmt(".###",3.14159) also yields \(3.142\), numfmt("00.###",3.14159) yields \(03.142\), and so on.

plotmaple

plotmaple(code) call maple to plot the graph produce by the Maple code. Consult the Maple documentation for all the possible types of graphs that can be produced with Maple.

rand

  • rand(m,n) returns a random real number between \(m\) and \(n\) inclusively.
  • rand(m,n,k) returns a random real number between \(m\) and \(n\) inclusively with \(k\) (a positive integer) significant digits.

range

  • range(n) generates a random integer between 1 and int(n) inclusively, where \(n > 0\);
  • range(m,n) generates a random integer between m and int(n) inclusively, where \(n > m\).
  • range(m,n,k) chooses randomly an integer among \(m, m+k, m+2k, \ldots, m+rk\), where \(n > m\) and \(r\) is the value int((n-m)/k).

rank

rank(n, a, b, c, d, ...) returns the nth (n>0) largest item from the list \(a, b, c, \ldots\)

rint

  • rint(n) generates a random integer between \(0\) and \(n-1\) inclusively, where \(n > 0\).
  • rint(m,n) generates a random integer between \(m\) and \(n-1\) inclusively, where \(n > m\).
  • rint(m,n,k) chooses randomly an integer among \(m, m+k, m+2k, \ldots, m+rk\), where \(n > m\) and \(r\) is the value int((n-1-m)/k).

sig

sig(n, x) returns \(x\) expressed as a floating-point number rounded to \(n\) significant digits. Scientific notation is used if needed (for very large or small numbers).

strcat

strcat(a, b, c, d, ...) returns the concatenation of the strings a, b, c, ...

studentst

studentst(k, x) is the probability that the random variable \(X\) with a Students-t distribution of \(k\) degrees of freedom be \(\leq x\).

sum

sum(v, m, n, f) sums the result of \(f(v)\) for \(v = m, m+1, \ldots, n\).

switch

switch(n, a, b, c, ...) returns the nth item in the list a, b, c, ..., where a is in position 0, b in position 1, ..., and \(n\) must be smaller than the number of items in the list.
