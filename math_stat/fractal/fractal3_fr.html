Systèmes dynamiques discrets

Les plus simples SIF sont définis par une seule fonction à valeurs réelles définie sur un segment de la droite réelle. De plus, au lieu de partir avec un ensemble (triangle, ...), nous partons avec un seul point sur le segment.

Soit f une fonction à valeurs réelles qui est définie sur la droite réelle. La formule

xn+1 = f(xn)  ,   n = 0,1,2,...

définie un système dynamique discret (SDD). Pour tous x0 donné, nous pouvons générer une suite

x1 = f(x0),   x2 = f(x1),   x3 = f(x2),   ...

Fonctions affines

Nous débutons avec l'étude des systèmes dynamiques discrets dont les fonction génératrices f sont des fonctions affines. C'est-à-dire, les fonctions de la forme

f(x) = m x + b

Le paramètre m est la pente de la droite qui représente l'image de la fonction f et b est l'abscisse à l'origine de cette droite.

Qu'arrive-t-il aux orbites x0, x1, x2, ... si nous varions les paramètres m et b?

La fonction Logistique

Le plus simple SDD non-affine est donné par la fonction logistique. Par contre, nous allons voir que le comportement des orbites générées par itérations de cette fonction sont loin d'être simples. La fonction logistique est la fonction fµ définie par

fµ(x) = µ x(1- x)   ,

où µ est un paramètre fixe mais arbitraire. Nous avons une famille de fonctions, une fonction pour chaque valeur de µ.

Le SDD associé à la fonction logistique est donné par la formule suivante.

xn+1 = fµ(xn)   ,   n = 0, 1, 2, 3, ...

Pour chaque valeur fixe de µ entre 1 et 3, les orbites x0, x1, x2, ... convergent vers un point unique pµ entre 0 et 1. Le point pµ satisfait fµ(pµ) = pµ. Donc, c'est un point fixe de fµ.

Le Théorème du Point Fixe affirme que si f: [a,b] → [a,b] est une fonction continûment différentiable et s'il existe une constante positive K <1 telle que |f'(x)| ≤ K pour tout x ∈ [a,b], alors toutes les orbites avec x0 ∈ [a,b] convergent vers un point fixe unique p ∈ [a,b].

La fonction fµ:[0,1] → [0,1] possède toujours un point fixe à l'origine. Pour µ > 1, elle possède un autre point fixe pµ>0. En fait, si nous résolvons fµ(p) = p pour p, nous trouvons que ce point fixe est pµ = (µ - 1)/µ. Pour chaque valeur de µ avec 1 < µ < 3, il est possible de trouver un petit intervalle [a,b] contenant le point fixe pµ>0 où le Théorème du Point Fixe peut être utilisée pour conclure que toute orbite avec x0 ∈ [a,b] convergent vers pµ lorsque n → ∞. Par exemple, si µ = 2, l'application graphique ci-dessus montre que le graphe de f2 coupe la droite y = x au point positif p2 = 1/2 seulement. C'est un point fixe de f2 et toutes les orbites avec x0 suffisamment près de p2 convergent vers p2.

Pour certaines valeurs de µ (les valeurs entre 3 et 4 sont vraiment intéressantes), les orbites x0, x1, x2, ... ne convergent pas vers un seul point mais ils convergent vers un ensemble plus complexe.

Pour µ = 3.4, le point x0 = 0.45195878844045... est un point périodique de f3.4 de période 2; c'est-à-dire, x1 = f3.4(x0) et x2 = f3.4(x1) = x0. On écrit x2 = f3.42(x0) = x0. L'orbite x0, x1, x2, ... est

Quand µ passe au-dessus de 3, le point fixe pµ n'est plus un attracteur et nous obtenons une orbite périodique de période 2 qui est un attracteur comme nous avons vu ci-dessus. Quand µ passe au-dessus de 3.236..., l'orbite périodique de période 2 n'est plus un attracteur et nous obtenons une orbite périodique de période 4 qui est un attracteur. Pour µ encore un petit peu plus grand, l'orbite périodique de période 4 n'est plus un attracteur et nous obtenons une orbite périodique de période 8 qui est un attracteur. Et ainsi de suite. C'est l'exemple la plus connue d'une cascade de doublement de période.

La cascade de doublement de période converge vers µ = 3.5699456...  Ce nombre est connu sous le nom de point de Feigenbaum. De plus, soit µ0 = 3, µ1 = 3.236..., µ2 = ... et ainsi de suite, les valeurs de µ pour lesquelles la fonction logistique subit un doublement de période, et soit dj = µj+1 − µj pour j ≥ 0. Il a été démontré que limj → ∞ dj/dj+1 = 4.6692016091029...   Ce nombre est appelé la constante de Feigenbaum. Feigenbaum a découvert ce nombre en 1975. Cette constante est universelle dans le sens qu'elle est la même pour une grande famille de SDD de la forme xn+1 = gµ(xn) où le graphe de gµ ressemble au graphe de la fonction logistique fµ.

Pour µ = 3.839..., nous avons que

{0.14988539433432, 0.48917380192271, 0.95930024021836, 0.14988539433432, ...}

est une orbite périodique de période 3 de f3.839... qui est un attracteur. Les valeurs ci-dessus ont été tronquées à 14 chiffres décimaux. Il découle du fameux théorème de Sarkovskii que f3.839... possède des orbites périodiques de toutes les périodes. Toutes les orbites périodiques, sauf l'orbite de période 3 ci-dessus, ne sont pas des attracteurs. Donc, sauf si une orbite débute avec un point exactement sur une des orbites qui n'est pas un attracteur, elle va converger vers l'orbite périodique de période 3. Notons que, en raison des erreurs de troncature, il est pratiquement impossible de tracer le graphe en forme de toile d'araignée d'une des orbites périodiques qui n'est pas un attracteur.
