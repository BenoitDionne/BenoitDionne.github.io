Définition des systèmes itératifs de fonctions

Cette section est théorique. Les lecteurs qui n'ont pas les connaissances de base des mathématiques peuvent ignorer cette section et reprendre leur lecture avec la section suivante où nous fournissons des exemples de fractales produites à l'aide de systèmes itératifs de fonctions.

Un espace métrique est un ensemble E avec une métrique d :E ×E→ [0 ,∞ [. Nous dénotons cet espace métrique par (E ,d ). La distance entre un point a∈E et un ensemble B⊂E est définie par d (a ,B ) =inf {d ( a,b ) :b∈B } , et la distance de l'ensemble A⊂E à l'ensemble B⊂E est définie par d (A ,B ) =sup {d (a ,B ) :a∈ A} .

Notons que d (A ,B ) peut ne pas être égale à d (B ,A ) comme nous pouvons l'observer dans la figure ci-dessus.

Proposition: Supposons que l'espace métrique (E ,d ) est complet; c'est-à-dire, toute suite de Cauchy converge. Soit Ec l'ensemble des sous-ensembles compactes et non-vides de E. Alors, la fonction dc : Ec× Ec→ [0 ,∞ [ définie par

d c (A ,B ) =max {d (A ,B ) ,d (B ,A ) }

pour tout A, B∈Ec est une métrique sur Ec. De plus, l'espace métrique (E c, dc ) est complet. La métrique dc est appelée la distance de Hausdorff ou métrique de Hausdorff.

Une démonstration de cette proposition se trouve dans le livre de . Notons que pour a∈A et A,B ∈Ec, nous avons que d (a ,B ) =min {d ( a,b ) :b∈B } <∞ et d (A ,B ) =max {d (a ,B ) :a∈ A} <∞ car A et A sont des ensembles compacts.

Une fonction f :E→ E est une contraction s'il existe un nombre C tel que 0≤C <1 et d (f ( x) ,f (y ) ) ≤Cd (x ,y ) pour tout x, y∈E. Une contraction est évidemment une fonction continue. La valeur C est appelée un facteur de contraction.

Si f :E→ E est une fonction continue, alors l'image d'un ensemble compact par cette fonction est un ensemble compact. Ainsi, la fonction f induit aussi une fonction f :E c→E c de façon naturelle. Supposons que { fj } 1≤ j≤J est une collection de fonctions continues fj :E→ E. Nous définissons une fonction fc : Ec→ Ec par

fc ( A) =∪ j=1 J fj (A )

pour tout A∈ Ec. Cette fonction est bien définie car l'union finie d'ensembles compacts est un ensemble compact.

Définition: Un système itératif de fonctions (hyperbolique) (SIF) sur un espace métrique complet (E c, dc ) est une collection { fj } 1≤ j≤J de contractions de E dans lui-même.

Proposition Ⅱ: Supposons que { fj } 1≤ j≤J est un SIF où chaque fonction fj est une contraction avec un facteur de contraction Cj . Alors la fonction fc : Ec→ Ec est une contraction avec un facteur de contraction C= max1≤ j≤J Cj.

Démonstration: Étant donné A, B∈Ec , nous avons que d ( fj (a ) ,fj ( b) ) ≤d (a ,b ) pour tout a∈A et b∈B. Ainsi  ...

Théorème Ⅲ: Si (E ,d ) est un espace métrique complet et { fj } 1≤ j≤J est un SIF (hyperbolique), alors fc : Ec→ Ec a un point fixe unique; c'est-à-dire, il existe un seul ensemble K∈ Ec tel que fc ( K) =K. De plus, pour tout ensemble A0 ∈Ec, la suite d'ensembles { An } n≥ 0 définis par A n+1 =fc ( An ) converge vers K par rapport à la métrique de Hausdorff dc lorsque n→∞ .

Le théorème précédent est une conséquence directe du Théorème de contraction car (E c, dc ) est un espace métrique complet et fc : Ec→ Ec est une contraction.

Il y a deux questions qui découlent du paragraphe précédent. Premièrement, comment pouvont-nous trouver x →∈K ? Il suffit de prendre un point fixe x d'une fonction fj du SIF. Les fonctions fj que nous considérons sont de la forme fj ( x→ ) =Mj x→ +b →j où Mj est une matrice de dimension 2×2 et b →j est un vecteur colonne. Il est facile de résoudre le système d'équations linéaires Mj x→ +b →j =x→ pour obtenir un point fixe de fj .

Le deuxième question est comment pouvons-nous calculer le diamètre d'un ensemble V j1 ,j 2, …, jn ? La réponse est que nous ne calculons pas ce diamètre mais nous calculons plutôt la plus petit borne supérieure de ce diamètre que nous pouvons trouver. Puisque diam (V j1 ,j 2, …, jn ) <C j1 ,j 2, …, jn diam ( A0 ) , plutôt de tester pour diam (V j1 ,j 2, …, jn ) <ε, nous testons pour C j1 ,j 2, …, jn diam ( A0 ) <ε. Si C j1 ,j 2, …, jn diam ( A0 ) ≥ε, alors nous assumons que diam (V j1 ,j 2, …, jn ) ≥ε quoique nous pourrions avoir que diam (V j1 ,j 2, …, jn ) <ε. Utiliser cette approche pour estimer diam (V j1 ,j 2, …, jn ) peut comporter quelques itérations de plus de la procédure ci-dessus que ce qui est théoriquement prédit mais c'est quand même moins exigeant en terme de temps de calculs que d'essayer de calculer directement les diamètres des ensembles V j1 ,j 2, …, jn . Nous devons donc trouver les plus petits facteurs de contraction C j1 ,j 2, …, jn que l'on peut. Nous ne voulons pas trop surestimer ces facteurs de contractions car cela entraînera des itérations supplémentaires de la procédure ci-dessus et donc un plus grand ensemble S qu'il est nécessaire. Problème inverse pour les SIF

La majorité des SIF que nous avons présentés dans les sections précédentes proviennent des livres mentionnés dans les à la fin de ce document. Supposons qu'un ensemble compact L⊂ ℝ2 représente une figure quelconque que nous aimerions produire avec un SIF.
