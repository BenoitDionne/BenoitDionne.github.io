Chaotic Behaviour

Content

To motivate the definition of chaotic behaviour for a DDS, we start with a very simple map from the unit circle to itself. After that, we consider the DDS generated by the logistic function fμ with μ≥4.

Maps on the Circle

We consider the unit circle in the complex plane defined by S1 ={ z∈ℂ :|z |=1 } . The function φ: ℝ/ℤ→ S1 defined by φ (θ ) =e2 πθi is an isomorphism between ℝ/ℤ and S1 . It is usual to defined the distance d ( θ1, θ2 ) between θ1 ,θ2 ∈ℝ/ℤ as d ( θ1 ,θ2 ) =d ( e2π θ1 i, e2π θ2 i ) , the smallest distance between e2π θ1 i and e2π θ2 i along the circle S1 . With this definition of distance on ℝ/ℤ, the function φ is an isometry.

Example: Using the isomorphism φ defined in the previous paragraph, the function f :S 1→ S1 defined by f (z ) =ze 4πi /3 corresponds to the function f: ℝ/ℤ→ ℝ/ℤ defined by f ( θ) =θ+2/ 3 All the points are periodic points of period 3 This proves that Sarkovskii's theorem is not valid on S1 . This is the example that we mentioned at the end of the .

Using the isomorphism φ defined at the beginning of this section, the function g :S 1→ S1 defined by g (z ) =z2 corresponds to the function g: ℝ/ℤ→ ℝ/ℤ defined by g (θ ) =2θ. Therefore, the behaviour of the DDS generated by the function g acting on S1 is identical to the behaviour of the DDS generated by the function g acting on ℝ/ℤ. The function g satisfies several properties.

  1. The function g has periodic points of all periods, and the periodic points for g are dense on S1 . To justify this claim, we consider n∈ℕ . We get from g ∘ n (θ )= θ that 2n θ=θ+k for k∈ℤ . Thus θ= θk= k2n −1 ( mod1 ) for 0≤k< 2n-1 . For instance, if n=3, we get θ= θk= k7 ( mod1 ) for 0≤k< 7. We get two periodic orbits of period 3; namely, { 1/7 ,2/7 ,4/7 ,1/7 ,… } and { 3/7 ,6/7 ,5/7 ,3/7 ,… }. We obviously have the fixed point θ0 =0. Hence, since n is arbitrary, we have that g has periodic points of all periods. Moreover, the periodic points for g are dense on S1 because the rational numbers are dense on ℝ.
  2. Given two open sets U,V ⊂S1 , there exists an integer k≥0 such that g ∘ k (U ) ∩V≠∅ . This is obvious because we can take k large enough such that g ∘ k (U ) ⊃S1 .
  3. There exists δ>0 such that, for any z∈ S1 and open neighbourhood U⊊ S1 of z, we have that d (g ∘ k (z ) ,g ∘ k (w ) ) >δ for some w∈U and integer k≥0. This result is also easy to prove. Suppose that δ<π where 2π is the circumference of the unit circle. There exists k≥0 such that g ∘ k (U ) ⊃S1 . Therefore, there must be a point w∈U such that d (g ∘ k (z ) ,g ∘ k (w ) ) >δ.

Definition: Suppose that E is a topological space. A function f : E→E is topologically transitive if, for every pair of open sets U,V ⊂E, there exists an integer k≥0 such that f ∘ k (U ) ∩V≠∅ .

It follows from (2) above that g : S1→ S1 is topologically transitive. Roughly speaking, this means that the domain of the DDS generated by g cannot be decomposed into two disjoint and g-invariant open sets.

Definition: Suppose that E is a topological space. A function f : E→E has sensitive dependence on initial conditions if there exists δ>0 such that, for every x∈E and open neighbourhood U ⊂E of x, we have that d (f ∘ k (x ) ,f ∘ k (y ) ) >δ for some point y∈U and integer <k.

It follows from (3) above that g : S1→ S1 has sensitive dependence on initial conditions. Roughly speaking, this means that there are points w∈ S1 as closed as we want to a given initial point z∈ S1 such that f ∘ k (w ) does not stay closed to f ∘ k (z ) for all k.

Remark: The butterfly effect is a popular expression referring to sensitive dependence on initial conditions. It is also often associate to chaos. The origin of this expression goes back to the simplified mathematical model for weather prediction introduced by Edward N. Lorenz. Lorenz observed numerically that a very small variation of the initial conditions produced a completely different solution. To draw attention to his observations, Lorenz asked the following question which is now famous. Does the flap of a butterfly’s wings in Brazil set off a tornado in Texas?. Lorenz' model is a system of differential equations that has what is called a strange attractor. The strange attractor for Lorenz' model is called the Lorenz attractor.

The three properties of g : S1→ S1 mentioned above are those required to say that a function has a chaotic behaviour.

Definition: Suppose that E is a metric space. A function f : E→E has a chaotic behaviour or is chaotic on E if

  • f has sensitive dependence on initial conditions,
  • f is topologically transitive, and
  • the set Pf of periodic points for f is dense in E.

We have that g : S1→ S1 defined above is chaotic.

Remark: Suppose that f : E→E is a continuous function on a metric space E. It has been proved by that topologically transitive and Pf dense in E implies sensitive dependence on initial conditions. Nevertheless, we keep the tradition of using the definition of chaotic behaviour given above because it lists three of the must important properties of chaotic behaviour. Moreover, it has been proved by that sensitive dependence on initial conditions and Pf in E do not imply topologically transitive, and sensitive dependence on initial conditions and topologically transitive do not imply that Pf is dense in E

Suppose that f : E→E is a continuous function on a metric space E. It is easy to prove that if there exists a dense orbit in E of the form { f ∘ n (x ) } n≥0 for some x∈E, then f is topologically transitive. So, the function gq of Jacobi's theorem is topologically transitive. However, gq does not have sensitive dependence on initial conditions because gq preserve the distance. Moreover, as we have shown in the first paragraph of the proof of Jacobi's theorem, gq does not have any periodic point.

Given ε > 0, we choose a positive integer m such that 2-m < ε and let δ = 2-m-1. If t ∈ Σ2 is such that d(t,s) < δ = 2-m-1, then sj = tj for 0 ≤ j ≤ m+1 according to the previous proposition. It is usually easy to prove properties associated to periodic points for σ. For instance, the set Pm of points s ∈ Σ2 such that σm(s) = s is of cardinality 2m. To prove this claim, it suffices to note that the points s ∈ Σ2 such that σm(s) = s are of the from (s0,s1,...,sm-1,s0,s1,...,sm-1,s0...). There are 2m different combinations of 0 and 1 of length m.

Corollary: σ:Σ2 → Σ2 has a chaotic behaviour.

Logistic Function

We are continuing our study of the DDS generated by the logistic function fμ defined by fμ(x) = μx(1-x). In this section, we assume that μ ≥ 4. It is important to note that we no longer have f([0,1]) ⊂ [0,1] when μ > 4. The reader may use the graphical application for the logistic function that can be found in the to observe that almost all the orbits generated by fμ with μ > 4 converge very rapidly to -∞. To get a realistic cobweb graph, the number of iterations should be small because the convergence to -∞ is very fast.

The following concept will be used to study the qualitative behaviour of the DDS generated by fμ.

Definition: Suppose that F and G are two metric spaces, and that f:F → F and g:G → G are two continuous functions. We say that f and g are topologically conjugate if there exists an homeomorphism h:F → G such that h∘f = g∘h. The function h is called a topological conjugacy between f and g.

The DDS generated by two topologically conjugate functions have the same qualitative behaviour. In particular, if one of them has a chaotic behaviour, then the other also has a chaotic behaviour. To study the qualitative behaviour of the DDS generated by fμ with μ > 4, we show that the function fμ is topologically conjugate to a shift map on two symbols σ:Σ2 → Σ2 defined in the previous section.

  6. We prove by induction that fμ∘n(x) < μn-1(fμ'(x))2/16 < u- for 1 < n ≤ N where N is defined in (3). It follows from (2) that the result is true for n = 2. We assume that fμ∘n(x) < μn-1(fμ'(x))2/16 < u- is true for some integer 1 < n < N. Since fμ'(x) = μ(1-2x) ≤ μ for x ∈ [0,u-] ⊂ [0,1/2], we get that
    fμn+1(x) = fμ(fμn(x)) ≤ μfμn(x)
    < μ(μn-1(fμ'(x))2/16) = μn(fμ'(x))2/16 < u-     ,
    where the second to last inequality comes from the hypothesis of induction and the last inequality comes from (3). We note that, according to the Mean Value Theorem, there exists ξ ∈ ]0,z[ such that fμ(z) = fμ(z)-fμ(0) = fμ'(ξ)(z-0) ≤ μz for all z ∈ [0,1/2]. This justifies the first inequality above.
  7. If N = 2, then it follows from (4) and (5) that
    |(fμ2)'(x)| = |fμ'(fμ(x))| |fμ'(x)|
    > μ2/5 (24/μ3)1/2 = (24μ/25)1/2 > (96/25)1/2 > 1     .
    Thus |(fμ∘mx)'(x)| > 1 in is satisfied with mx = 2.
  8. If N > 2, let w- be the solution of fμ(w) = u- with w- ≤ u-. This solution is w- = (1-(μ2-2μ+2)1/2/μ)/2. We have that μN-2(fμ'(x))2/16 ≤ w- because μN-2(fμ'(x))2/16 > w- yields u- = fμ(w-) = μw-(1-w-) < μw- < μN-1(fμ'(x))2/16 that contradicts the minimal property in the choice of N. Therefore, it follows from (6) that fμ∘n(x) < w- for 1 < n < N. Since the function fμ' is decreasing on [0,w-], we get that |fμ'(fμ∘n(x))| ≥ fμ'(w-) = (μ2-2μ+2)1/2 > 101/2 for 1 < n < N. Finally, combining these inequalities with the relation |fμ'(fμ(x))| |fμ'(x)| > 1 obtained in (7), we get that |(fμ∘N)'(x)| = ∏1≤n≤N |fμ'(fμ∘(n-1)(x))| > 10(N-2)/2 > 1. Thus, |(fμ∘mx)'(x)| > 1 in is satisfied with mx = N.

This concludes the proof.  ∎

Theorem: For μ > 4, the set Δ is a Cantor set and the function fμ:Δ → Δ is chaotic.

Proof:
Part A: We proof that fμ:Δ → Δ is chaotic.

We first prove that Bs contains only one point for every s ∈ Σ2. It suffices to prove that Bs is not a closed interval of length greater than 0. It follows from that there exist C > 0 and r > 1 such that |(fμ∘n)'(x)| ≥ Crn for all x ∈ Δ and n > 0. Given s ∈ Σ2, we suppose that Bs = [a,b] ⊂ Δ with a < b. By the Mean Value Theorem, there exists ξn ∈ ]a,b[ such that  ...

|fμ∘n(a)-fμ∘n(b)| = |(fμ∘n)'(ξn)| |a-b| ≥ Crn|a-b|

for all n ∈ ℕ. It follows that |fμ∘n(a)-fμ∘n(b)| → ∞ as n → ∞. This is a contradiction that Δ is invariant under the action of fμ and that Δ is bounded.

It follows from the previous paragraph that the function H:Δ → Σ2 defined by H(x) = s for Bs = {x} is well defined. It is also a bijection between Δ and Σ2. To prove that H is a continuous function, we prove that H is continuous at an arbitrary point x ∈ Δ. Suppose that H(x) = s. Given ε > 0, we choose n ∈ ℕ such that 2-n < ε, and δ > 0 such that Δ ∩ ]x-δ,x+δ[ ⊂ Bs0,s1,...,sn. Hence, if y ∈ ]x-δ,x+δ[ ∩ Δ, then H(y) = (s0,s1,...,sn,...). Therefore, d(H(y),s) ≤ 2-m < ε. To prove that H-1 is a continuous function, we prove that H-1 is continuous at an arbitrary point s ∈ Σ2. Suppose that H-1(s) = x; namely, H(x) = s. Given ε > 0, we choose n ∈ ℕ such that diam(Bs0,s1,...,sn) < ε. This is possible because Bs0 ⊃ Bs0,s1 ⊃ Bs0,s1,s2 ⊃ ... with {x} = Bs = ∩m≥0 Bs0,s1,...,sm. Let δ = 2-m. If t ∈ Σ2 and d(t,s) < δ, then tj = sj for 0 ≤ j ≤ n. Therefore, H-1(t) ∈ Bs0,s1,...,sn and so |H-1(y)-x| < ε.

We now prove that σ∘H = H∘fμ on Δ. We consider an arbitrary point x ∈ Δ and assume that H(x) = s. Since {x} = Bs = ∩n≥0Bs0,s1,...,sn, we get that

{fμ(x)} = fμ({x}) = fμ(∩n≥0Bs0,s1,...,sn)
⊂ ∩n≥0 fμ(Bs0,s1,...,sn) ⊂ ∩n≥0 Bs1,s2,...,sn = Bs1,s1,... = {y}

for a point y ∈ Δ, where the second inclusion comes from fμ(Bs0,s1,...,sn) ⊂ Bs1,s2,...,sn as we have seen before. Thus H(fμ(x)) = H(y) = (s1,s2,...) = σ(s) = σ(H(x).

Since the function fμ:Δ → Δ is topologically conjugate to σ:Σ2 → Σ2, a function with a chaotic behaviour on Σ2, we have that fμ has a chaotic behaviour on Δ.

Part B: We prove that Δ is a Cantor set.

We have seen that Δ is compact and so closed. The first paragraph of this proof can be easily adapted to prove that Δ is also totally disconnected. It also follows from the topological conjugacy between Δ and Σ2 that there exists x ∈ Δ such that {fμj(x)}j≥0 is a dense orbit in Δ. This implies that Δ is perfect. This completes the proof that Δ is a cantor set.  ∎

The DDS generated by the logistic function fμ for μ = 4 also exhibits a chaotic behaviour. More precisely, we have the following result.

Theorem: For μ = 4, the DDS generated by fμ:[0,1] → [0,1] is chaotic.

The invariant set on which f4 is chaotic is not a Cantor set. The technique used to study the qualitative behaviour of the DDS generated by fμ for μ > 4 cannot be used to study the qualitative behaviour of the DDS generated by f4.

Proof: We first prove that the function f4:[0,1] → [0,1] is semi-conjugate to the function g : S1→ S1 defined in the section above. Namely, we define a continuous function H:S1 → [0,1] such that H∘g = f4∘H but H is not an isomorphism.  ...

Let H1:S1 → [-1,1] be the function defined by H1(θ) = cos(θ), and H2:[-1,1] → [0,1] be the function defined by H2(x) = (1-x)/2. If h:[-1,1] → [-1,1] is the function defined by h(x) = 2x2-1, then

H1(g(θ)) = H1(2θ) = cos(2θ) = 2 cos2(θ) - 1
= h(cos(θ)) = h(H1(θ)

and

f4(H2(x)) = f4((1-x)/2) = 4((1-x)/2)(1-(1-x)/2)
= 1-x2 = (1-(2x2-1))/2 = (1-h(x))/2 = H2(h(x)) .

Hence, if H = H2∘H1, then

H(g(θ)) = H2(H1(g(θ))) = H2(h(H1(θ)))
= f4(H2(H1(θ))) = f4(H(θ)) .

We note that H:S1 → [0,1] is a two to one function because H(θ) = H(2π-θ). We however have that the function H:S1 → [0,1] is onto. Since H does not define a topological conjugacy between f4 and g, we cannot automatically conclude that f4 is chaotic on [0,1] because g is chaotic on S1.

To prove that the function f4:[0,1] → [0,1] is topologically transitive, let U,V be two open intervals in [0,1]. We choose two open sets (two open arcs) Uˆ,Vˆ on S1 such that H(Uˆ) ⊂ U and H(Vˆ) ⊂ V. Since g : S1→ S1 is topologically transitive, there exists an integer n ≥ 0 such that g∘n(Uˆ) ∩ Vˆ ≠ ∅. Hence,

f4∘n(U) ∩ V ⊃ f4∘n(H(Uˆ)) ∩ H(Vˆ) = H(g∘n(Uˆ)) ∩ H(Vˆ) ⊃ H(g∘n(Uˆ) ∩ Vˆ) ≠ ∅ .

To prove that the function f4:[0,1] → [0,1] has sensitive dependence on initial conditions, we choose δ ∈ ]0,1/2[. Suppose that x ∈ [0,1] and that U ⊂ [0,1] is an open interval containing x. Note that the topology on [0,1] is the topology inherited from ℝ. We choose an open arc Uˆ on S1 such that H(Uˆ) ⊂ U. There exists n > 0 such that g∘n(Uˆ) ⊃ S1. Hence,

f4∘n(U) ⊃ f4∘n(H(Uˆ)) = H(g∘n(Uˆ)) ⊃ H(S1) = [0,1] .

Thus, there exists y ∈ [0,1] such that |f4∘n(x)-f∘n(y)| > δ.

Finally, to prove that the set Pf4 of periodic points for f4:[0,1] → [0,1] is dense in [0,1], let x be an arbitrary point of [0,1] and U ⊂ [0,1] be an open interval containing x. We choose an open arcs Uˆ on S1 such that H(Uˆ) ⊂ U. Since the set Pg of periodic points for g : S1→ S1 is dense in S1, there exists θ ∈ Pg ∩ Uˆ. Hence, H(θ) ∈ Pf4 ∩ U.  ∎
