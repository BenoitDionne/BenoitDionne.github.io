Discrete Dynamical Systems

Before defining what is a fractal, we must study discrete dynamical systems (DDS). In fact, it is enough to consider DDS on the real line. They illustrate all the complexity that can be displayed by DDS.

Let f be a real valued function defined on the real line. The formula

xn+1 = f(xn), n = 0, 1, 2, ...

defines a DDS. Given any x0, we may produce the sequence

x1 = f(x0), x2 = f(x1), x3 = f(x2), ...

It is called an orbit of the DDS.

Affine Functions

We begin with the study of the discrete dynamical systems whose updating functions f are affine functions. Namely, functions of the form

f(x) = m x + b

The parameter m is the slope of the line representing the image of the function f and b is the y intercept of this line.

What happen to the orbits x0, x1, x2, ... if we change the values of the parameters m and b?

Logistic Map

The simplest non-affine DDS is given by the logistic map. However, we show below that the behaviour of the orbits generated by iterating this function is far from simple. The logistic map is the function f𝜇; defined by

f𝜇(x) = 𝜇 x(1-x)

where 𝜇 is a fixed but arbitrary parameter. We have a family of functions; one for each value of 𝜇.

The DDS associated to the logistic map is given by the following formula.

xn+1 = f𝜇(xn), n = 0, 1, 2, 3, ...

For each fixed value of 𝜇 between 1 and 3, the orbits x0, x1, x2, ... converge toward a single point p𝜇 between 0 and 1. The point p𝜇 satisfies f𝜇(p𝜇) = p𝜇. Therefore, it is a fixed point of f𝜇.

The Fixed Point Theorem states that if f:[a,b] → [a,b] is a continuously differentiable function and there exists a positive constant K < 1 such that |f'(x)| ≤ K for all x ∈ [a,b], then all the orbits with x0 ∈ [a,b] converge to a unique fixed point p ∈ [a,b].

The function f𝜇:[0,1] → [0,1] has always a fixed point at the origin. For 𝜇 > 1, there is another fixed point p𝜇>0. In fact, if we solve f𝜇(p) = p for p, we find that this fixed point is p𝜇 = (𝜇-1)/𝜇. For each value of 𝜇 with 1 < 𝜇 < 3, it is possible to find a small interval [a,b] containing the fixed point p𝜇 where the Fixed Point Theorem can be used to conclude that any orbit with an initial condition x0 ∈ [a,b] converges toward p𝜇 as n → ∞. For instance, if 𝜇 = 2, the graphical application above shows that the graph of f2 intersects the line y = x at the positive point p2 = 1/2 only. It is a fixed point of f2 and all orbits with x0 closed enough to p2 converge to p2.

For some values of 𝜇 (values between 3 and 4 are really interesting), the orbits x0, x1, x2, ... do not converge toward a single point but they converge toward a more complex set.

For 𝜇 = 3.4, the point x0 = 0.45195878844045... is a periodic point of f3.4 of period 2; namely, x1 = f3.4(x0) and x2 = f3.4(x1) = x0. We write x2 = f3.42(x0) = x0. The orbit x0, x1, x2, ... is

0.45195878844045, 0.84215476876273, 0.45195878844045, 0.84215476876273, ...

where the values have been truncated to 14 digits after the decimal point. The reader should draw the cobweb graph of the orbit of f3.4 starting with x0 = 0.45195878844045 using the graphical application above.

For 𝜇 = 3.5, the point x0 = 0.87499726360246... is a periodic point of f3.5 of period 4; namely, x4 = f3.44(x0) = x0. The orbit x0, x1, x2, ... is

0.87499726360246, 0.38281968301732, 0.82694070659144, 0.50088421030722, 0.87499726360246, ...

where the values have been truncated to 14 digits after the decimal point. The reader should draw the cobweb graph of the orbit of f3.5 starting with x0 = 0.87499726360246 using the graphical application above.

When 𝜇 crosses above 3, the fixed point p𝜇 is no longer attracting and we get an attracting periodic orbit of period 2 as we have seen above. When 𝜇 crosses above 3.236..., the periodic orbit of period 2 is no longer attracting and we get an attracting periodic orbit of period 4. For 𝜇 slightly larger, the periodic orbit of period 4 is no longer attracting and we get an attracting periodic orbit of period 8, And so on. This is the best known example of a period doubling cascade.

Period doubling accumulates to 𝜇 = 3.5699456...  This number is known as the Feigenbaum point. Moreover, let 𝜇0 = 3, 𝜇1 = 3.236..., 𝜇2 = ... and so on be the values of 𝜇 for which the logistic map undergoes period doubling and let dj = 𝜇j+1−𝜇j for j ≥ 0. It has been shown that limj → ∞ dj/dj+1 = 4.6692016091029...   This number is called the Feigenbaum constant. Feigenbaum discovered this number in 1975. This constant is universal in the sense that it is the same for a whole class of DDS of the form xn+1 = g𝜇(xn) where the graph of g𝜇 looks like the graph of the logistic map f𝜇.

For 𝜇 = 3.839..., we have that

0.14988539433432, 0.48917380192271, 0.95930024021836, 0.14988539433432, ...

is an attracting periodic orbit of period 3 for f3.839..., where all value have been truncated to 14 digits after the decimal point. It follows from the famous theorem of Sarkovskii that f3.839... has periodic orbits of all possible periods. None of the periodic orbits, except for the periodic orbit of period 3 above, is attracting. So, unless an orbit starts with a point exactly on one of these non-attracting periodic orbit, it will converge toward the periodic orbit of period 3. Note that, due to truncation errors, it is practically impossible to draw the cobweb graph of one of these non-attracting periodic orbits.

What happen when 𝜇 is greater than or equal to 4? We have that the orbits of f4 are Chaotic .
