Discrete Dynamical Systems

The simplest IFS are defined by a single real valued function defined on a segment of the real line. Moreover, instead of starting with a set (triangle, ...), we start with a single point on the segment.

Let f be a real valued function defined on the real line. The formula

xn+1 = f(xn)   ,   n=0,1,2,...

defines a discrete dynamical system (DDS). Given any x0, we may produce a sequence

x1 = f(x0),   x2 = f(x1),   x3 = f(x2),   ...


Affine Functions

We begin with the study of the discrete dynamical systems whose updating functions f are affine functions. Namely, functions of the form

f(x) = m x + b

The parameter m is the slope of the line representing the image of the function f and b is the y intercept of this line.

What happen to the orbits x0, x1, x2, ... if you change the values of the parameters m and b?

Logistic Map

The simplest non-affine DDS is given by the logistic map. However, we will see that the behaviour of the orbits generated by iterating this function are far from simple. The logistic map is the following function.

fµ(x) = µ x ( 1- x)   ,

where µ is a fixed but arbitrary parameter. We have a family of functions; one for each value of µ.

The DDS associated to the logistic map is given by the following formula.

xn+1 = fµ(xn)   ,   n = 0, 1, 2, 3, ...

For each fixed value of µ between 1 and 3, the orbits x0, x1, x2, ... converge toward a single point pµ between 0 and 1. The point pµ satisfies fµ(pµ) = pµ. Therefore, it is a fixed point of fµ.

The Fixed Point Theorem states that if f: [a,b] → [a,b] is a continuously differentiable function and there exists a positive constant K < 1 such that |f'(x)| < K for all x ∈ [a,b], then all the orbits with x0 ∈ [a,b] converge to a unique fixed point p ∈ [a,b].

The function fµ:[0,1] → [0,1] has always a fixed point at the origin. For µ > 1 , there is another fixed point p>0. For 1<µ <3, we can find a small interval [a,b] containing the fixed point p where the Fixed Point Theorem can be applied to conclude that any orbit with an initial condition x0 ∈ [a,b] converges toward p as n → ∞. For instance, if µ = 2, the graphical application above shows that the graph of f2 intersects the line y = x at only one point p>0. It is a fixed point of f2 and all orbits with x0 closed enough to p converge to p.

For some values of µ (values between 3 and 4 are really interesting), the orbits x0,x1, x2, ... do not converge toward a single point but they do converge toward a more complex set. What happen when µ is chosen close to 4? The orbits become Chaotic .
