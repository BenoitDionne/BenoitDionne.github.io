Fractal Dimensions

There is no clear definition of a fractal. Benoit B. Mandelbrot (the father of Fractal Geometry) defines a fractal as a set for which the Hausdorff dimension is strictly greater than the topological dimension. Some mathematicians will also request that the set had some self-similarity. This is the case for the Sierpinski triangle.

We only consider the notion of similarity dimension and Minkowski dimension. We may add more information on these topics later (?).

Similarity Dimension

The similarity dimension of a set A is defined by the equation

Dimension = log(a) / log(1/s)

where a is the number of small sets similar to the original set A and s is the size of the rescaling used to produce the small sets. For instance:

  • The similarity dimension of the interval [0,1] is 1. For s = 1/2 and a = 2, we get

    log(a)/log(1/s) = log(2)/log(2) = 1.

    We leave it to the reader to describe the (obvious) two functions from [0,1] into itself that compose the IFS {fj}1≤j≤2 such that the interval [0,1] is the fixed points of the function fc associaited to the IFS.

  • The similarity dimension of a cube is 3. For s = 1/2 and a = 8, we get

    log(a)/log(1/s) = log(8)/log(3) = log2(8) = 3.

    Again, we leave it to the reader to describe the (obvious) eight functions from [0,1]3 into itself that compose the IFS {fj}1≤j≤8 such that the cube [0,1]3 is the fixed points of the function fc associaited to the IFS.

  • The similarity dimension of the Sierpinski triamgle is about 1.5850. For s = 1/2 and a = 3, we get

    log(a)/log(1/s) = log(3)/log(2) ∼ 1.5850.

    For s = 1/4 and a = 9, we get

    log(a)/log(1/s) = log(9)/log(4) ∼ 1.5850.

Minkowski Dimension

The Minkowski dimension of a set A is defined by the following formula.

Dimension = lim𝜇->0 log(N(A,𝜇)) / log(1/𝜇) ,

where N(A,𝜇) is the smallest number of squares of side length 𝜇 > 0 needed to cover A.
