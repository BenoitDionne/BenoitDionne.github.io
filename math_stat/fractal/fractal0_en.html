Discrete Dynamical Systems

Content

Our introduction to chaos and fractals starts with the simplest discrete dynamical system. Despite its simplicity, it illustrates all the complexity that the behaviour of a discrete dynamical system can exhibit.

Introduction to Discrete Dynamical Systems

Let f be a real valued function defined on the real line. Given any x0, the formula

xn +1= f( xn ) , n=0,1,2,…

defines a sequence { xn } n≥ 0 ={ x0 , x1 , x2 , …} . This sequence is called a (forward) orbit of x0 generated by f. We denote by f ∘ n the composition f∘f∘ f∘ …∘f of n times the function f. Hence, xn= f ∘ n ( x0 ) .

Definition: The function φ: ℕ×ℝ→ ℝ defined by φ ( n,x ) =f ∘ n ( x) is called a discrete dynamical system (DDS) generated by the function f. The function f is called the updating function or generating function.

Some points of the real line will play a particularly important role in our study of DDS.

Definition: Suppose that f: ℝ→ℝ. A point p∈ℝ is a fixed point of f if f ( p) =p. A point p∈ℝ is a periodic point of period k of f if f ∘ k ( p) =p and f ∘ j ( p) ≠p for 0<j< k. If p is a periodic point of period k, then the orbit { xn } n≥ 0 with x0 =p is called a periodic orbit of period k.

Affine Functions

We begin with the study of the DDS generated by affine updating functions f; namely, by functions of the form f ( x) =mx+b, where m is the slope of the line representing the graph of the function f and b is the y intercept of this line. Despite their simplicity, these updating functions provide a strong foundation for the study of DDS generated by more general functions f as we will see later.

What are the conditions that f must satisfy to ensure that the orbits { xn } n≥ 0 converge toward a fixed point p as n→∞ ? The answer depends only of the slope m.

Proposition: Let f: ℝ→ℝ be the function defined by f ( x) =mx+b.

  • If |m|< 1, then f has a unique fixed point p and all orbits { xn } n≥ 0 converge toward p as n→∞ .
  • If |m|> 1, then f has a unique fixed point p but none of the orbits { xn } n≥ 0 converges toward p as n→∞ except for the constant orbit starting with x0 =p.
  • If m=1, and b≠0, then f has no fixed point and all the orbits { xn } n≥ 0 converge to ∞ as n→∞ . If m=1 and b=0, then f ( x) =x and all the points are fixed points.
  • If m= -1, then f has a unique fixed point p but no orbit { xn } n≥ 0 with x0 ≠p converges to it as n→∞ . All the orbits { xn } n≥ 0 with x0 ≠p are periodic orbit of period 2.

To study the behaviour of the orbits { xn } n≥ 0 generated by fμ as n→∞ when 1<μ< 4, we need the fallowing famous result.

Theorem (Fixed Point Theorem or Contraction Mapping Theorem): Suppose that f : [ a,b ] → [ a,b ] . If there exists a constant C<1 such that |f ( x) -f ( y) |<C|x- y| for all x, y∈ [ a,b ], then all the orbits { xn } n≥ 0 given by the formula xn+1 =f( xn ) for n=0, 1,2, … and x0 ∈ [ a,b ] converge to a unique fixed point p∈ [ a,b ] for f as n→∞ .

The previous theorem is also true if the interval [ a,b ] is replaced by a complete metric space E and |f ( x) -f ( y) |<C|x- y| is replaced by d ( f( x) ,f ( y) ) <Cd ( x,y ) where d: E×E→ [ 0,∞ [ is the metric on E. This theorem will play a major role in the following documents. The conclusion of this theorem is also true if f : [ a,b ] → [ a,b ] is continuously differentiable and there exists a constant C>0 such that |f ' ( x) |≤C for all x∈ [ a,b ]. This follows from the Mean Value Theorem because, given any x, y∈ [ a,b ], there exists z between x and y such that |f ( x) -f ( y) | =|f ' ( z) ||x- y|≤C|x- y|.

The function fμ : [ 0,1] → [ 0,1] has always a fixed point at the origin. For μ>1, there is another fixed point pμ >0. In fact, if we solve fμ ( p) =p for p, we find that this fixed point is pμ =( μ-1 ) /μ.

Sarkovkii's theorem is sharp. There are functions which have periodic points of period k and no periodic points of smaller period according to Sarkovskii's ordering. For instance, gives the following example of a function that has a periodic point of period 5 and no periodic point of period 3.

The periodic orbit of period 5 is { 1, 3, 4, 2, 5, 1, …} . To prove that f has no periodic point of period 3, we note that f ∘ 3 ( [ 1,2 ] ) =[ 2,5 ] , f ∘ 3 ( [ 2,3 ] ) =[ 3,4 ] and f ∘ 3 ( [ 4,5 ] ) =[ 1,4 ] . Thus, f cannot have a periodic point of period 3 in the intervals [ 1,3 ] and [ 4,5 ] . Since f : [ 3,4 ] → [ 2,4 ] , f : [ 2,4 ] → [ 2,5 ] and f : [ 2,5 ] → [ 1,5 ] are decreasing, we have that f ∘ 3 ( [ 3,4 ] ) =[ 1,5 ] is decreasing. Thus f ∘ 3 has a unique fixed point in the interval [ 3,4 ] . But this fixed point is the fixed point of f. Therefore, it is not a periodic point of period 3.

Sarkovskii's theorem is only true for continuous functions f: ℝ→ℝ. In the section of the document , we will give an example of a function that has periodic points of period 3 and no other periodic points.

If we look at the cobweb graph of fμ for some values μ< 4, we may think that the behaviour of the DDS generated by fμ is chaotic because the period of the attracting periodic orbit { xn } n≥ 0 is very large and the points of this orbit seems to be bouncing randomly all over a region of the interval ] 0,1 ] . For instance, the reader should use the graphical application above to draw the cobweb graph for the DDS generated by fμ with μ= 3.9. A very large number of iterations should be performed. What we observe is far from being chaotic. We have a periodic orbit with a very large period, but all the other non-periodic orbits converge to it. We need a precise definition of chaotic behaviour for a DDS.
