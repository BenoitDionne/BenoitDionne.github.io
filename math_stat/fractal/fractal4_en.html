Mandelbrot and Julia Sets

We cannot end our little introduction to fractal geometry without mentioning the figure that started all the excitement about computer generated fractal images; namely, the Mandelbrot set .

In the previous document, we have presented some properties of the logistic map. More precisely, we have looked at the iterations of the real valued function fµ defined by fµ(x) = µ x(1-x) for x ∈ [0,1] as µ varies.

The logical next step is to consider the iterations of complex valued functions defined on the complex plane.

Julia Sets

The Julia sets are generated by iterations of the simple complex valued function f defined by

fc(z) = z2 + c ,

where c and z are complex numbers. More precisely, given c, let M be the set of all points z0 in the complex plane such that the sequence

z0, z1 = fc(z0), z2 = fc(z1), z3 = fc(z2), ...

is unbounded.

Definition
The Julia Set associated to c is the boundary of M.

If a point of the sequence starting with z0 is outside the circle of radius r = max{|c|,2} centred at the origin, then the sequence z0, z1, z2, ... is unbounded (the reader should prove this claim). Therefore, z0 is in M. Because of this property, we say that a point z0 does not belong to M if after a chosen number of iterations, the sequence starting with z0 is still inside the circle of radius r centred at the origin. If we choose a large number of initial points z0, we should get an accurate image of the Julia set. Obviously, the quality of the picture is limited by the number of pixels on the computer screen. In particular, if M is highly disconnected (i.e. is formed of many little pieces), we may get an almost empty image if most of the points in M are not associated to pixels on the computer screen.

Mandelbrot Set

The Mandelbrot set is the set of all points c in the complex plane such that the following sequence is bounded.

c, f0(c) = c^2 + c, f02(c) = f0(f0(c)) = (c^2 + c)^2 + c,
f03(c) = f0(f0(f0(c))) = ((c^2 + c)^2 + c)^2 + c, ...

If a point of the sequence c, f0(c), f02(c), f03(c), ... falls outside the circle of radius r centred at the origin defined in the section about Julia sets above, then the sequence is unbounded. Therefore, this value of c is not in the Mandelbrot set. As for the Julia sets, this is the rule that we have implemented in the graphical application above.

We may zoom in on a region of the Mandelbrot set by clicking with the left button of our mouse on the region of interest in the figure.

We can also produce the Julia set associated to a value of the Mandelbrot set by clicking with the left button of our mouse on the point of interest in the Mandelbrot set when holding the Alt key. The associated Julia set is displayed in the window of the graphical Application for the Julia sets above.

The Mandelbrot set is also called the gingerbread man. The Mandelbrot set looks like a gingerbread man cookie, doesn't it? If we zoom in judiciously, we will see smaller and smaller gingerbread men. This is comparable to the self-similarity that we have observed in the images generated with IFS.

There is a beautiful relation between the Mandelbrot set and the Julia sets.

Proposition
The Mandelbrot set is the set of all points c that produce a connected Julia sets; namely, the set can be drawn without lifting the pen though it may take an infinite among of time to draw it.

There are many fascinating mathematical questions that came up from the study of the Mandelbrot set and Julia sets. Many of them are still unsolved.
