Systèmes dynamiques discrets

Contenu

Notre introduction au chaos et aux fractales débute avec le plus simple système dynamique discret. Malgré sa simplicité, il illustre toute la complexité que le comportement d'un système dynamique discret peut exhiber.

Introduction aux systèmes dynamiques discrets

Soit f une fonction à valeurs réelles qui est définie sur la droite réelle. Étant donné un point x0, la formule

xn +1= f( xn ) , n=0,1,2,…

définit une suite { xn } n≥ 0= { x0 , x1 , x2 , …} . Cette suite est appelée l'orbite (positive) de x0 générée par f. Nous désignons par f ∘ n la composition f∘f∘ f∘ …∘f de n fois la fonction f. Ainsi, xn= f ∘ n ( x0 ) .

Définition: La fonction φ: ℕ×ℝ→ ℝ définie par φ ( n,x ) =f ∘ n ( x) est appelée un système dynamique discret (SDD) généré par la fonction f. La fonction f est appelée la fonction génératrice.

Certains points de la droite jouent un rôle particulièrement important dans l'étude des SDD.

Définition: Soit f: ℝ→ℝ. Un point p∈ℝ est un point fixe pour f si f ( p) =p. Un point p∈ℝ est un point périodique de période k pour f si f ∘ k ( p) =p et f ∘ j ( p) ≠p pour 0<j< k. Si p est un point périodique de période k, alors l'orbite { xn } n≥ 0. avec x0 =p est appelée une orbite périodique de période k.

Fonctions affines

Nous débutons avec l'étude des SDD générés par des fonctions génératrices affines f; c'est-à-dire, par des fonctions de la forme f ( x) =mx+b, où m est la pente de la droite qui représente le graphe de la fonction f et b est l'ordonnée à l'origine (l'intersection de cette droite avec l'axe des y). Malgré sa simplicité, cette fonction génératrice fournit une bonne base pour l'étude des SDD générés par des fonctions f plus générales comme nous allons voir plus tard.

Qu'arrive-t-il à l'orbite { xn } n≥ 0 si on change les valeurs de m et b? Nous invitons le lecteur à explorer à l'aide de l'application graphique ci-dessous le comportement des orbites { xn } n≥ 0. pour différentes valeurs de m et b, et pour différentes conditions initiales x0 .

L'application graphique ci-dessous dessine le graphe en forme de toile d'araignée du SDD généré par la fonction génératrice f choisie et pour la condition initiale x0 choisie. Le graphe en forme de toile d'araignée commence toujours au point ( x0, 0) .

  1. À partir de ( x0, 0) , nous traçons une droite verticale qui coupe le graphe de f au point ( x0, x1 ).
  2. À partir de ( x0, x1 ), nous traçons une droite horizontale qui coupe la droite y=x au point ( x1, x1 ).
  3. À partir de ( x1, x1 ), nous traçons une droite verticale qui coupe le graphe de f au point ( x1, x2 ).
  4. À partir de ( x1, x2 ), nous traçons une droite horizontal qui coupe la droite y=x au point ( x2, x2 ).
  5. À partir de ( x2, x2 ), nous traçons une droite verticale qui coupe le graphe de f au point ( x2, x3 ).
  6. Et ainsi de suite.

Quelles sont les conditions que f doit satisfaire pour garantir que l'orbite { xn } n≥ 0 converge vers le point fixe p lorsque n→∞ ? La réponse dépend seulement de la pente m.

Proposition: Soit f: ℝ→ℝ la fonction définit par f ( x) =mx+b.

  • Si |m|< 1, alors f a un point fixe unique p et toutes les orbites { xn } n≥ 0 convergent vers p lorsque n→∞ .
  • Si |m|> 1, alors f a un point fixe unique p mais aucune des orbites { xn } n≥ 0 converge vers p lorsque n→∞ sauf pour l'orbite constante qui début avec x0 =p.

La fonction Logistique

Une des plus simples fonctions génératrices non-affine est la fonction logistique. Par contre, nous montrons ci-dessous que le comportement des orbites générées par les itérations de cette fonction est loin d'être simple. La fonction logistique est la fonction fμ : ℝ→ℝ définie par

fμ (x ) =μx ( 1-x ) ,

où μ est un paramètre fixe mais arbitraire. Nous avons une famille de fonctions, une fonction pour chaque valeur de μ.

Les orbites { xn } n≥ 0 générées par fμ sont données par la formule suivante.

Théorème (Théorème du point fixe): Soit f : [ a,b ] → [ a,b ] . S'il existe une constante C<1 telle que |f ( x) -f ( y) |<C|x- y| pour tout x, y∈ [ a,b ], alors toutes les orbites { xn } n≥ 0. données par la formule xn+1 =f( xn ) pour n=0, 1,2, … et x0 ∈ [ a,b ] convergent vers un point fixe unique p∈ [ a,b ] pour f lorsque n→∞ .

Le théorème précédent est aussi vrai si l'intervalle [ a,b ] est remplacée par un espace métrique complet E et |f ( x) -f ( y) |<C|x- y| est remplacé par d ( f( x) ,f ( y) ) <Cd ( x,y ) où d: E×E→ [ 0,∞ [ est la métrique sur E. Ce théorème joue un rôle majeur dans les documents qui suivent La conclusion de ce théorème est aussi vrai si f : [ a,b ] → [ a,b ] est continument différentiable et il exists une constante C>0 telle que |f ' ( x) |≤C pour tout x∈ [ a,b ]. Cela découle du théorème des valeurs moyennes car, étant donné x, y∈ [ a,b ], il existe z entre x et y telle que |f ( x) -f ( y) | =|f ' ( z) ||x- y|≤C|x- y|.

La fonction fμ : [ 0,1] → [ 0,1] a toujours un point fixe à l'origine. Pour μ>1, elle a un autre point fixe pμ >0. En fait, si nous résolvons fμ ( p) =p pour p, nous obtenons que ce point fixe est pμ =( μ-1 ) /μ.

Le théorème de Sarkovskii est optimal. Il existe des fonctions qui ont des points périodique de période k et aucun point périodique de période plus petite selon l'ordre de Sarkovskii. Pour illustrer ce fait, donne l'exemple suivant d'une fonction qui a un point périodique de période 5 et aucun point périodique de période 3.

Pour démontrer que f n'a pas de point périodique de période 3, nous notons que f ∘ 3 ( [ 1,2 ] ) =[ 2,5 ] , f ∘ 3 ( [ 2,3 ] ) =[ 3,4 ] et f ∘ 3 ( [ 4,5 ] ) =[ 1,4 ] . Donc, f ne peut avoir de point périodique de période 3 dans les intervalles [ 1,3 ] et [ 4,5 ] . Puisque f : [ 3,4 ] → [ 2,4 ] , f : [ 2,4 ] → [ 2,5 ] et f : [ 2,5 ] → [ 1,5 ] sont décroissantes, nous avons que f ∘ 3 ( [ 3,4 ] ) =[ 1,5 ] est décroissante. Donc f ∘ 3 possède un seul point fixe dans l'intervalle [ 3,4 ] . Mais ce point fixe est le point fixe de f. Donc, il n'y a pas de point périodique de période 3.

Le théorème de Sarkovskii est seulement vrai pour les fonctions continues f: ℝ→ℝ. Dans la section du document , nous allons donner un exemple d'une fonction qui a des points périodiques de période 3 et aucun autre point périodique.

Si nous considérons le graphe en forme de toile d'araignée de fμ pour des valeurs μ< 4, nous pouvons imaginer que le comportement du SDD généré par fμ est chaotique car la période de l'orbite périodique attractive { xn } n≥ 0 est très grande et les points de cette orbite semblent rebondir aléatoirement sur toute une région de l'intervalle ] 0,1 ] . Par exemple, le lecteur devrait utiliser l'application graphique ci-dessus pour tracer le graphe en forme de toile d'araignée pour le SDD généré par fμ avec μ= 3.9. Un très grand nombre d'itérations doivent être exécutées. Ce que nous observons est très loin d'être chaotique. Nous avons une orbite périodique avec une très grande période, mais toutes les autres orbites non-périodiques convergent vers elle. Nous avons besoin d'une définition précise du comportement chaotique d'un SDD.
