Mandelbrot Set

We cannot end our little introduction to chaos and fractals without mentioning the figure that started all the excitement about computer generated fractal images; namely, the Mandelbrot set .

Mandelbrot Set

The Mandelbrot set is the set of all points c in the complex plane such that the following sequence is bounded.

c, f0(c) = c^2 + c, f02(c) = f0(f0(c)) = (c^2 + c)^2 + c,
f03(c) = f0(f0(f0(c))) = ((c^2 + c)^2 + c)^2 + c, ...

The following graphical application can be used to draw the Mandelbrot set. The points drawn in black form the Mandelbrot set.

If a point of the sequence c, f0(c), f02(c), f03(c), ... falls outside the circle of radius r centred at the origin defined in the section about Julia sets above, then the sequence is unbounded. Therefore, this value of c is not in the Mandelbrot set. As for the Julia sets, this is the rule that we have implemented in the graphical application above.

We may zoom in on a region of the Mandelbrot set by clicking with the left button of our mouse on the region of interest in the figure.

We can also produce the Julia set associated to a value of the Mandelbrot set by clicking with the left button of our mouse on the point of interest in the Mandelbrot set when holding the Alt key. The associated Julia set is displayed in the window of the graphical Application for the Julia sets below.

The Mandelbrot set is also called the gingerbread man. The Mandelbrot set looks like a gingerbread man cookie, doesn't it? If we zoom in judiciously, we will see smaller and smaller gingerbread men. This is comparable to the self-similarity that we have observed in the images generated with IFS.

There is a beautiful relation between the Mandelbrot set and the Julia sets.

Proposition
The Mandelbrot set is the set of all points c that produce a connected Julia sets; namely, the set can be drawn without lifting the pen though it may take an infinite among of time to draw it.

There are many fascinating mathematical questions that came up from the study of the Mandelbrot set and Julia sets. Many of them are still unsolved.
