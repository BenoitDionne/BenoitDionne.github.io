Fractal Dimensions

There is no clear definition of a fractal set. Benoit B. Mandelbrot (the father of Fractal Geometry) defines a fractal set as a set for which the Hausdorff dimension is strictly greater than the topological dimension. Some mathematicians will also request that the set had some self-similarity (this is the case for the Sierpinski gasket).

We only consider the notion of similarity dimension and Minkowski dimension.

Similarity Dimension

The similarity dimension of a set A is defined by the equation

Dimension = log(a) / log(1/s)

where a is the number of small sets similar to the original set and s is the scaling of the dimensions used to produce the small sets. For instance:

  • The similarity dimension of a straight line is 1. For s = 1/4 and a = 4, we get
    log(a)/log(1/s) = log(4)/log(4) = 1.
    We leave it to the reader to describe the (obvious) four functions of the IFS on the interval [0,1] whose limit after an infinite number of iterations is [0,1].
  • The similarity dimension of a cube is 3. for s = 1/2 and a = 8, we get
    log(a)/log(1/s) = log(8)/log(3) = log2(8) = 3.
    Again, we leave it to the reader to describe the (obvious) eight functions of the IFS on the cube [0,1]3 whose limit after an infinite number of iterations is [0,1]3.
  • The similarity dimension of the Sierpinski gasket is about 1.5850. For s = 1/2 and a = 3, we get
    log(a)/log(1/s) = log(3)/log(2) ∼ 1.5850.
    For s = 1/4 and a = 9, we get
    log(a)/log(1/s) = log(9)/log(4) ∼ 1.5850.

Minkowski Dimension

The Minkowski dimension of a set A is defined by the following formula.

Dimension = limµ->0 log(N(A,µ)) / log(1/µ) ,

where N(A,µ) is the smallest number of squares of side length µ > 0 needed to cover A.
