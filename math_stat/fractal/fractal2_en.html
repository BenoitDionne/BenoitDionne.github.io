In our study of DDS in the previous document, we have considered functions from ℝ to itself and computed iterations starting at an initial point. We now consider set valued functions acting on sets and compute iterations starting with an initial set.

Definition of Iterative Function Systems

This section is theoretical. Readers who do not have the mathematical background may skip this section and resume reading with the next section where we provide examples of fractals produced with the help of iterative function systems.

A metric space is a set E with a metric d:E×E → [0,∞[. We denote this metric space by (E,d). The distance between a point a ∈ E and a set B ⊂ E is defined by d(a,B) = inf{d(a,b) : b ∈ B}, and the distance from the set A ⊂ E to the set B ⊂ E is defined by d(A,B) = sup{d(a,B) : a ∈ A}.

We note that d(A,B) may not be equal to d(B,A).

Proposition: Suppose that the metric space (E,d) is complete; namely, every Cauchy sequence converges. Let Ec be the space of non-empty compact subsets of E. Then the function dc:Ec×Ec → [0,∞[ defined by

dc(A,B) = max{d(A,B),d(B,A)}

for all A,B ⊂ Ec is a metric on Ec. Moreover, the metric space (Ec,dc) is complete. The metric dc is called the Hausdorff distance or Hausdorff metric.

A proof of this proposition is found in the book by . Note that for a ∈ A and A,B ∈ Ec, we have that d(a,B) = min{d(a,b) : b ∈ B} < ∞ and d(A,B) = max{d(a,B) : a ∈ A} < ∞ because A and B are compact sets.

Proposition Ⅰ: Suppose that {Aj}1≤j≤J and {Bj}1≤j≤J are two collections of elements in Ec. Then dc(∪1≤j≤J Aj,∪1≤j≤J Bj) ≤ max1≤j≤J dc(Aj,Bj).

Proof: We have that

d(A ∪ B,P) = max{d(u,P) : u ∈ A ∪ B}
= max{max{d(u,P) : u ∈ A},max{d(u,P) : u ∈ B}} = max{d(A,P),d(B,P)}

for all A,B,P ∈ Ec. Moreover, since

d(a,P ∪ Q) = min{d(a,u) : u ∈ P ∪ Q}
= min{min{d(a,u) : u ∈ P},min{d(a,u) : u ∈ Q} = min{d(a,P),d(a,Q)}

for all a ∈ E and P,Q ∈ Ec, we get that

d(A,P ∪ Q) = max{d(a,P ∪ Q) : a ∈ A}
= max{min{d(a,P),d(a,Q)} : a ∈ A} ≤ max{d(a,P) : a ∈ A} = d(A,P)

and similarly that d(A,P ∪ Q) ≤ d(A,Q) for all A,P,Q ∈ Ec. It follows that

d(A ∪ B,P ∪ Q) ≤ max{d(A,P ∪ Q),d(B,P ∪ Q)} ≤ max{d(A,P),d(B,Q)}

for all A,B,P,Q ∈ Ec. We finally conclude that

dc(A ∪ B,P ∪ Q) = max{d(A ∪ B,P ∪ Q),d(P ∪ Q,A ∪ B)}
≤ max{max{d(A,P),d(B,Q)},max{d(P,A),d(Q,B)}
= max{max{d(A,P),d(P,A)},max{d(B,Q),d(Q,B)}
= max{dc(A,P),dc(B,Q)}

for all A,B,P,Q ∈ Ec. This proves the proposition for J = 2. A simple induction on J completes the proof of the proposition.  ∎

A function f: E → E is a contraction if there exists a number C such that 0 ≤ C < 1 and d(f(x),f(y)) ≤ C d(x,y) for all x,y ∈ E. A contraction is obviously a continuous function. The value C is called a contraction factor.

If f: E → E is a continuous function, then it maps compact sets to compact sets. Hence, the function f also induces a function f: Ec → Ec in a natural way. Suppose that {fj}1≤j≤J is a collection of continuous functions fj: E → E, we define a function fc: Ec → Ec by

fc(A) = ⋃1≤j≤J fj(A)

for all A ∈ Ec. This function is well defined because the finite union of compact sets is a compact set.

Definition: A (hyperbolic) iterative function system (IFS) on a complete metric space (Ec,dc) is a collection {fj}1≤j≤J of contractions from E to itself.

Proposition Ⅱ: Suppose that {fj}1≤j≤J is an IFS where each function fj is a contraction with a contraction factor Cj. Then the function fc: Ec → Ec is a contraction with a contraction factor C = max1≤j≤J Cj.

Proof: Given A,B ∈ Ec, we have that d(fj(a),fj(b)) ≤ Cj d(a,b) for all a ∈ A and b ∈ B. Hence

d(fj(a),fj(B)) = min{d(fj(a),fj(b)) : b ∈ B}
≤ min{Cj d(a,b) : b ∈ B} = Cj min{d(a,b) : b ∈ B}
= Cj d(a,B)

for all a ∈ A and so

d(fj(A),fj(B)) = max{d(fj(a),fj(B)) : a ∈ A}
≤ max{Cj d(a,B) : a ∈ A} = Cj max{d(a,B) : a ∈ A}
= Cj d(A,B) .

Similarly, we have that d(fj(B),fj(A)) ≤ Cj d(B,A). Thus dc(fj(A),fj(B)) ≤ Cj dc(A,B). It follows from that

dc(fc(A),fc(B)) = dc(∪1≤j≤J fj(A),∪1≤j≤J fj(B))
≤ max1≤j≤J{dc(fj(A),fj(B)) ≤ max1≤j≤J Cj dc(A,B) = C dc(A,B) .  ∎

Theorem Ⅲ: If (E,d) is a complete metric space and {fj}1≤j≤J is a (hyperbolic) IFS, then fc: Ec → Ec has a unique fixed point; namely, there exists a unique set K ∈ Ec such that fc(K) = K. Moreover, for all sets A0 ∈ Ec, the sequence of sets {Ai}i≥0 defined by Ai+1 = fc(Ai) converges to K according to the Hausdorff metric dc as i → ∞.

The previous theorem is a direct consequence of the Contraction Mapping Theorem because (Ec,dc) is a complete metric space and fc: Ec → Ec is a contraction.

Examples

In the examples that we consider below, E is the real plane and d is the Euclidean metric. The fractals that we draw are the fixed points of functions fc: Ec → Ec induced by some IFS {fj}1≤j≤J. The challenge is to choose the IFS that produces the fractal that we want. We address this issue in the section below.

The first example is the example of the must famous IFS.

Example A - Sierpinski Triangle: The following figure shows the famous Sierpinski gasket or Sierpinski triangle.

It is a typical example of a fractal. We give a definition of fractals in the document . We do not need this definition right now.

The Sierpinski triangle is the fixed point of the function fc:(ℝ2)c → (ℝ2)c induced by the IFS {fj}1≤j≤3 where

f1( x → ) = (x1/2,x2/2 + 1/2) ,
f2( x → ) = (x1/2 + 1/2,x2/2) ,
f3( x → ) = (x1/2,x2/2) .

f1 and f2 are dilatations followed by translations. f3 is only a dilatation. We now explain in a graphical way how the Sierpinski triangle is drawn using the IFS composed of the three functions described above.

  • First, we choose any initial set. In the present case, we choose the filled triangle defined by T = { x → : x1,x2 ≥ 0 and x1 + x2 ≤ 1}.
  • Second, we shrink the filled triangle T to a quarter of its original size (a dilatation by 1/2) and translate it vertically by 0.5 (a translation by (0,1/2)). This is the work of the function f1.
  • Third, we shrink the filled triangle T to a quarter of its original size (a dilatation by 1/2) and translate it horizontally by 0.5 (a translation by (1/2,0)). This is the work of the function f2.
  • Fourth, we shrink the filled triangle T to a quarter of its original size only (a dilatation by 1/2). This is the work of the function f3.

This four steps are illustrated in the figure below.

We repeat the second, third and fourth steps above with the new set formed of three filled triangles. The next figure illustrates the second iteration of the second, third and fourth step described above.

We repeat this procedure until we are happy with the figure that we get. Usually, we stop when we can no longer observe any variation in the figure.

As we mentioned in the theoretical section above, independently of the set of points that we choose initially, we always get the Sierpinski triangle after an infinite number of iterations.

Adaptive Cut Method

This method to draw the fixed point of the function fc induced by an IFS has been proposed by .

We assume in this section that (E,d) = (ℝ2,d) where d is the Euclidean distance d( x → , y → ) = ((x2-x1)2+(y2-y1)2)1/2 for x → , y → ∈ ℝ2. This assumption simplifies the presentation but a similar presentation can be done for any complete metric space (E,d).

Suppose that {fj}1≤j≤J is an IFS, fc is the function induced by this IFS and K ∈ (ℝ2)c is the fixed point of the function fc. Given A0 ∈ Ec and ε > 0, our goal is to find a set A ∈ (ℝ2)c such that dc(A,K) ≤ ε. Since dc(An,K) → 0 as n → ∞, we can take A = An for n large enough. However, computing the iterations An+1 = fc(An) for n = 0,1,2,... can be very demanding in term of memory space on a computer. We explain below how to find a set A that may not be exactly one of the sets An but nevertheless satisfies dc(A,K) ≤ ε and requires less memory space on the computer.

If we look closely at the action of the iterations of fc, then we find that An = (fc)∘n(A0) is the union of the sets Vj1,j2,...,jn = fj1∘fj2 ... ∘fjn(A0) for 1 ≤ ji ≤ J. The sets Vj1,j2,j3 for the IFS associated to the Sierpinski triangle are illustrated in the figure below. To draw this figure, we have assumed that the set A0 is the filled triangle with vertices at (0,0), (1,0) and (0,1).

We assume that K ⊂ A0 where K is the the fixed point of fc.

  • If diam(Vj1,j2,...,jn) < ε and x → ∈ Vj1,j2,...,jn, then all the other points in Vj1,j2,...,jn are at a distance less than ε of x → . There is therefore no need to find the sets Vj1,j2,...,jn+1,... since they are subsets of Vj1,j2,...,jn.
  • If diam(Vj1,j2,...,jn) ≥ ε, then we consider the sets Vj1,j2,...,jn,jn+1 = fj1∘fj2 ... ∘fjn+1(A0) for jn+1 = 1,2,...,J.

We illustrate this situation with the set V1,1 in pink in the figure above. The IFS associated to the Sierpinski triangle is not a very good example of the procedure above because all the functions fj of the IFS have the same contraction factor of 1/2. Thus, if diam(Vj1,j2,...,jn) < ε for one sequence of n indices, then diam(Vj1,j2,...,jn) < ε for all sequences of n indices. In general, the functions fj that form an IFS do not have all the same contraction factor. The IFS for the fern above is one such example.

We claim that after a finite number of iterations of the procedure above, we get sets Vj1,j2,...,jn of diameters less than ε such that their union covers K. To prove this claim, suppose that Cj1,j2,...,jn is a contraction factor for fj1∘fj2 ... ∘fjn. In particular, Cj is a contraction factor for fj with 1 ≤ j ≤ J. Then diam(Vj1,j2,...,jn) ≤ Cj1,j2,...,jn diam(A0). Using the induction principle, we get that

d(fj1∘fj2 ... ∘fjn( x → ),fj1∘fj2 ... ∘fjn( y → )) ≤ Cj1Cj2 ... Cjnd( x → , y → )

for all x → , y → ∈ ℝ2. Thus diam(Vj1,j2,...,jn) ≤ Cj1Cj2 ... Cjndiam(A0). Hence, we may assume that Cj1,j2,...,jn ≤ Cj1Cj2 ... Cjn ≤ (max1≤j≤J Cj)n. Since 0 ≤ Cj < 1 for 1 ≤ j ≤ J, we have that Cj1,j2,...,jn → 0 as n → ∞. Thus, diam(Vj1,j2,...,jn) → 0 as n → ∞. This result proves that the number of iterations of the procedure above is finite because An → K as n → ∞ with respect to the Hausdorff measure and K is compact. Thus, K can be covered by a finite number of sets of the form Vj1,j2,...,jn and diameter ε/2 for instance. Since K is the fixed point of fc, the union of the sets Vj1,j2,...,jn covers K.

Let S be the set of all vectors of the form (j1,j2,...,jn) such that diam(Vj1,j2,...,jn) < ε that we obtained with the procedure above. The set S is a finite set. Given x → ∈ K, let A = {fj1∘fj2 ... ∘fjn( x → ) ∈ Vj1,j2,...,jn : (j1,j2,...,jn) ∈ S}. We have by construction that dc(A,K) ≤ ε.

There are two issues that come out of the previous paragraph. First, how can we find x → ∈ K? It suffices to take a fixed point x of a function fj of the IFS. The functions fj that we consider are of the form fj( x → ) = Mj x → + b → j where Mj is a 2×2 matrix and b → j is a column vector. It is easy to solve the linear system of equations Mj x → + b → j = x → to get a fixed point of fj.

The second issue is how to compute the diameter of a set Vj1,j2,...,jn? The answer is that we do not computer this diameter but we compute instead the smallest upper bound to this diameter that we can find. Since diam(j1,j2,...,jn) ≤ Cj1,j2,...,jn diam(A0), instead of testing for diam(Vj1,j2,...,jn) < ε, we test for Cj1,j2,...,jndiam(A0) < ε. If Cj1,j2,...,jndiam(A0) ≥ ε, then we assume that diam(Vj1,j2,...,jn) ≥ ε though we may have that diam(Vj1,j2,...,jn) < ε. Using this approach to estimate diam(Vj1,j2,...,jn) may imply a few more iterations of the procedure above than theoretically expected but it is still generally less demanding in term of computer time than trying to compute directly the diameters of the sets Vj1,j2,...,jn. We therefore need to find the smallest contraction factors Cj1,j2,...,jn that we can. We do not want to greatly over-estimate these contraction factors because this will imply extra iterations of the procedure above and therefore a larger set S than necessary. As the next example shows, using Cj1,j2,...,jn = Cj1Cj2 ... Cjn is not a good idea.

Example: Suppose that f1( x → ) = M1 x → + b → 1 with A1 = ( μ   0 0   ν ) and f2( x → ) = M2 x → + b → 2 with A2 = ( ν   0 0   μ ) for some numbers μ < ν. Then

d(f1( x → ),f1( y → )) = (μ2(x1-y1)2 + ν2(x2-y2)2)1/2
≤ (ν2(x1-y1)2 + ν2(x2-y2)2)1/2 =|ν| d( x → , y → )

for all x → , y → ∈ ℝ2 with an equality when x1 = y1. Thus C1 = |ν| is the smallest contraction factor for f1. Similarly, C2 = |ν| is the smallest contraction factor for f2. Therefore, if we use C1,2 = C1C2, then we get C1,2 = ν2. However, f1∘f1( x → ) = M1,2 x → + b → 1,2 where M1,2 = M1M2 = ( μν   0 0   μν ) and b1,2 = M1b2 + b1. Hence, the smallest contraction factor for f1∘f2 is |μν|, a value that can be a lot smaller than ν2. For instance, with μ = 0.01 and ν = 0.9, we get |μν| = 0.009 < 0.81 = ν2. Thus ν2 is 90 times bigger than the smallest contraction factor for f1∘f2.

To estimate the smallest contraction factor of fj1∘fj2 ... ∘fjn, we therefore need to compute Mj1,j2,...,jn = Mj1Mj2 ... Mjn. Suppose that Mj1,j2,...,jn = ( α   β γ   δ ) for some values α,β,γ,δ ∈ ℝ. It is shown in the classical textbook by that the smallest contraction factor of fj1∘fj2 ... ∘fjn is at most equal to 2 max{|α|,|β|,|γ|,|δ|}. We may use this value as an estimate of the smallest contraction factor of fj1∘fj2 ... ∘fjn.

Example (continued): In the previous example, we have that M1,2 = ( μν   0 0   μν ) . Thus α = δ = μν and β = γ = 0. Hence 2 max{|α|,|β|,|γ|,|δ|} = 2|μν|. This value is only twice the smallest contraction factor of f1∘f2.

It is proved in linear algebra that the smallest contraction factor of the function f( x → ) = M x → + b is the largest singular value of M; namely, max{(λ)1/2 : λ is an eigenvalue of MMT}. This is obviously the best method to estimate the smallest contraction factor of fj1∘fj2 ... ∘fjn if we are ready to accept the extra computer time to evaluate the singular eigenvalues of Mj1,j2,...,jn.

There is a third problem that we have ignored so far but cannot ignore to implement the adaptive cut method. We have assume that A0 ⊃ K in the discussion above. But we do not know K. So, how can we choose A0 ⊃ K? In fact, we assume that A0 = K and choose to the better of our knowledge a value for diam(K), the only information needed.

Remark: The adaptive cut method is implemented in the Matlab function ifs_adaptive that is given in the section of the document in Matlab.

The Chaos Game

Example: There is another method to draw the Sierpinski triangle using a random number generator. We choose a point x0 in the plane. For each value of n > 0, we use the computer number generator to select a number r ∈ [0,1] and set

⎧ f1( x → n-1) if r ≤ 1/3
x → n = ⎨ f2( x → n-1) if 1/3 < r ≤ 2/3
⎩ f3( x → n-1) if r > 2/3

If we plot the points of the finite sequence { x → n}0<n≤N where N is very large, we get the shadow of the Sierpinski triangle. To get a better image, it is preferable to start plotting the points xn from a value of n a little larger then 0. The first transient points are usually not very closed to the set representing the Sierpinski triangle. The number of iterations N must be very large and the random number generator of the computer must be really ... really good. The following image of the Sierpinski triangle was produced with N = 20,000 iterations of the procedure above starting from the point x → 0 = (1,0) which is a point of the Sierpinski triangle.

The result is not bad.

This method to draw the Sierpinski triangle can obviously be generalized to draw the fixed point K of the function fc induced by an IFS {fj}1≤j≤J. We choose a point x0 in the plane. For each value of n > 0, we use the computer number generator to select a number r ∈ [0,1] and set

⎧ f1( x → n-1) if r ≤ q1
⎪ f2( x → n-1) if q1 < r ≤ q2
x → n = ⎨ f3( x → n-1) if q2 < r ≤ q3
⎪    ⋮
⎩ fJ( x → n-1) if r > qJ-1

If we plot the points of the finite sequence { x → n}0<n≤N where N is very large, we get the shadow of the fixed point K. This method to draw the fixed point of the function fc induced by an IFS is called the chaos game. Assuming that the random generator of the computer has a uniform distribution, then at each iteration,

  • p1 = q1 is the probability of selecting the function f1,
  • p2 = q2 - q1 is the probability of selecting the function f2,
  • p3 = q3 - q2 is the probability of selecting the function f3,
  • ... ,
  • pJ-1 = qJ-1 - qj-2 is the probability of selecting the function fJ-1, and
  • pJ = 1 - qJ-1 is the probability of selecting the function fJ.

This method complicates the because, in addition to the problem of determining the function fj that compose the IFS, we have just added the problem of determining the values of the probabilities pj. Nevertheless, This method is very often used to draw the fixed point K because it requires little memory space on the computer, only computing time.

Definition: An IFS with probabilities is a pair ({fj}1≤j≤J,{pj}1≤j≤J) where {fj}1≤j≤J is an IFS and {pj}1≤j≤J is a collection of probabilities for the chaos game.

In the example for the Sierpinski triangle above, we have J = 3 and we have selected q1 = 1/3 and q2 = 2/3. We have simply assumed that at each iteration the functions fj had an equal probability of 1/3 to be selected. The image of the Sierpinski triangle is not bad. Assuming that the IFS {fj}1≤j≤J is known (we will come back on the subject of selecting the IFS in the section below), how can we choose the best probability distribution for the random selection of the function fj at each iteration of the chaos game? There is a theoretical answer to this question given in the Section below. For the applications, we present two partial answers below.

Method A

The functions fj that we consider for our IFS are of the form fj( x → ) = Mj x → + bj for a given 2×2 matrix Mj and vector bj. If we use the Euclidean norm on ℝ2, then we have that area(fj(A)) = |det(Mj)| area(A) for all sets A ⊂ ℝ2. Let Dj = |det(Mj)| for 1 ≤j ≤ J. We select pj = max{δ,Dj} (∑1≤i≤J max{δ,Di})-1 for j = 1,2,...,J where δ is a very small fixed positive value. Thus, at each iteration, the probability of selecting the function fj is pj. This small value δ is introduced to avoid the situation where the probability of selecting a function fj would be null because det(Mj) = 0 as it is the case for instance with the function f1 of the IFS associated to the fern above. This method to determine the values of the pj is good when the IFS satisfies the open set condition defined in the section of the document . Roughly, this condition ensures that fj1(K) ∩ fj2(K) is negligible for j1 ≠ j2. The IFS associated to the Sierpinski triangle satisfies the open set condition but the IFS associated to the fern above does not satisfy this condition.

Method B

Given ε > 0 and x → ∈ K, if we use the adaptive cut method to draw the fixed point of the function fc induced by an IFS, we get the set A = {fj1∘fj2 ... ∘fjn( x → ) : (j1,j2,...,jn) ∈ S} where S is a finite set of vectors of the form (j1,j2,...,jn). We have that dc(A,K) ≤ ε. Let N be the number of points in A, and Nj be the number of points in A ∩ fj(K) for 1 ≤ j ≤ J. We set pj ≈ Nj/N for j = 1,2,...,J. We use the symbol of approximation instead of the equality sign in the previous formula because we may have that fj1(K) ∩ fj2(K) ≠ ∅ for some j1 ≠ j2. Therefore, some of the Nj may have to be slightly modified to ensure that ∑1≤j≤J Nj = N.

Remark - Probabilistic System: For the Sierpinski triangle, there is another probabilistic game to draw the Sierpinski triangle. Iterative Function Systems with Condensation

As in the previous sections, we assume that (E,d) is a complete metric space. A function f0: Ec → Ec defined by fc(A) = Q for all A ∈ Ec and some fixed element Q ∈ Ec is called a condensation function and the set Q is called the condensation set.

Definition: Suppose that {fj}1≤j≤J is an IFS and that f0: Ec → Ec is a condensation function. The collection of functions {fj}0≤j≤J is called an IFS with condensation.

We now define fcc: Ec → Ec by

fcc(A) = f0(A) ∪ fc(A) = ⋃0≤j≤J fj(A)

for all A ∈ Ec.

Proposition: Suppose that (E,d) is a complete metric space and that {fj}1≤j≤J is an IFS where each function fj is a contraction with a contraction factor Cj. If f0: Ec → Ec is a condensation function with condensation set Q, then fcc: Ec → Ec is a contraction with a contraction factor C = max1≤j≤J Cj as fc.

Proof: The proof is identical to the proof of except that the last line of the proof is now

dc(fc(A),fc(B)) = dc(∪0≤j≤J fj(A),∪0≤j≤J fj(B))
≤ max0≤j≤J{dc(fj(A),fj(B)) = max1≤j≤J{dc(fj(A),fj(B))
≤ max1≤j≤J Cj dc(A,B) = C dc(A,B)

because f0(A) = f0(B) = Q. ∎

We have the following version of .

Theorem: If (E,d) is a complete metric space and {fj}0≤j≤J is an IFS with condensation, then fcc: Ec → Ec has a unique fixed point; namely, there exists a unique set K ⊂ Ec such that fcc(K) = K. Moreover, for all sets A0 ∈ Ec, the sequence of sets {Ai}i≥0 defined by Ai+1 = fcc(Ai) converges to K according to the Hausdorff metric dc as i → ∞.

Dependence on a Parameter

It is interesting to note that if an IFS {fj}1≤j≤J depends continuously on a parameter, then the fixed point of fc induced by this IFS varies continuously with respect to this parameter. More precisely, we have the following result.

Theorem: Suppose that (E,d and ( E ˆ , d ˆ ) are two metric spaces with (E,d) complete and E ˆ compact. Moreover, suppose that {fj}1≤j≤J is a collection of functions such that, for each j, the function fj: E× E ˆ → E is a continuous function that satisfies d(fj(x,v),fj(y,v)) ≤ Cj(v) d(x,y) for all x,y ∈ E and v ∈ E ˆ , where Cj: E ˆ → ]0,1[ is a continuous function. Let fc: Ec× E ˆ → Ec be the function defined by fc(A,v) = ∪1≤j≤J fj(A,v) for all A ∈ Ec and v ∈ E ˆ . If Kv is the fixed point of fvc ≡ fc(·,v), then dc(Kv,Kw) → 0 as v → w; namely, as d ˆ (v,w) → 0 with w fixed.

Proof: Note that, for each v ∈ E ˆ , the collection {fj(·,v)}1≤j≤J is an IFS and the contraction factor of the function fvc induced by this IFS is C(v) = max1≤j≤J Cj(v) ∈ ]0,1[.

We first prove that fc: Ec× E ˆ → Ec is continuous with respect to it second variable. Choose ε > 0. Given v,w ∈ E ˆ and A ∈ Ec, we have that

d(fj(A,v),fj(A,w))
= max{min{ d(fj(a,v),fj(â,w)) : â ∈ A} : a ∈ A}
≤ max{min{ d(fj(a,v),fj(â,v)) + d(fj(â,v),fj(â,w)) : â ∈ A} : a ∈ A} .

The function fj is uniformly continuous on the compact set A× E ˆ because it is continuous on this set by assumption. Thus, there exists δj such that d(fj(â,v),fj(â,w)) < ε for all â ∈ A if d ˆ (v,w) < δj. Hence,

d(fj(A,v),fj(A,w))
≤ max{min{ d(fj(a,v),fj(â,v)) : â ∈ A} : a ∈ A} + ε
= d(fj(A,v),fj(A,v)) + ε = ε .

for d ˆ (v,w) < δj. Similarly, we get that d(fj(A,w),fj(A,v)) ≤ ε for d ˆ (v,w) < δj. Thus dc(fj(A,v),fj(A,w)) ≤ ε for d ˆ (v,w) < δj. If we take δ = min1≤j≤J δj, then it follows from that

dc(fc(A,v),fc(A,w)) = dc(∪1≤j≤J fj(A,v),∪1≤j≤J fj(A,w))
≤ max1≤j≤J dc(fj(A,v),fj(A,w)) ≤ ε

for d ˆ (v,w) < δ.

Since Cj is a continuous function on the compact set E ˆ , there exists vj ∈ E ˆ such that 0 < maxv∈ E ˆ Cj(v) ≤ Cj(vj). Let C = max1≤j≤J Cj(vj). Then C ∈ ]0,1[ and d(fj(x,v),fj(y,v)) ≤ C d(x,y) for all x,y ∈ E and v ∈ E ˆ . Proceeding as we did in the proof of , we get that dc(fc(A,v),fc(B,v)) ≤ C dc(A,B) for all A,B ∈ Ec and v ∈ E ˆ .

Given v,w ∈ E ˆ , we have that

dc(Kv,Kw) = dc(fc(Kv,v),fc(Kw,w))
≤ dc(fc(Kv,v),fc(Kw,v)) + dc(fc(Kw,v),fc(Kw,w))
≤ C dc(Kv,Kw) + dc(fc(Kw,v),fc(Kw,w)) .

Therefore

dc(Kv,Kw) ≤ (1 - C)-1 dc(fc(Kw,v),fc(Kw,w)) → 0

as d ˆ (v,w) → 0 with w fixed. ∎

It follows from the previous theorem that, with enough computer time, we could create animation videos using fractals. For instance, a leave blows by the wind.

Network of Iterative Function Systems

As usual, we assume that (E,d) is a complete metric space. A possible metric d ˆ on the product space E×E is defined by d ˆ ((x,y),(u,v)) = max{d(x,u).d(y,v)} for all (x,y),(u,v) ∈ E×E. We have that (E×E, d ˆ ) is a complete metric space. Similarly, a possible metric d ˆ c on the product space Ec×Ec is defined by d ˆ c((A×B,U×V) = max{dc(A,U).dc(B,V)} for all A×B,U×V ∈ Ec×Ec. We also have that (Ec×Ec, d ˆ c) is a complete metric space.

Suppose that {fj[1]}1≤j≤J[1] and {fj[2]}1≤j≤J[2] are two IFS where the functions fj[k]:E → E are contractions with contractions factor 0 ≤ Cj[k] < 1 for k = 1,2 and all j. For k = 1,2, suppose that S1[k],S2[k] ⊂ {1,2,...,J[k]} are two subsets such that S1[k] ∩ S2[k] = ∅ and S1[k] ∪ S2[k] = {1,2,...,J[k]}. We define a function f ˆ c = f ˆ 1c× f ˆ 2c : Ec×Ec → Ec×Ec as it follows.

f ˆ 1c(A×B) = ∪j∈S1[1] fj[1](A) ∪ ∪j∈S2[1] fj[1](B)
f ˆ 2c(A×B) = ∪j∈S1[2] fj[2](A) ∪ ∪j∈S2[2] fj[2](B)

for all A×B ∈ Ec×Ec. It can be proved that f ˆ c satisfies the contraction mapping theorem. Thus, we have a theorem similar to .

Theorem: If (E,d) is a complete metric space, and {fj[1]}1≤j≤J[1] and {fj[2]}1≤j≤J[2] are two (hyperbolic) IFS, then f ˆ c: Ec×Ec → Ec×Ec has a unique fixed point; namely, there exists a unique set K× K ∼ ∈ Ec×Ec such that f ˆ c(K× K ∼ ) = K× K ∼ . Moreover, for all sets A0×B0 ∈ Ec×Ec, the sequence of sets {Ai×Bi}i≥0 defined by Ai+1×Bi+1 = f ˆ c(Ai×Bi) converges to K× K ∼ according to the Hausdorff metric d ˆ c as i → ∞.

Example: Suppose that {fj[1]}1≤j≤4 and {fj[2]}1≤j≤3 are two IFS. Moreover, suppose that S1[1] = {1,2}, S2[1] = {3,4}, S1[2] = {2,3} and S2[2] = {1}. We get the function f ˆ c = f ˆ 1c× f ˆ 2c : Ec×Ec → Ec×Ec defined by

f ˆ 1c(A×B) = f1[1](A) ∪ f2[1](A) ∪ f3[1](B) ∪ f4[1](B)
f ˆ 2c(A×B) = f2[2](A) ∪ f3[2](A) ∪ f1[2](B)

for all A×B ∈ Ec×Ec. This function f ˆ c is represented by the following graph.

Inverse Problem for Iterative Function Systems

Most of the IFS that we have presented in the previous sections come from the books listed in the at the end of this document. It is intuitively easy to create IFS to generate figures like the Sierpinski triangle. But how can we find an IFS that generates a flower for instance? Suppose that a compact set L ⊂ ℝ2 represents some figure that we would like to generate with an IFS. The next theorem gives an upper bound on the Hausdorff distance between the set L and the fixed point K of the function fc induced by an IFS. This theorem does not give us an IFS to generate the set L but it at least allows us to test if an IFS generates a set K closed to the set L.

Theorem (Collage): Suppose that (E,d) is a complete metric space and that L ∈ Ec. If {fj}1≤j≤J is an IFS with a contraction factor C < 1 such that dc(L,fc(L)) ≤ ε, then dc(L,K) ≤ ε/(1-C) where K is the fixed point of the function fc induced by the IFS.

This theorem is nothing else than a reformulation of a well know result about contractions on complete metric spaces.

Proposition Ⅳ; Suppose that (E,d) is a complete metric space and that f:E → E is a contraction with a contraction factor C ∈ ]0,1[. If p ∈ E is the fixed point of f, then d(x,p) ≤ (1-C)-1 d(x,f(x)) for all x ∈ E.

The problem of finding an IFS that generates a given compact set L ⊂ ℝn is known as the inverse problem for IFS. This is not an easy problem to solve. Using IFS for image compression is one of the main motivations to develop efficient algorithms to solve the inverse problem for IFS. A readable introduction to this subject is given by .

Measures on Fractals

For this section, we assume that the reader has a basic knowledge of measure theory. This section illustrates the role that measure theory plays in the study of IFS with probabilities. This is the entrance door to the use of IFS for neural networks, image compression, and so on.

Definition: Suppose that μ is a Borel measure on the compact metric space (E,d). The measure μ is said to be normalized if μ(E) = 1.

The reader may find a little bit of information about measure, measurable sets and the Borel algebra in the section of the document .

Proposition: Suppose that (E,d) is a compact metric space. Let 𝓑 be the collection of all normalized Borel measures on E. The function d𝓑 : 𝓑×𝓑 → [0,∞[ defined by

d𝓑(μ,ν) = sup{|∫Eg dμ - ∫Eg dν| : g:E → ℝ satisfies
|g(x)-g(y)| ≤ d(x,y) for all x,y ∈ E}

for all μ,ν ∈ 𝓑 is a metric on 𝓑. It is called the Hutchinson metric. Moreover, (𝓑,d𝓑) is a compact metric space.

Definition: Suppose that (E,d) is a compact metric space and that 𝓑 is the collection of all normalized Borel measures on E. The Markov operator associated to an IFS with probabilities ({fj}1≤j≤J,{pj}1≤j≤J) is the function M: 𝓑 → 𝓑 defined by M(μ) = sum1≤j≤J pj μ∘fj-1 for μ ∈ 𝓑.

Proposition: Suppose that (E,d) is a compact metric space, that 𝓑 is the collection of all normalized Borel measures on E, and that ({fj}1≤j≤J,{pj}1≤j≤J) is an IFS with probabilities. If M: 𝓑 → 𝓑 is the Markov operator associated to this IFS with probabilities and C = max1≤j≤J Cj, where Cj is a contraction factor for fj, then M: 𝓑 → 𝓑 is a contraction with contraction factor C with respect to the Hutchinson metric d𝓑; namely, d𝓑(M(μ),M(ν)) ≤ C d𝓑(μ,ν) for all μ,ν ∈ 𝓑.

Proof (sketch): Let G = {g:E → ℝ : |g(x)-g(y)| ≤ d(x,y) for all x,y ∈ E}. We first prove that

∫E g d(M(ν)) = ∑1≤j≤J pj ∫E g∘fj dν

for all g ∈ G. Since E is a compact set, there exists a sequence of step functions {si}i≥1 that converges uniformly to g on E. It is easy to verify that

∫E si d(M(ν)) = ∑1≤j≤J pj ∫E si d(ν∘fj-1)
= ∑1≤j≤J pj ∫fj(E) si dν = ∑1≤j≤J pj ∫E si∘fj dν

for all i. Since Si → g uniformly on the compact set E as i → ∞, we get that ∫E si d(M(ν)) → ∫E g d(M(ν)) and ∫E si∘fj dν → ∫E g∘fj dν as i → ∞. This proves the result claimed above.

Let G ˆ = {C-1 ∑1≤j≤J pj g∘fj : g ∈ G}. We have that

|C-1 ∑1≤j≤J pj g∘fj(x) - C-1 ∑1≤j≤J pj g∘fj(y)| ≤ C-1 ∑1≤j≤J pj |g∘fj(x)-g∘fj(y)|
≤ C-1 ∑1≤j≤J pj d(fj(x),fj(y)) ≤ ∑1≤j≤J pj d(x,y) = d(x,y)

for all x,y ∈ E and g ∈ G. Therefore, G ˆ ⊂ G. Hence,

d𝓑(M(μ),M(ν)) = sup{|∫Eg d(M(μ)) - ∫Eg d(M(ν))| : g ∈ G}
= sup{|∑1≤j≤J pj ∫E g∘fj dμ - ∑1≤j≤J pj ∫E g∘fj dν| : g ∈ G}
= sup{|C ∫E g ˆ dμ - C ∫E g ˆ dν| : g ˆ ∈ G ˆ }
≤ C sup{|∫E g ˆ dμ - ∫E g ˆ dν| : g ˆ ∈ G} = C d𝓑(μ,ν)

for all μ,ν ∈ 𝓑.  ∎

The next theorem is a corollary of the previous proposition and the contraction mapping theorem.

Theorem: Suppose that (E,d) is a compact metric space, that 𝓑 is the collection of all normalized Borel measures on E, and that ({fj}1≤j≤J,{pj}1≤j≤J) is an IFS with probabilities. If M: 𝓑 → 𝓑 is the Markov operator associated to this IFS with probabilities, then there exists a unique set μ ∈ 𝓑 such that M𝓑(μ) = μ. Moreover, for all measures ν0 ∈ 𝓑, the sequence of measures {νi}i≥0 defined by νi+1 = M𝓑(νi) converges to μ according to the Hutchinson metric d𝓑 as i → ∞.

Definition: In the previous theorem, the measure μ such that M𝓑(μ) = μ is called the invariant measure of the IFS with probabilities.

Proposition: Suppose that (E,d) is a compact metric space, that 𝓑 is the collection of all normalized Borel measures on E, and that ({fj}1≤j≤J,{pj}1≤j≤J) is an IFS with probabilities. Then, the support K ⊂ E of the invariant measure μ ∈ 𝓑 of this IFS with probabilities is the fixed point of the function fc induced by the IFS {fj}1≤j≤J.

Proof (sketch): Let K be the fixed point of the function fc induced by the IFS {fj}1≤j≤J. The set K is invariant under the action of the IFS with probabilities ({fj}1≤j≤J,{pj}1≤j≤J). Therefore, there exists an invariant measure ν for the IFS with probabilities ({fj}1≤j≤J,{pj}1≤j≤J) restricted to K. If we assume that ν(A) = 0 for all Borel measurable sets A ⊂ E ∖ K, then ν defines a normalized Borel measure on E. By uniqueness of the invariant measure, we have that ν = μ. This implies that the support of ν is a subset of K.

A proof that the support of ν is equal to K uses the isometry between the set ΣJ = {(s0s1s2...) : sk ∈ {1,2,...,J} for all k ≥ 0} and the set K, and the shift map on J symbols acting on ΣJ. This is a topic that we have not addressed. It is similar to what was done in the document .  ∎

There exists a collage theorem for measures similar to the college theorem for IFS in the previous section. It is also a corollary of .

Theorem (Collage): Suppose that (E,d) is a compact metric space and that 𝓑 is the collection of all normalized Borel measures on E. Moreover, suppose that M: 𝓑 → 𝓑 is the Markov operator associated to the IFS with probabilities ({fj}1≤j≤J,{pj}1≤j≤J). Finally, suppose that C is a contraction factor for the function fc induced by the IFS {fj}1≤j≤J. If d𝓑(ν,M(ν)) ≤ ε, then d𝓑(ν,μ) ≤ ε/(1-C) where μ is the invariant measure of the IFS with probabilities.

As for IFS in the previous section, we have an inverse problem for IFS with probabilities. The problem is now to find an IFS with probabilities whose associated invariant measure is a given Borel measure. Let K be the support of this measure. Ideally, the density distribution on K of the points produced by the chaos game for the IFS with probabilities should represent the density distribution of the invariant measure on K. This is a difficult area of constant research. The reader may consult the article by for an introduction to neural networks and automata using IFS with probabilities.
