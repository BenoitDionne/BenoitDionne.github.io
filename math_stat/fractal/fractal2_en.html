Definition of Iterative Function Systems

In our study of DDS in the previous document, we have considered simple functions and computed iterations starting with a single initial point. We now consider more complex functions than the simple functions of the previous document. Moreover, we replace the initial point by an initial set.

This section is theoretical. Readers who do not have the mathematical background may skip this section and resume reading with the next section that provides examples of a procedure to draw fractals.

A metric space is a set E with a metric d:E×E → [0,∞[. We denote this metric space by (E,d).

Proposition
Suppose that the metric space (E,d) is complete; namely, every Cauchy sequence converges. Let Ec be the space of non-empty compact subsets of E. Then, the function dc:Ec × Ec → [0,∞[ defined by

dc(A,B) = max{max{d(a,B):a ∈ A},max{d(b,A):b ∈ B}}

for all A,B ⊂ Ec is a metric on Ec. Moreover, the metric space (Ec,dc) is complete. The metric dc is called the Hausdorff distance.

If f: E → E is a continuous function, then it maps compact sets to compact sets. Hence, the function f also defines a function f: Ec → Ec in a natural way.

A function f: E → E is a contraction if there exists a number C such that 0 ≤ C < 1 and d(f(x),f(y)) ≤ C d(x,y) for all x,y ∈ E. A contraction is obviously a continuous function. The value C is called a contraction factor.

Suppose that {fj}1≤j≤J is a collection of continuous functions fj: E → E, we define a function fc: Ec → Ec by

fc(A) = ∪1≤j≤J fj(A)

for all A ∈ Ec. This function is well defined because the finite union of compact sets is a compact set.

Proposition
If each function fj is a contraction with a contraction factor Cj, then the function fc: Ec → Ec is a contraction with a contraction factor C = max1≤j≤J Cj.

Theorem
If (E,d) is a complete metric space and {fj}1≤j≤J is a collection of contractions from E to itself, then fc: Ec → Ec has a unique fixed point; namely, there exists a unique A ⊂ Ec such that fc(A) = A. Moreover, for all set X0 ∈ Ec, the sequence of sets {Xi}i≥0 defined by Xi+1 = fc(Xi) converges to A according to the metric dc as i → ∞.

The previous theorem is a direct consequence of the Contraction Mapping Theorem because (Ec,dc) is a complete metric space and fc: Ec → Ec is a contraction.

An iterative function system (IFS) on a complete metric space (Ec,dc) is a collection {fj}1≤j≤J of contractions from E to itself.

In the examples that we consider below, E is the plane and d is the Euclidean metric. The fractals that we draw are the fixed points of functions fc: Ec → Ec associated to IFS {fj}1≤j≤J. The challenge is to choose the IFS that will produce the fractal that we want.

Good references (for advanced undergraduate students in mathematics) are Fractals Everywhere by Micheal Barnsley (Academic press, 1988) and Chaos and Fractals by H.-O. Peitgen, H. Jürgens and D. Saupe (Springer-Verlag, 1992).

Examples

Sierpinski Triangle

The following figure shows the famous Sierpinski gasket or Sierpinski triangle.

It is a typical example of a fractal. We give a definition of a fractal in the document . We do not need this definition right now.

To store this figure on a computer, we need about 10857 bytes (in png format). Using IFS, this figure (and the next two figures at any level of accuracy) can be stored using less than 2876 bytes (a simple Matlab code).

The Sierpinski triangle is the fixed point of the function fc:(ℝ2)c → (ℝ2)c associated to the IFS {fj}1≤j≤3 where

f1(x) = ( x1/2 , x2/2 + 1/2 )
f2(x) = ( x1/2 + 1/2 , x2/2 )
f3(x) = ( x1/2 , x2/2 )

We now explain in a graphical way how the Sierpinski triangle is drawn using the IFS composed of the three simple functions described above.

  • First, we choose any initial set. In the present case, we choose the solid triangle defined by T = {x : x1,x2 ≥ 0 and x1 + x2 ≤ 1 }.
  • Second, we shrink the solid triangle T to a quarter of its original size and translate it vertically by 0.5. This is the work of the function f1.
  • Third, we shrink the solid triangle T to a quarter of its original size and translate it horizontally by 0.5. This is the work of the function f2.
  • Fourth, we shrink the solid triangle T to a quarter of its original size only. This is the work of the function f3.

This four steps are illustrated in the figure below.

We repeat the second, third and fourth steps above with the new set formed of three solid triangles. The next figure illustrates the second iteration of the second, third and fourth steps described above.

We repeat this procedure until we are happy with the figure that we get. Usually, we stop when we can no longer observe any variation in the figure.

As we mentioned in the previous theoretical section above, independently of the set of points that we choose initially, we always get the Sierpinski triangle after an infinite number of iterations.

Probabilistic System
This is a simple technique to illustrate the Sierpinski triangle. Let A be the point with coordinate (0,1), B be the point with coordinate (1,0) and C be the origin (see the figure below). Suppose that we have an unbiased dice and that 1,6 are associated to A, 2,5 are associated to B and 3,4 are associated to C.

  • We choose a point x0 in the plane.
  • We throw the dice. Suppose that we get a 3.
  • The point x1 is the middle of the segment between x0< and C.
  • We throw the dice a second time. Suppose that we get a 1.
  • The point x2 is the middle of the segment between x1 and A.
  • And so on.

The isolated points are invisible. We only see the cluster of points. This cluster of points shadows the Sierpinski triangle. To get a good approximation of the Sierpinski triangle, the number of iterations must be very large and the random number generator of the computer must be really ... really good.
