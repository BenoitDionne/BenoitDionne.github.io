Introduction to Matlab

Using examples, this tutorial explains how to perform with Matlab many types of calculations including solving ordinary differential equations. A detailed description of Matlab (functions, ...) can be found in the help menu of Matlab. One can also get help from the Matlab command window by typing the command help subject after the Matlab prompt and pressing the return key. The word subject can be any function name, library name, etc. We can execute the command help to get the list of available libraries. The help command displays the names of functions in capital letters (e.g. QUADL, ODE113, ...). The name of a function must be typed in small letter in the Matlab command window (e.g. quadl, ode113, ...).

In each of the examples of this tutorial on Matlab, we give the command to be executed and run it in Matlab so that the reader may see the results of this command.

In this tutorial, the text in blue is the text as it should be typed in after the Matlab prompt.

Launching Matlab

To launch Matlab from a computer running Linux/Unix, it suffices to type matlab at the prompt in a terminal window. From a computer running Windows, it suffices to click on the Matlab icon (or select Matlab in the menu). In both cases, one gets a new window with the Matlab prompt.

>>

The cursor is sitting just after the Matlab prompt waiting for the user to type in instructions.

Basic Arithmetical Operations

The basic arithmetic operation are:

Operation Description
+ addition
- subtraction
* multiplication
/ right division
\ left division
^ exponentiation
( ) parentheses

Matlab performs the arithmetic operations in the following order of priorities.

  1. Parentheses
  2. Exponentiation
  3. Multiplications and Divisions
  4. Additions and subtractions

When two operations are on the same level, Matlab performs the operations from left to right. The exponentiation is the exception because Matlab performs these operations from right to left.

Example: To compute $16.07(42.5 + 387 / 23.8) + 3.62^2$, type in

>>  16.07*(42.5+387/23.8) + 3.6^2

and press the return key (we will no longer mention to press the return key but it must always be done) to get the result.

ans = 

  957.2413

The result is stored in the variable ans.

Example: The following example shows how to assign the result of the previous computation to the variable x .

>> x = 16.07*(42.5+387/23.8) + 3.6^2

x = 

   957.2413

If one adds a semi-colon at the end of the command, Matlab executes the command but does not display the result.

>> x = 10 + pi;
>> x

x = 

   13.1416

Number of Significant Digits Displayed

The number of significant digits displayed on the screen can be increased to the user's desired number. By default, non-integers are displayed in short format which displays only five significant digits. The computations are always performed with as many digits as Matlab can used.

Example: The cosine of $3$ radians is given by:

>> cos(3) 

ans = 

   -0.9900
The cosine of $1.57$ radians is given by:

>> cos(1.57) 

ans = 

   7.9633e-04

If more significant digits are desired, one can request the long format which displays sixteen significant digits. To change the format to long, execute the command format long.

Example: The cosine of $1.57$ radians in the long format is given by:

>> format long
>> cos(1.57) 

ans = 

      7.963267107332633e-04

To return to the short format, execute the command format short. To see all possible formats in Matlab execute the command help format. It is also possible to produce fancier outputs using the function sprintf.

Complex Numbers

To type in a complex number into MATLAB, one uses the regular notation:

>> z = 5 - 3i

z = 

   5.0000 - 3.0000i

The table of arithmetical operations on real numbers above extends to the complex number.

Example: The product of $5 + 3i$ and $5 - 3i$ is given by:

>> z = 5 - 3i;
>> zbar = 5 + 3i;
>> w1 = z * zbar

w1 = 

    34

The division of $5 + 3i$ by $5 -3i$ is given by:

>> w2 = z / zbar

w2 = 

   0.4706 - 0.8824i

Saving a Matlab Session

By default, Matlab save all the commands executed in the command history window.

However, it may be useful to save part or all the commands and outputs of a session inside a file for the purpose of using them later to generate a Matlab session.

To save a Matlab session (or part of it), execute the command diary. After that, Matlab echos all commands and outputs into a default file. To save the commands and outputs in the file named assignment1 for instance, execute the command diary assignment1. After that, all the commands and outputs will be saved to the file assignment1 in the working directory. To stop saving the commands and outputs, execute the command diary off. To start again saving the commands and outputs into the file assignment1, execute diary on again.

Matrices in Matlab

Every numerical quantity in Matlab is seen as a complex matrix. For instance, the number $5$ in Matlab is a $1\times 1$ matrix.

To define a matrix in Matlab, type in all the components of the matrix between a pair of square brackets. Commas or spaces are used to separate the components of a row, and semi-colons or returns are used to separate the rows of the matrix.

Example: To define the $2\times 3$ matrix $A$ given by

$$ A = \begin{pmatrix} 1 & \pi & 0 \\ 0 & 4 & 5 \end{pmatrix} \ ,$$

just type in the following command:

>> A = [ 1 pi 0; 0 4 5 ] 

A = 

     1.0000    3.1416         0
          0    4.0000    5.0000

or

>> A = [ 1 pi 0
0 4 5 ]

A = 

     1.0000    3.1416         0
          0    4.0000    5.0000

To get the dimension of a matrix, the command size can be used.

Example: Using the matrix $A$ of the previous example.

>> size(A)

ans = 

      2     3

Vectors are row or column matrices. We call them row and column vectors respectively.

Array Operations

Array operations are operations on matrices that operate component by component.

  • .*  array multiplication of two matrices where the dimensions of the two matrices are the same. The corresponding elements in the two matrices are multiplied.
  • .^  array exponentiation of matrices. The power of each element of the matrix is evaluated.
  • ./  array division of two matrices where the dimensions of the two matrices are the same. The corresponding elements in the two matrices are divided.

Example:

>> v1=[1 2 3];
>> v2=[2 2 2];
>> v1 .* v2

ans = 

     2     4     6

>> v1 ./ v2

ans = 

     0.5000    1.0000    1.5000 

>> A = [1 2 3 ; 3 2 1] 

A = 

     1     2     3
     3     2     1 

>> A .^2

ans = 

     1     4     9
     9     4     1

All built-in MATLAB functions are array smart. This means that when such a functions is applied to a matrix $A$ the result is the matrix obtained by applying the function to each element of $A$.

Example: Using the matrix $A$ defined above, we get;

>> sin(A)

ans = 

    0.8415    0.9093    0.1411
    0.1411    0.9093    0.8415

Two Dimensional Plotting in Matlab

Suppose that we want to plot the graph of the function $y = f(x)$ over the interval $[a,b]$.

We first create a vector x whose components form a partition of the interval $[a,b]$. It is usual to take $N + 1$ equally spaced points in the interval $[a,b]$. One way to do it is to type in the command x = a : h : b , where h = (b-a)/N. The other way is to use the command x = linspace(a,b,N+1).

Example: We consider the function $y = f(x) = x^3$ defined on the interval $[0,1]$. The following two examples show how to generate $11$ equally spaced points ($10$ subintervals). 

>> x = 0:0.1:1 

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 
 
     0.7000    0.8000    0.9000    1.0000

or

>> x = linspace(0,1,11)

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 

     0.7000    0.8000    0.9000    1.0000

To evaluate $y = f(x) = x^3$ at the $11$ points generated above, a simple array operation can be used.

>> y = x.^3 

y = 

   Columns 1 through 7 

          0    0.0010    0.0080    0.0270    0.0640    0.1250    0.2160 

   Columns 8 through 11 

     0.3430    0.5120    0.7290    1.0000

Each entry of y is the cube of the corresponding entry in x. Finally, the following call to the Matlab function plot produces the graph of $f$ over the interval $[0,1]$. The function plot use linear interpolation between the $11$ equally spaced point to approximate the graph of the function $f$.

>> plot(x,y)

A new window pop up with the following graph.

More equally spaced points will produce a more accurate graph of the function.

It is possible to plot more than one function on the same figure. The command hold on after having produce the first graph tells Matlab to draw the following graphs in the existing figure. The command hold off returns to the default mode which is to replace the present figure by the new one.

Example: Using the definition of x above and assuming that the previous figure exists, the following instructions will add the graph of the straight line $y = x + 2$ to the previous graph.

>> hold on
>> z = x + 2;
>> plot(x,z,'r')

The figure is now

One notes that in the previous example, the result of the Matlab expression z = x + 2 is to add the value $2$ to each component of x and store the result in z. The $i^{th}$ component of z is the sum of the $i^{th}$ component of x with $2$.

The option 'r' of the previous plot command tells Matlab to draw the graphs of $x + 2$ in red.

A title and axis labels can be added to the figure using the Matlab commands title to produce the title, xlabel to label the $x$ axis and ylabel to label the $y$ axis. The following example shows how to use these commands.

Example: Suppose that the following commands are parts of the session that produced the previous figure and that this figure is still existing (i.e. has not been closed).

>> title('sample plotting with MATLAB')
>> xlabel('x-axis')
>> ylabel('y-axis')

The results of these commands is to add the title sample plotting with MATLAB and labels to the axes to the previous figure to get the following figure.

Numerical Integration

There are three fundamental functions for numerically integration a function: trapz, quad and quadl.

The function trapz uses the Trapezoidal method to approximate the integral of a function.

Example: Use the trapezoidal method to approximate the area under the curve $y = x sin(x)$ for $0 < x < \pi$ using the function trapz with $10$ subintervals.

>> x = linspace(0,pi,11)

x = 

  Columns 1 through 7 

          0    0.3142    0.6283    0.9425    1.2566    1.5708    1.8850 

  Columns 8 through 11 

    2.1991    2.5133    2.8274    3.1416

The next step is to evaluate $x sin(x)$ at each of the coordinates of the vector x (the coordinates of x are the mesh points of the partition of the interval $[0.\pi]$.) 

>> y = x .* sin(x);

The sum of the trapezoidal method is computed with

>> trapz(x,y) 

ans = 

    3.1157

The function quad is based on an an adaptive recursive Simpson's rule and the function quadl is based on an adaptive recursive Newton-Cotes method. To be able to use these functions, we need to be able to define new functions using m-files. This is the topic of the next section.

m-files

Matlab has a large set of built-in mathematical functions. It is also easy to create your own functions. The following example will illustrate how to create a function.

Example: The following example shows how to define the function funct1 which is only $x \mapsto x sin(x)$.

First, a file name funct1.m is created (using any ascii text editor). The first line of this file is function y = funct1(x) and the second line is y = x.*sin(x);. There is nothing else to be added to this file.

Comments can be added to the m-file above. The text on a line following the character % is ignored by Matlab.

Here is the content of the m-file funct1.m.

% y = funct1(x)
%
% This function takes one argument x and returns the result of the
% computation  x sin(x)
function y = funct1(x)
    y = x.*sin(x);
end

If the file funct1.m is in the directory from which Matlab as been launched or in a directory included in the list of directories read by Matlab (see the menu), then our new function funct1 can be called as any other Matlab function as it is shown in the following example.

Example: The value of $x sin(x)$ at $x=5$ is given by the following command.

>> funt1(5) 

ans = 

    -4.7946

Executing help funct1 will return the (first group of commented) lines before the line function y = funct1(x) of the file funct1.m. An m-file should always begin with comments telling what the function implemented in this m-file does and how to use this function including the list and description of the arguments.

>> help funct1

  y = funct1(x) 

  This function takes one argument x and returns the result of the
  computation  x sin(x)

The first line of the m-file has the following format
function dependent_variable = function_name(independent_variable).

The rest of the m-file defines the function using the same syntax as used in the command window. The semi-colon is needed at the end of each command line otherwise the result of the line will be printed each time that the m-file is executed. It is recommended to use .* instead of *, ./ instead of /, etc to create an array smart functions. This means that when the function is evaluate at a matrix A the result is the matrix obtained by evaluating the function at each element of A.

The name of the m-file defining the function function_name must be function_name.m. The name of the function can be almost anything, as long as it satisfies the following few rules:

  • It must start with a letter (either upper case or lower case).
  • It must consist entirely of letters, numbers, and underscores (_). No other symbols are allowed.
  • Function names already used such as cos, log, sin, ... should not be used. Matlab will not complain if such names are used but then the original functions will no longer be available.

The m-files can be saved in any directory. However, Matlab must know where the files are stored. Matlab has a list of directory paths where it looks for m-files. To check if the directory in which a m-file has been saved is included in the list of directory paths searched by Matlab, execute the command path. Matlab will return all the directories in its search path. The directory where the m-file has been saved can be added to the search path of Matlab if not present with the command path(path, 'the path') or addpath the_path, where the_path is the path to the directory where the m-file is stored. The full path must be used. For instance, suppose that the file funct1.m is stored in the directory /home/user1/matlab, then the command path(path,'/home/user1/matlab') will add the path /home/user1/matlab to the list of paths searched by Matlab if it is not already included in this list.

Function Handles

Some Matlab functions require as one of their arguments the name of a function. For instance, the function quadl that we have used above requires the name of the function to be integrated as one of its argument. Instead of giving the name of the function as one of the argument, it is more convenient to give the handle of the function. Think of the handle of a function as the address of the function.

To construct the handle of a function, it suffices to precede the name of the function by @. For instance, the handle of the function funct1 is given by @funct1.

We now give an example of quad and quadl using this new concept.

.

Example: Find the area under the curve $y = x sin(x)$ for $0 < x < \pi$. We have y = funct1(x). To evaluate numerically the integral of $x sin(x)$ between $0 < x < \pi$, we only have to execute the following command.

>> quadl(@funct1,0,pi)
ans = 

    3.1416

The format of quadl and quad is quadl(@Funct, a, b);, where Funct is a function defined for $a \leq x \leq b$, the interval of integration. The result is an approximation of the exact result with a relative error of about $10^{-3}$. To specify a different tolerance, one uses the format quadl(@Funct,a,b,tol), where tol is a bound on the relative error.

A function handle can be used as the function that it represents.

Example: The following commands show how function handles can be manipulated and used.

>> hand = @funct1;
>> hand(10)

ans = 

   -5.44021110889370 

>> fubct(10) 

ans = 

   -5.44021110889370 

>> hands = {hand, @sin};
>> hands{1}(10) 

ans = 

   -5.44021110889370 

>> hands{2}(10)
ans = 

   -0.54402111088937

hand is the function handle of the function funct1. Hence hand(10) is identical to the call funct1(10). hands is an array (an ordered list) of two functions handles: the function handle of funct1 and the function handle of the Matlab function sin which is the trigonometric sine function. hands{1}(10) simply evaluates the function funct1 at $10$ and hands{2}(10) simply means to evaluate the sine at $10$ radians.

It is sometime cumbersome to create an m-file to define a simple function which will be used only one time. Function handles can be used to eliminate the need to create an m-file.

Example: Compute the integral of $f(x) = x^3 + 2 x^2 + 1$ for $3 \leq x \leq 5$.

Instead of creating an m-file for the function $f$, we define an anonymous function and store its function handle in a data structure as follows.

>>  f = @(x) x.^3 + 2* x.^2 + 1

This function handle can then be used in a call to the function quadl. The following sample illustrates how to do it.

>> f = @(x) x.^3 + 2* x.^2 + 1;
>> quadl(f,3,5) 

ans =  

     2.033333333333333e+02

The following functions manipulating function handles are sometime useful.

Command Description
functions(function_handle) Return a description of the function associated to the function handle given as argument.
func2str(function_handle) Return the name of the function associated to the function handle given as argument or, if the function handle is associated to an anonymous function, the formula used to define the anonymous function.
str2func('function_name') Construct a function handle from a function named function_name.
isa(variable_name. 'function_handle') Return 1 (or true) if the variable given as the first argument contains a function handle and 0 (or false) if it does not contain a function handle.

Ordinary Differential Equations (ODE)

Three of the Matlab functions to solve (non-stiff) first order (systems of) ODE's are ode23, ode45 and ode113. They are variable step size methods based on Runge-Kutta methods. To get a list of all possible ODE's solvers, execute help ode23 . The function name ode23 can be replaced by any other ODE's solver name like ode45 and ode113 .

Only the procedure to use the ODE's solver ode45 will be explained below. However, the procedure to use the other solvers is similar.

The format of the command ode45 is [xx,yy] = ode45(@yprime ,[x_zero , x_final], y0, options) .

The function yprime (of $x$ and $y$) is the right side of the ODE $y'(x) = \text{yprime}(x,y)$. x_zero is the initial time and x_final is where the integration stop. y0 is a row vector of initial conditions at x_zero. One solution for each initial condition will be computed.

The vector xx and the matrix yy returned by ode45 have the same number of rows. The matrix yy has the same number of columns as the length of y0. Each column of yy is associated to an initial condition in y0. The $k^{th}$ row of yy is the approximation of the solution of $y'(x) = \text{yprime}(x,y)$ at the $k^{th}$ entry of xx. The $i^{th}$ column of yy is associated to the $i^{th}$ initial condition given in the vector y0.

Many options can be given to the ODE's solvers. To provide the solver with bounds on the relative tolerance, absolute tolerance, etc. one has to first define a structure of options like the following one.

>>  option = odeset('reltol', 0.001, 'abstol', [0.000001])

Only the relative tolerance, absolute tolerance have been defined in the previous example but there are many more options according to the integration method used.

Example: Use ode45 to approximate the solution of $y'(x) = x sin(x)$ for $0 \leq x \leq \pi$. The initial condition is $y(0) = 0$ and it is assumed that the relative tolerance is at most $10^{-5}$. The function $f(x) = x sin(x)$ has been defined previously in the file funct1.m. However, funct1 can not be used with the ODE's solver ode45 because the function funct1 does not depend on $y$. The right hand side of the ODE must be a function of $x$ and $y$.

The function funct1 is modified to get the new function funct2 defined in the file funct2.m. The m-file funct2.m contains the following lines of code:

% yprime = funct2(x,y)
%
% This function takes two arguments, x and y, and returns the
% result of the computation  x sin(x)
function yprime = funct2(x,y)
     yprime = x.*sin(x);
end

The only option given to ode45 is the upper bound $10^{-5}$ for the relative error.

>> options = odeset('reltol',10^(-5));

Using linear interpolation at the data given in [xx,yy], one can approximate the solution of the ODE at any points of the interval $[0,\pi]$. For instance, the linear approximation of the solution at $x = 2$ is given by:

>> w = interp1(xx,yy,2,'linear')

Programming

The plain version of Matlab does not have functions that execute iterative methods. The user therefore has to program Matlab to execute iteration methods. The following example will illustrate how to do it for the fixed point method. The approach is identical for the other iterative methods.

Example: Use fixed point iterations to approximate the solution of $-(x^2/8) - x/4 + 1/2 = x$ in the interval $[0,1]$. Start with $x = 0.5$. A possible solution is to write a little m-file like the following one:

%  Starting value of x for the iteration:
x = 0.5; 

%   Number of iterations:
n = 20; 

% loop:

for i = 1:n
   x = -(x.^2/8) - x/4 + 1/2;
end  

% Return the final value of the iteration
x

This m-file is called fxpt1.m. It is not a function but only a simple script that Matlab will execute. With more knowledge of the Matlab language, one can write much more sophisticated programs but this one is enough to understand the basic of programming in Matlab.

If we type fxpt1 in Matlab, Matlab executes $20$ iterations of the function $x \mapsto -(x^2/8) - x/4 + 1/2$ starting with $x = 0.5$ and return the $20^{th}$ iteration.

>> fxpt1

x = 

    0.3852

The program above is not convenient because one has to modify the file fxpt1.m each time that the function, the initial value or the number of iterations has to be modified.

The function fxpt2 defined in the file fxpt2.m takes as arguments the handle to the function to iterate, the initial value and the number of iterations.

% y = fxpt2(funct,x0,n)
%
% This function returns the result of n iterations of the function
% y = funct(x) starting with the value x = x0 .
function y = fxpt2(funct,x0,n)
    y = x0
    for i=1:n
      y = feval(funct,y);
    end
end

To execute $20$ iterations of the function $f(x) = -(x^2/8) - x/4 + 1/2$ starting with $x = 0.5$, we first define the function funct3 as follows.

% y = funct3(x)
%
% This function takes one argument x and return the result of the
% computation  -(x.^2/8) - x/4 + 1/2 .
function y = funct3(x)
   y = -(x.^2/8) - x/4 + 1/2;
end

The function fxpt2 can then be invoked with the arguments @funct3, 0.5 and 20.

>> fxpt2(@funct3,0.5,20) 

ans = 

    0.3852

Instead of defining funct3 using an m-file, we could have simply defined an anonymous function as it follows. 

>> funct3 = @(x) -(x.^2/8) - x/4 + 1/2;

This way, it is easy to modify the function that will be used for the fixed point method.

File Management and Batch Mode in Matlab

Matlab provides several files management commands that allow the user to list files, view and delete m-files, show and change the current directory or folder. A summary of these commands is given in the following table.

Command Description
what Return a listing of all m-files in the current directory.
dir List all files in the current directory.
type file_name Display the content of the m-file file_name.m.
delete file_name Delete the m-file file_name.m.
cd path Change to the directory or folder given by path.
cd Show present working directory or folder.
which funct_name Display the directory path to funct_name.m.

It is also very simple to execute a Matlab script on a Unix platform. For instance, to execute the script my_code.m in batch mode, one enters the following command at the prompt of an terminal.

% nice +19 matlab -nosplash < my_code.m > my_code.log

The nice command is a Unix command to change the priority of execution of the program to be executed. The +19 lower the priority of execution of the program so that it will not monopolized the CPU. The output of the program is send to the file my_code.log. The option -nosplash cancels the display of the welcoming window when Matlab is launched.
