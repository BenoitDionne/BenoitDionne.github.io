Introduction to Matlab

Content

This tutorial explains using examples how to perform with Matlab many types of calculations including solving ordinary differential equations. A detailed description of Matlab (functions, commands, libraries, ...) can be found in the help menu of Matlab. We can also get help from the Matlab command window by typing the command help subject after the Matlab prompt and pressing the Enter key. The word subject can be any function, command or library name. The help command displays the names of functions in capital letters (e.g. QUADL, ODE113, ...). The name of a function must be typed in small letter in the Matlab command window (e.g. quadl, ode113, ...).

Almost all the information provided in this document is also valid for Octave. The presentation of the results of a computation with Octave may sometime be different than the presentation of the same results with Matlab. A very small number of Matlab functions are missing in Octave. We mention one in the section on solving ordinary differential equations below. In such situation, there is usually a function in Octave that can perform the same task.

In each of the examples of this tutorial on Matlab, we give the code to be executed and display the results of the code after it has been run in Matlab.

In this tutorial, the text in blue is the code as it should be typed in after the Matlab prompt.

Launching Matlab

To launch Matlab from a computer running Linux/Unix, it suffices to type matlab at the prompt in a terminal window and press the Enter key. From a computer running Windows, it suffices to click on the Matlab icon or to select the item Matlab in the menu. In all cases, we get a new window with the Matlab prompt.

>>

The cursor is sitting just after the Matlab prompt waiting for the user to type in instructions.

Basic Arithmetical Operations

The basic arithmetic operations are:

Operation Description
+ addition
- subtraction
* multiplication
/ right division
\ left division
^ exponentiation
( ) parentheses

Matlab performs the arithmetic operations in the following order of priorities.

  1. Parentheses
  2. Exponentiation
  3. Multiplications and divisions
  4. Additions and subtractions

When two consecutive operations are on the same level of priority, Matlab performs the operations from left to right. The exponentiation is the exception because Matlab performs these operations from right to left.

Example: To compute \(\displaystyle 16.07(42.5 + 387 / 23.8) + 3.6^2\), we type in

>>  16.07*(42.5+387/23.8) + 3.6^2

and press the Enter key (we will no longer mention to press the Enter key but it must always be done) to get the result.

ans = 

  957.2413

The result is stored in the variable ans.

Example: The following example shows how to assign the result of the previous computation to the variable x .

>> x = 16.07*(42.5+387/23.8) + 3.6^2

x = 

   957.2413

If we add a semi-colon at the end of the command, then Matlab executes the command but does not display the result.

>> x = 10 + pi;
>> x

x = 

   13.1416

Number of Significant Digits Displayed

The number of significant digits displayed on the screen can be increased to the user's desired number. By default, non-integers are displayed in short format which displays only five significant digits. However, the computations are always performed with as many digits as Matlab can used.

Example: The cosine of \(3\) radians is given by

>> cos(3) 

ans = 

   -0.9900
The cosine of \(1.57\) radians is given by

>> cos(1.57) 

ans = 

   7.9633e-04

If we need more significant digits, then we can request the long format which displays sixteen significant digits. To change the format to long, it suffices to execute the command format long.

Example: The cosine of \(1.57\) radians in the long format is given by

>> format long
>> cos(1.57) 

ans = 

      7.963267107332633e-04

To return to the short format, it suffices to execute the command format short. To see all possible formats in Matlab, it suffices to execute the command help format. It is also possible to produce fancier outputs using the function sprintf.

Complex Numbers

To type in a complex number in Matlab, we use the regular notation as it follows.

>> z = 5 - 7i

z = 

   5.0000 - 7.0000i

The table of arithmetical operations on real numbers above extends to the complex numbers.

Example: The product of \(5 + 3i\) and \(5 - 3i\) is given by

>> z = 5 - 3i;
>> zbar = 5 + 3i;
>> w1 = z * zbar

w1 = 

    34

The division of \(5 + 3i\) by \(5 -3i\) is given by

>> w2 = z / zbar

w2 = 

   0.4706 - 0.8824i

Saving Matlab Sessions

By default, Matlab save all the commands executed in the command history window.

However, it may be useful to save part of or all the commands and outputs of a session inside a file for the purpose of using them later to generate a Matlab session.

To save a Matlab session (or part of it), it suffices to execute the command diary. After that, Matlab echos all commands and outputs into a default file usually called diary. To save the commands and outputs in the file named assignment1 for instance, it suffices to execute the command diary assignment1. After that, all the commands and outputs will be saved to the file assignment1 in the working directory. To stop saving the commands and outputs, it suffices to execute the command diary off. To start again saving the commands and outputs into the file assignment1, it suffices to execute diary on. The new commands and results are appended to the existing content of the file assignment1.

Matrices in Matlab

In fact, every numerical quantity in Matlab is treated as a matrix of complex numbers. For instance, the number \(5\) in Matlab is a \(1\times 1\) matrix.

To define a matrix in Matlab, we type in all the components of the matrix between a pair of square brackets. Commas or spaces are used to separate the components of a row, and semi-colons or line changes are used to separate the rows of the matrix.

Example: To define in Matlab the \(2\times 3\) matrix

\[ A = \begin{pmatrix} 1 & \pi & 0 \\ 0 & 4 & 5 \end{pmatrix} \ , \]

we may type in one of the following commands:

>> A = [ 1 pi 0; 0 4 5 ] 

A = 

     1.0000    3.1416         0
          0    4.0000    5.0000

or

>> A = [ 1 pi 0
0 4 5 ]

A = 

     1.0000    3.1416         0
          0    4.0000    5.0000

The command size can be used to get the dimensions of a matrix.

Example: Using the matrix \(A\) of the previous example, we get 

>> size(A)

ans = 

      2     3

Vectors are Special Matrices

Vectors are row or column matrices. We call them row and column vectors respectively.

Example: The following vector is a column vector.

>> V = [1 ; 2 ; -5 ; 3]

V = 

      1
      2
     -5
      3

This vector is of length \(4\) (it has four components).

>> length(V) 

ans = 

      4

Example: The following vector is a row vector of length \(4\).

>> U = [sin(2) , -5 , 0 , 1] 

U = 

     0.9093   -5.0000         0    1.0000

Matrix Algebra

All normal operations on matrices can be executed by Matlab.

Operation Description
+ addition of matrices of the same dimensions
- subtraction of matrices of the same dimensions
* multiplication of two matrices where the number of columns of the first matrix equal the number of rows of the second matrix
^ exponentiation of square matrices
( ) parentheses

Operation Description
/ \(A/B\) is \(A\) times the inverse of \(B\) if \(B\) is invertible and the number of columns of \(A\) equals the number of rows of \(B\).

Use the help menu for more information.

Array Operations

Array operations are operations on matrices that operate component by component.

  • .*  Array multiplication of two matrices that have the same dimensions. The components of the two matrices with the same indices are multiplied.
  • .^  Array exponentiation of matrices. The exponential of each component of the matrix is computed.
  • ./  Array division of two matrices that have the same dimensions. Each components of the first matrix is divided by the component of the second matrix with the same indices.

Example:

>> v1=[1 2 3];
>> v2=[2 2 2];
>> v1 .* v2

ans = 

     2     4     6

>> v1 ./ v2

ans = 

     0.5000    1.0000    1.5000 

>> A = [1 2 3 ; 3 2 1] 

A = 

     1     2     3
     3     2     1 

>> A.^2

ans = 

     1     4     9
     9     4     1

All built-in Matlab functions are array smart. This means that when such a function is applied to a matrix \(A\) the result is the matrix obtained by applying the function to each components of \(A\).

Example: If we use the matrix \(A\) defined above and compute \(\sin(A)\), we get the following result.

>> sin(A)

ans = 

    0.8415    0.9093    0.1411
    0.1411    0.9093    0.8415

Two Dimensional Plotting in Matlab

Suppose that we want to plot the graph of a function \(f\) defined on an interval \([a,b]\).

The first step is to create a list x whose components form a partition of the interval \([a,b]\). It is usual to take \(N + 1\) equally spaced points in the interval \([a,b]\). One way to create such a list is with the command x = a : h : b where h = (b-a)/N. Another way to create such a list is with the command x = linspace(a,b,N+1).

Example: We consider the function \(f\) defined by \(\displaystyle f(x) = x^3\) on the interval \([0,1]\). The following two examples show how to generate \(11\) equally spaced points (\(10\) subintervals) including the end points of the interval.

>> x = 0:0.1:1 

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 
 
     0.7000    0.8000    0.9000    1.0000

or

>> x = linspace(0,1,11)

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 

     0.7000    0.8000    0.9000    1.0000

To evaluate the function \(f\) defined by \(\displaystyle f(x) = x^3\) at the \(11\) points generated above, a simple array operation can be used.

>> y = x.^3 

y = 

   Columns 1 through 7 

          0    0.0010    0.0080    0.0270    0.0640    0.1250    0.2160 

   Columns 8 through 11 

     0.3430    0.5120    0.7290    1.0000

Each component of y is the cube of the corresponding component in x. Finally, the following call to the Matlab function plot draws the graph of \(f\) over the interval \([0,1]\). The function plot use linear interpolation between the \(11\) equally spaced points to approximate the graph of the function \(f\).

>> plot(x,y)

After having pressed the Enter key, a new window pops up with a figure containing the graph of the function.

More equally spaced points will produce a more accurate graph of the function.

It is possible to include in the same figure the graphs of several functions. The command hold on after having produce the first figure tells Matlab to draw the following graphs in the existing figure. The command hold off returns Matlan to the default mode which is to replace the present figure by a new one.

Example: Using the definition of the variable x above and assuming that the previous figure exists (i.e. it has not been closed), the following commands add the straight line \(y = x + 2\) to the previous figure containing the graph of \(f\).

>> hold on
>> z = x + 2;
>> plot(x,z,'r')

The figure is now

In the previous example, the result of the Matlab expression z = x + 2 is to add the value \(2\) to each component of x and store the results in the variable z. The \(\displaystyle i^{th}\) component of z is the sum of the \(\displaystyle i^{th}\) component of x with \(2\). This is one of the unnatural behaviours of Matlab.

The option 'r' of the previous plot command tells Matlab to draw the line \(y = x + 2\) in red.

A title and axis labels can be added to the figure using the Matlab functions title to produce the title, xlabel to label the \(x\) axis and ylabel to label the \(y\) axis. The following example shows how to use these functions.

Example: Suppose that the following commands are parts of the session that produced the previous figure and that this figure is still existing (i.e. the figure has not been closed).

>> title('sample plotting with MATLAB')
>> xlabel('x-axis')
>> ylabel('y-axis')

The effect of these commands is to add the title sample plotting with MATLAB and the labels to the axes to the previous figure to get the following figure.

Interpolation

Polynomial interpolation can be used in Matlab.

Example: We draw the linear interpolation of the function \(f\) associated to the data in the table below.

\[ \begin{array}{|l|r|r|r|r|r|} \hline x & 0 & 0.7854 & 1.5708 & 2.3562 & 3.1416 \\ \hline y & 0 & 0.5554 & 1.5708 & 1.6661 & 0.0000 \\ \hline \end{array} \]

The data for \(x\) and \(y\) are stored in two vectors in Matlab.

>> x = [ 0  0.7854  1.5708  2.3562  3.1416 ] 

x = 

         0    0.7854    1.5708    2.3562    3.1416 

>> y = [ 0  0.5554  1.5708  1.6661  0.0000 ]

y = 

         0    0.5554    1.5708    1.6661         0

It is in fact easier to draw the linear interpolation of \(f\) than to evaluate \(f\) at some points. Assuming that the previous figure has been closed (or that the command hold off has been used), the following command draws the linear interpolation of \(f\).

>> plot(x,y);

The linear interpolation of \(f\) can be evaluated at some points using the Matlab function interp1.

Example: Suppose that the points where the linear interpolation of \(f\) has to be evaluated are \(0, \pi/10 , \pi/5 , 3\pi/10, \ldots, \pi\). These points may be listed in Matlab as it follows. 

>> z = linspace(0,pi,11)

z = 

   Columns 1 through 9 

       0    0.3142    0.6283    0.9425    1.2566    1.5708    1.8850   2.1991    2.5133 

   Columns 10 through 11 

       2.8274    3.1416

The next Matlab command computes the value of the linear interpolation of \(f\) at the \(11\) equally spaced points in z.

>> w = interp1(x,y,z,'linear') 

w = 

   Columns 1 through 9 

       0    0.2222    0.4443    0.7585    1.1646    1.5708    1.6089    1.6470    1.3329 

   Columns 10 through 11 

       0.6665    0.0000

The \(\displaystyle k^{th}\) component of w is the value of the linear interpolation of the function \(f\) at the \(\displaystyle k^{th}\) component of z. The following commands plot the points with coordinates \((x,y)\) where \(x\) and \(y\) are the \(\displaystyle k^{th}\) components of z and w respectively for \(k = 1, 2, \ldots, 11\).

>> hold on
>> plot(z,w,'or');

The third argument in plot above tells Matlab to only plot a red circle at each point.

There are other methods of interpolation than linear (the default) like cubic and spline. To use these methods, it suffices to follow the steps in the previous example but substituting linear by cubic or spline. To compare these methods, the reader should try these methods with the previous example.

Numerical Integration

There are three fundamental Matlab functions to numerically integrate a function: trapz, quad and quadl. The function trapz uses the Trapezoidal method to approximate the integral of a function.

Example: We use the trapezoidal method to approximate the area under the curve \(y = x \sin(x)\) for \(0 < x < \pi\) with \(10\) subintervals. We use the \(11\) equally spaced points given in the following list. 

>> x = linspace(0,pi,11)

x = 

  Columns 1 through 7 

          0    0.3142    0.6283    0.9425    1.2566    1.5708    1.8850 

  Columns 8 through 11 

    2.1991    2.5133    2.8274    3.1416

The next step is to evaluate \(x \sin(x)\) at each of the components of the list x (the components of x are the mesh points of the partition of the interval \([0.\pi]\).) 

>> y = x .* sin(x);

The sum of the trapezoidal method is computed with the following command

>> trapz(x,y) 

ans = 

    3.1157

The function quad is based on an an adaptive recursive Simpson's rule and the function quadl is based on an adaptive recursive Newton-Cotes method. To be able to use these functions, we need to be able to define new functions using m-files or to define anonymous functions. These are the topics of the next two sections.

m-files

Matlab has a large set of built-in mathematical functions. It is also easy to create our own functions. The following example will illustrate how to create a function.

Example: The following example explains how to create the function funct1 which is defined by \(x \mapsto x \sin(x)\).

First, a file named funct1.m is created using any ascii text editor. The first line of this file contains the statement function y = funct1(x), the second line contains the formula y = x.*sin(x); and the last line contains the statement end. There is nothing else to be added to this file.

Comments can be added to the m-file above. The text on a line following the character % is ignored by Matlab.

Here is the content of the m-file .

% y = funct1(x)
%
% This function takes one argument x and returns the result of the
% computation  x sin(x)
function y = funct1(x)
    y = x.*sin(x);
end

Note: The file funct1.m can be downloaded by clicking with the right button of the mouse on the previous link and then selecting Save link as ... → Save file.

If the file funct1.m is in the directory from which Matlab as been launched or in a directory included in the list of directories read by Matlab when it is launched (see the menu of Matlab), then our new function funct1 can be called as any other Matlab function as it is shown in the following example.

Example: The value of \(x \sin(x)\) for \(x=5\) is given by the following command.

>> funct1(5) 

ans = 

    -4.7946

The first line of the m-file has the following format.

function dependent_variables = function_name(independent_variables)

The rest of the m-file defines the function using the same syntax as the syntax used in the command window. The semi-colon is needed at the end of each command line otherwise the result of the line will be displayed each time that the m-file is executed. It is strongly recommended to use .* instead of *, ./ instead of /, etc to create an array smart function.

The name of the m-file defining the function function_name must be function_name.m. The name of the function can be almost anything as long as it satisfies the following few rules:

  • It must start with a letter (either upper case or lower case).
  • It must consist entirely of letters, numbers, and underscores (_). No other symbols are allowed.
  • Function names already used such as cos, log, sin, ... should not be used. Matlab does not complain if such names are used but then the original functions are no longer available.

The m-files can be saved in any directory. However, Matlab must know where the m-files are stored. Matlab has a list of directory paths where it looks for m-files. To check if the directory path of the directory containing a m-file is included in the list of directory paths searched by Matlab, it suffices to execute the command path. Matlab then displays all the directory paths that it searches. The directory where a m-file has been saved can be added to the search paths of Matlab, if it is not already present, with the commands path(path, 'the_path') or addpath the_path, where the_path is the full path to the directory where the m-file is stored. For instance, suppose that the file funct1.m is stored in the directory /home/user1/matlab, then the command path(path,'/home/user1/matlab') adds the path /home/user1/matlab to the list of paths searched by Matlab if it is not already included in this list.

The comment help function_name displays the (first group of) commented lines before the line function dependent_variables = function_name(independent_variables) of the file function_name.m. A m-file should always begin with comments describing the function defined in the m-file, what the function does and how to use it including the list and description of its arguments.

Example: 

>> help funct1

  y = funct1(x) 

  This function takes one argument x and returns the result of the
  computation  x sin(x)

Function Handles

Some Matlab functions require the name of a function as one of their arguments . For instance, the function quadl that we have introduced above requires the name of the function to be integrated as one of its arguments. Instead of giving the name of the function as one of the arguments, it is often more convenient to give the handle of the function. Think of the handle of a function as the address of the function.

To get the handle of a function, it suffices to add the prefix @ to the name of the function. For instance, the handle of the function funct1 is given by @funct1.

We may now give an example for quad and quadl using this new concept.

Example: To approximate the area under the curve \(y = x \sin(x)\) for \(0 \leq x \leq \pi\), we use our function funct1. To evaluate numerically the integral of \(x \sin(x)\) over the interval \(0 \leq x \leq \pi\), we only have to execute the following command.

>> quadl(@funct1,0,pi)
ans = 

    3.1416

The basic format of quadl and quad is quadl(@Funct, a, b);, where Funct is the name of the function defined for \(a \leq x \leq b\), the interval of integration. The result is an approximation of the exact result with a relative error of no more than \(\displaystyle 10^{-3}\). To specify a different upper bound on the relative error, it suffices to use the command quadl(@Funct,a,b,tol), where tol is the new bound on the relative error.

A function handle can be used instead of the name of the function that it represents.

Example: The following commands show how function handles can be manipulated and used.

>> hand = @funct1;
>> hand(10)

ans = 

   -5.44021110889370 

>> funct1(10) 

ans = 

   -5.44021110889370 

>> hands = {hand, @sin};
>> hands{1}(10) 

ans = 

   -5.44021110889370 

>> hands{2}(10)
ans = 

   -0.54402111088937

hand contains the function handle of the function funct1. Hence hand(10) is identical to the command funct1(10). The variable hands is an array (an ordered list) of two functions handles: the function handle of the function funct1 and the function handle of the Matlab function sin which is the trigonometric sine function. hands{1}(10) is equivalent to the command funct1(10) and hands{2}(10) is equivalent to the command sin(10).

It is sometime cumbersome to create an m-file to define a simple function which will be used only during one Matlab session. Function handles can be used to eliminate the need to create an m-file.

Example: We want to approximate the value of the integral of \(\displaystyle f(x) = x^3 + 2 x^2 + 1\) for \(3 \leq x \leq 5\).

Instead of creating an m-file for the function \(f\), we define an anonymous function which is only represented by its handle that we store in a variable as it follows.

>>  f = @(x) x.^3 + 2* x.^2 + 1

f = 

    @(x) x .^ 3 + 2 * x .^ 2 + 1

This function handle can then be used in with function quadl. The following command illustrates how to do it.

>> quadl(f,3,5) 

ans =  

     2.033333333333333e+02

The following functions to manipulate function handles are sometime useful.

Command Description
functions(function_handle) Display a description of the function associated to the function handle given as argument.
func2str(function_handle) Display the name of the function associated to the function handle given as argument or, if the function handle is associated to an anonymous function, the formula used to define the anonymous function.
str2func('function_name') Return a function handle for a function named function_name.
isa(variable. 'function_handle') Return 1 (or true) if the variable given as the first argument contains a function handle and 0 (or false) if the variable does not contain a function handle.

Ordinary Differential Equations (ODE)

Three of the Matlab functions to solve (non-stiff) first order (systems of) ODE are ode23, ode45 and ode113 (Octave does not have ode113 but offers ode115s instead). They are variable step size methods based on Runge-Kutta methods. They are parts of the family of ODE solvers for Matlab. To get help about an ODE solver and/or to get a list of the other ODE solvers in Matlab, it suffices to execute the command help ode23 for instance. The function name ode23 can be replaced by any other Matlab ODE solver name.

Only the procedure to use the ODE solver ode45 will be explained below. However, the procedure to use the other solvers is similar.

The format of the ODE solver ode45 is [xx,yy] = ode45(@yprime ,[x_zero , x_final], y0, options) .

The function yprime (depending on \(x\) and \(y\)) is the right hand side of the ODE \(y'(x) = \mathrm{yprime}(x,y)\). The value x_zero is the initial time and the value x_final is when to stop the numerical integration. The expression y0 is a row vector of initial values of \(y\) at x_zero. One solution is computed for each initial condition.

The vector xx and the matrix yy returned by ode45 have the same number of rows. The number of columns of the matrix yy is equal to the length of the row vector y0. The \(\displaystyle i^{th}\) column of yy is an approximation at each component of xx of the solution \(y\) of \(y'(x) = \mathrm{yprime}(x,y)\) with initial condition at x0 given by the \(\displaystyle i^{th}\) component of y0. The \(\displaystyle k^{th}\) row of yy is the approximation of the solution \(y\) of \(y'(x) = \mathrm{yprime}(x,y)\) evaluated at the \(\displaystyle k^{th}\) component of xx for each initial condition given by the components of y0 at x_zero.

Many options can be given to the Matlab ODE solvers. To provide the solver with a bound on the relative tolerance, a bound on the absolute tolerance, etc, we have to first define a structure of options like the following one.

>>  option = odeset('reltol', 0.001, 'abstol', [0.000001])

Only bounds on the relative tolerance and absolute tolerance have been included in the previous example but there are many more options that can be included according to the ODE solver used.

Example: We use the solver ode45 to approximate the solution of \(y'(x) = f(x) = x \sin(x)\) for \(0 \leq x \leq \pi\). The initial condition is \(y(0) = 0\) and the upper bound on the relative tolerance is \(\displaystyle 10^{-5}\). We have already defined in the m-file funct1.m a function \(x \mapsto x \sin(x) \). However, this function funct1 cannot be used with the ODE solver ode45 because the function funct1 depends only of \(x\). The right hand side of an ODE \(y'(x)=\ldots\) must be a function of \(x\) and \(y\).

The function funct1 is modified to get the new function funct2 defined in the file funct2.m. The m-file contains the following lines of code:

% yprime = funct2(x,y)
%
% This function takes two arguments, x and y, and returns the
% result of the computation  x sin(x)
function yprime = funct2(x,y)
     yprime = x.*sin(x);
end

The only option given to the solver ode45 is the upper bound \(\displaystyle 10^{-5}\) for the relative tolerance.

>> options = odeset('reltol',10^(-5));

Finally, we can use the solver ode45 to numerically solve the ODE \(y' = f(x,y)\) for \(0 \leq x\leq \pi\) with the initial condition \(y(0) = 0\).

>> [xx,yy] = ode45('funct2',[0,pi],0,options) 

xx = 

         0

Programming

The plain version of Matlab does not have functions to execute iterative methods. Therefore, the user has to program Matlab to execute iterative methods. The following example will illustrate how this could be done for the fixed point method. The approach is similar for other iterative methods.

Example: We want to use the fixed point method to approximate the solution of the equation \(\displaystyle -(x^2/8) - x/4 + 1/2 = x\) in the interval \([0,1]\). We start the iterations with \(x = 0.5\). A possible solution of this problem is to execute a little m-file containing the following code.

%  Starting value of x for the iteration:
x = 0.5; 

%  Number of iterations:
n = 20; 

% loop:

for i = 1:n
   x = -(x.^2/8) - x/4 + 1/2;
end  

% Return the final value of the iteration
x

This m-file is called ,. It is not a function but only a simple script that Matlab can execute. With a deeper knowledge of Matlab, we can write much more sophisticated programs but this example is enough to understand the basic of programming in Matlab.

If we run fxpt1 in Matlab, then it executes \(20\) iterations of the function \(\displaystyle x \mapsto -(x^2/8) - x/4 + 1/2\) starting with \(x = 0.5\) and return the \(\displaystyle 20^{th}\) iteration.

>> fxpt1

x = 

    0.3852

However, the script above is not convenient because we have to modify the file fxpt1.m each time that the function to be iterated, the initial value or the number of iterations are modified.

Example (continued): The function fxpt2 defined in the file takes as arguments the name or handle of the function to iterate, the initial value and the number of iterations.

% y = fxpt2(funct,x0,n)
%
% This function returns the result of n iterations of the function
% y = funct(x) starting with the value x = x0 .
function y = fxpt2(funct,x0,n)
    y = x0;
    for i=1:n
      y = feval(funct,y);
    end
end

To execute \(20\) iterations of the function \(\displaystyle x \mapsto -(x^2/8) - x/4 + 1/2\) starting with \(x = 0.5\), we define the function funct3 by creating the m-file with the following content.

% y = funct3(x)
%
% This function takes one argument x and return the result of the
% computation  -(x.^2/8) - x/4 + 1/2 .
function y = funct3(x)
   y = -(x.^2/8) - x/4 + 1/2;
end

The function fxpt2 can then be invoked with the arguments @funct3 or 'funct3', 0.5 and 20.

>> fxpt2(@funct3,0.5,20) 

ans = 

    0.3852

Note: If we had used the line y = funct(y); instead of the line y = feval(funct,y); in the previous script, then the function fxpt2 would have only accepted function handles as its first argument. By using the function feval(), function names can also be given as first argument of the function fxpt2.

Instead of defining funct3 using a m-file, we could have simply defined an anonymous function as it follows. 

>> Hfunct3 = @(x) -(x.^2/8) - x/4 + 1/2;

This way, it is now easy to modify the function to be iterated.

File Management and Batch Mode in Matlab

Matlab provides several files management commands that allow users to list, view and delete m-files, to view the content of a directory/folder, to change the current directory/folder, etc. A summary of some commands is given in the following table.

Command Description
what Display a list of all m-files in the current directory.
dir List all files in the current directory.
type file_name Display the content of the m-file file_name.m.
delete file_name Delete the m-file file_name.m.
cd path Change the current directory to the directory/folder given by path.
cd Show present working directory/folder.
which funct_name Display the directory path to the m-file funct_name.m.

It is also very simple to execute a Matlab script in batch mode on a computer running Linux/Unix. For instance, to execute the script my_code.m in batch mode, it suffices to enter the following command at the prompt of a terminal.

% nice +19 matlab -nosplash < my_code.m > my_code.log

The nice command is a Linux/Unix command to change the priority of execution of the program to be executed. The argument +19 lowers the priority of execution of the program so that it does not monopolize the CPU of the computer. The output of the program is sent to the file my_code.log. The option -nosplash cancels the display of the welcoming message when Matlab is launched.
