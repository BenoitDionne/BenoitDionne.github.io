Calculs numériques

Contenu

Ce document illustre une minuscule portion du genre de calcul numériques qui peuvent être faits avec Matlab. La version de base de Matlab n'a pas des millions de fonctions prédéfinies. Les concepteurs de Matlab assument que les utilisateurs vont définir les fonctions qu'ils ou elles ont besoin. La programmation dans Matlab est donc essentielle. Il y a cependant un très grand nombre des boîtes à outils sur toutes sortes de sujets. Ces boîtes à outils sont ajoutées à l'installation de basse de Matlab et étendent énormément le choix de fonctions. Nous ne parlerons pas des boîtes à outils dans notre introduction à Matlab. Une des raisons principales est que chaque boîte à outils doit être achetée séparément. Ceci peut être dispendieux.

Intégration numérique

Il y a deux principales fonctions de Matlab pour l'intégration numérique d'une fonction: trapz et integral (avec integral2 et integral3 pour les intégrales sur les sous-ensembles de \(\mathbb{R}^2\) et \(\mathbb{R}^3\) respectivement). La fonction trapz utilise la méthode des trapèzes pour estimer l'intégral d'une fonction .

Exemple: Nous utilisons la méthode des trapèzes pour estimer l'aire sous la courbe \(y = x \sin(x)\) pour \(0 < x < \pi\) avec \(10\) sous-intervalles. Nous utilisons les \(11\) points également distancés donnés dans la liste suivante.

>> x = linspace(0,pi,11)

x = 

  Columns 1 through 7 

          0    0.3142    0.6283    0.9425    1.2566    1.5708    1.8850 

  Columns 8 through 11 

    2.1991    2.5133    2.8274    3.1416

L'étape suivante consiste à évaluer \(x \sin(x)\) à chacune des composantes de la liste x (les composantes de x sont les points du maillage de l'intervalle \([0.\pi]\).) 

>> y = x .* sin(x);

La somme pour la méthode des trapèzes est calculée avec la commande suivante. 

>> trapz(x,y) 

ans = 

    3.1157

La fonction integral est une version de d'une méthode adaptative de quadrature. Afin d'utiliser cette fonction, il faut définir de nouvelles fonctions à l'aide des fichiers m ou de définir des fonctions anonymes.

Exemple: Pour estimer l'aire sous la courbe \(y = x \sin(x)\) pour \(0 \leq x \leq \pi\), nous utilisons la fonction funct1 que nous avons définie dans le document . Pour évaluer numériquement l'intégrale de \(x \sin(x)\) sur l'intervalle \(0 \leq x \leq \pi\), nous utilisons la commande suivante.

>> integral(@funct1,0,pi)
ans = 

    3.1416

Le format minimal de la fonction integral est

integral(@Funct, a, b, 'propriété1', valeur1, 'propriété2', valeur2, ...);
où Funct est le nom d'une fonction définie pour \(a \leq x \leq b\), l'intervalle d'intégration. Par exemple, pour spécifier une borne supérieure pour l'erreur relative ou pour l'erreur absolue, il suffit d'utiliser une commande de la forme integral(@Funct,a,b,'RelTol',valeur1,'AbsTol',valeur2) où valeur1 est la nouvelle borne supérieure pour l'erreur relative et valeur2 est la nouvelle borne supérieure pour l'erreur absolue..

Exemple: Nous voulons estimer la valeur de l'intégrale de \(\displaystyle f(x) = \sqrt{x} + 2 \sin(1/x^2) + 1\) pour \(1 \leq x \leq 5\).

Au lieu de créer un fichier m pour la fonction \(f\), nous définissons une fonction anonyme qui est seulement représentée par son anse que nous sauvegardons dans une variable comme il est fait ci-dessous.

>>  f = @(x) sqrt(x) + sin(1./x.^2) + 1

f = 

    @(x) sqrt(x) + sin(1 ./ x .^ 2) + 1

Cette anse peut alors être utilisée avec la fonction integral. La commande suivante illustre comment cela est fait. Nous exigeons une erreur relative d'au plus \(10^{-6}\).

>> integral(f,1,5,'RelTol',10^(-6)) 

ans =  

     11.55448141551789

Exemple: Nous voulons estimer la valeur de l'intégrale de \(\displaystyle f(x,y) = x^2 y^2\) sur le disque de rayon 2 centré à l'origine.

Première méthode: Nous calculons en premier l'intégrale

\[ \int_{-2}^2 \int_{-\sqrt{4-x^2}}^{\sqrt{4-x^2}} f(x,y) \text{d} y \text{d} x \ . \]

Pour calculer cette intégrale à l'aide de Matlab, nous exécutons les commandes suivantes.

>> format long; ...
   f = @(x,y) x.^2 .* y.^2; ...
   ymax = @(x) sqrt(4-x.^2); ...
   ymin = @(x) -sqrt(4-x.^2); ...
   integral2(f, -2,2, ymin, ymax,'Method','iterated')

ans = 

   8.377580360000902

Deuxième méthode: Nous calculons l'intégrale précédente à l'aide des coordonnées polaires. C'est-à-dire, nous posons \(x = r \cos(\theta)\) et \(y = r \sin(\theta)\) pour \(0 \leq r \leq 2\) et \(0 \leq \theta \leq 2\pi \), et calculons l'intégrale

\[ \int_0^2 \int_0^{2\pi} f(r\cos(\theta),r\sin(\theta)) r \text{d} \theta \text{d} r \ . \]

Pour calculer cette intégrale à l'aide de Matlab, nous exécutons les commandes suivantes.

>> X = @(r,theta) r.*cos(theta); ...
   Y = @(r,theta) r.*sin(theta); ...
   frt = @(r,theta) f(X(r,theta),Y(r,theta)); ...
   frtD = @(r,theta) f(X(r,theta),Y(r,theta)).*r; ...
   integral2(frtD, 0,2, 0, 2*pi,'Method','tiled')

ans = 

   8.377580409572781

Il y a trois options pour la propriété Method: auto, tiled et iterated. Nous choisissons l'option tiled quand nous voulons que l'intégrale soit calculée avec des sommes partielles sur des petits rectangles comme cela est fait pour la définition de l'intégrale de fonctions de deux variables et plus. Nous choisissons l'option iterated quand nous voulons que l'intégrale soit calculer comme une intégrale double ou triple.

Équations différentielles ordinaires (EDO)

Trois des fonctions de Matlab pour résoudre les (systèmes d') EDO (non-raides) d'ordre un sont ode23, ode45 et ode113 (Octave n'a pas la fonction ode113 mais offre la fonction ode115s en remplacement). Ce sont des méthodes à pas variables dérivées des méthodes de Runge-Kutta. Ils font partis de la famille de solveurs d'EDO de Matlab. Pour obtenir de l'aide au sujet d'un solveur et/ou une liste des autres solveurs de Matlab pour résoudre les EDO, il suffit d'utiliser la commande help ode23 par exemple. Le nom ode23 peut être remplacé par tout autre nom de solveur d'EDO de Matlab.

Nous allons seulement expliquer la procédure pour utiliser le solveur ode45. Cependant, la procédure pour utiliser les autres solveurs d'EDO de Matlab est très semblable.

Le format du solveur ode45 est [xx,yy] = ode45(@f ,[x_zero , x_final], y0, options) .

La fonction f (qui dépend de \(x\) et \(y\)) est le côté droit de l'EDO \(y'(x) = f(x,y)\). La valeur x_zero est le temps initial et la valeur x_final est le temps quand arrêter l'intégration numérique. L'expression y0 est un vecteur rangée avec les valeurs initiales de \(y\) à x_zero. Une solution est calculée pour chacune des conditions initiales.

Le vecteur xx et la matrice yy que ode45 retourne ont le même nombre de rangées. Le nombre de colonnes de la matrice yy est égale à la longueur du vecteur rangée y0. La \(\displaystyle i^{e}\) colonne de yy est l'estimé à chacune des valeurs de xx de la solution \(y\) de \(y'(x) = f(x,y)\) avec la condition initiale à x_zero donnée par la \(\displaystyle i^{e}\) composante de y0. La \(\displaystyle k^{e}\) rangée de yy est une approximation de la solution \(y\) de \(y'(x) = f(x,y)\) évaluée à la \(\displaystyle k^{e}\) composante de xx pour chacune des conditions initiales données par les composantes de y0 à x_zero.

Il y a un grand nombre d'options qui peuvent être fournies aux solveurs d'EDO de Matlab. Pour fournir une borne sur la tolérance relative, une borne sur la tolérance absolue, etc, nous devons premièrement définir une structure d'options comme celle ci-dessous.

>>  option = odeset('reltol', 0.001, 'abstol', [0.000001])

Seulement les bornes sur la tolérance relative et la tolérance absolue ont été incluses dans l'exemple précédent mais il y a beaucoup plus d'options qui peuvent être incluses selon le solveur d'EDO utilisé pour résoudre numériquement l'EDO.

Exemple: Nous voulons estimer la solution de l'EDO \(y'(x) = f(x,y) = x \sin(x)\) pur \(0 \leq x \leq \pi\) à l'aide du solveur ode45. La condition initial est \(y(0) = 0\) et la borne supérieure sur la tolérance relative est de \(\displaystyle 10^{-5}\). Nous avons déjà défini à l'aide du fichier m funct1.m une fonction \(x \mapsto x \sin(x)\). Cependant, cette fonction funct1 ne peut pas être utilisée avec le solveur ode45 car la fonction funct1 dépend seulement de \(x\). Le côté droit d'une EDO \(y'(x)= \ldots\) doit être une fonction de \(x\) et \(y\).

La fonction funct1 est redéfinie pour obtenir la nouvelle fonction funct2 définie dans le fichier funct2.m. Le fichier m contient les lignes de code suivantes:

% yprime = funct2(x,y)
%
% This function takes two arguments, x and y, and returns the
% result of the computation  x sin(x)
function yprime = funct2(x,y)
     yprime = x.*sin(x);
end

La seule option qui est fournie au solveur ode45 est la borne supérieure \(\displaystyle 10^{-5}\) pour la tolérance relative.

>> options = odeset('reltol',10^(-5));

Finalement, nous pouvons utiliser le solveur ode45 pour résoudre numériquement l'EDO \(y' = f(x,y)\) pour \(0 \leq x\leq \pi\) avec la condition initiale \(y(0) = 0\).

Ce n'est pas très sage d'énumérer les valeurs de [xx,yy] en raison du grand nombre possible de valeurs retournées par le solveur. Il est préférable de tracer l'interpolation linéaire de la solution en utilisant les données fournies par [xx,yy].

>> plot(xx,yy);

Question Mathématique: Quelle est la relation entre la solution de l'EDO \(y' = x\sin(x)\) et l'intégral de la fonction \(f(x) = x \sin(x)\) sur l'intervalle \([0,\pi]\)?

À l'aide de l'interpolation linéaire construite à partir des données fournies par [xx,yy], nous pouvons estimer la valeur de la solution de l'EDO à tous points de l'intervalle \([0,\pi]\).

Exemple: Une valeur approximative de la solution de l'EDO précédente à \(x=2\) est donnée par la comande

>> w = interp1(xx,yy,2,'linear') 

w = 

    1.7416
