Introduction à Matlab

Contenu

Ce document explique à l'aide d'exemples comment exécuter à l'aide de Matlab plusieurs types de calculs et cela inclu la résolution d'équations différentielles ordinaires. Une description détaillée de Matlab (fonctions, commandes, librairies, ...) se trouve sous le menu d'aide de Matlab. Nous pouvons aussi obtenir de l'aide à partir de la fenêtre de commande de Matlab en tapant la commande help sujet après le prompt de Matlab suivi de la touche Enter. Le mot sujet peut être le nom d'une fonction, d'une commande ou d'une librairie. La commande help affiche les noms de fonctions en lettres majuscules (e.g. QUADL, ODE113, ...). Les noms de fonctions doivent être tapés en lettres minuscules dans la fenêtre de commande de Matlab (e.g. quadl, ode113, ...).

Presque toute l'information fournie dans ce document est aussi valide pour Octave. La présentation des résultats d'un calcul avec Octave peut de temps à autre être différente de la présentation des mêmes résultats avec Matlab. Un petit nombre de fonctions de Matlab ne se retrouvent pas dans Octave. Nous mentionnons une de ces fonctions dans la section portant sur la résolution d'équations différentielles ordinaires ci-dessous. Dans de tels cas, il y a normalement une fonction de Octave qui effectue le même ouvrage.

Pour chacun des exemples dans cette introduction à Matlab, nous donnons le code qui doit être exécuté et affichons le résultat après avoir exécuté le code dans Matlab.

Dans ce document, le texte en bleu est le code qui doit être tapé après le prompt dans Matlab.

Démarrer Matlab

Pour démarrer Matlab à partir d'un ordinateur géré par Linux/Unix, il suffit de taper matlab après le prompt d'un terminal suivi de la touche Enter. Pour un ordinateur géré par Windows, il suffit de cliquer sur l'icône Matlab ou de choisir Matlab dans le menu. Dans tous les cas, nous obtenons une nouvelle fenêtre avec le prompt de Matlab.

Sauvegarder les sessions de Matlab

Par défaut, Matlab sauvegarde toutes les commandes dans la fenêtre pour l'historique des commandes.

Cependant, il est parfois utile de sauvegarder en partie ou en entier les commandes et résultats d'une session dans un fichier afin de les utiliser plus tard pour produire une session dans Matlab.

Pour sauvegarder une session sur Matlab (ou une partie d'une session), il suffit d'exécuter la commande diary. Après cela, Matlab sauvegarde toutes les commandes et résultats dans un fichier qui normalement porte le nom de diary. Pour sauvegarder les commandes et résultats dans un fichier appelé devoir1 par exemple, il suffit d'exécuter la commande diary devoir1. Après cela, toutes les commandes et résultats sont sauvegardés dans le fichier devoir1 qui se trouve dans le répertoire d'où Matlab a démarré. Pour arrêter de sauvegarder les commandes et résultats, il suffit d'exécuter diary off. Pour reprendre la sauvegarde des commandes et résultats dans le fichier devoir1, il suffit d'exécuter la commande diary on. Les nouvelles commandes et nouveaux résultats sont ajoutés au contenu déjà existant du fichier devoir1.

Gestion de fichiers et Batch Mode dans Matlab

Matlab possède plusieurs commandes pour gérer les fichiers qui permet à l'utilisateur d'énumérer, de lire et de supprimer les fichiers m, de lire le contenu d'un répertoire, de changer le répertoire présentement utilisé, etc. Un résumé de certaines commandes est fourni dans le tableau ci-dessous.

Commande Description
what Affiche une liste de tous les fichiers m dans le répertoire présentement utilisé.
dir Affiche une liste de tous les fichiers dans le répertoire présentement utilisé.
type nom_do_fichier Affiche le contenu du fichier m nom_du_fichier.m.
delete nom_du_fichier Supprime le fichier m nom_du_fichier.m.
cd emplacement Remplacer le répertoire présentement utilisé par celui associé à l'emplacement donné.
cd Affiche le répertoire présentement utilisé .
which nom_de_la_fonction Affiche l'emplacement du fichier m nom_de_la_fonction.m.

Il est aussi facile d'exécuter un script de Matlab en batch mode sur un ordinateur dont le système d'opération est Linux/Unix. Par exemple, pour exécuter le script my_code.m en batch mode, il suffit d'exécuter la commande suivante après le prompt d'un terminal.

% nice +19 matlab -nosplash < my_code.m > my_code.log

La commande nice est une commande de Linux/Unix pour changer la priorité d'exécution du programme qui doit être exécuté. L'argument +19 abaisse la priorité d'exécution de telle sorte que le programme ne monopolise par l'unité de calcul de l'ordinateur. Le résultat du programme est emmagasiné dans le fichier my_code.log. L'option -nosplash annule l'affichage du message de bienvenue quand Matlab est démarré.
