Introduction à Matlab

Contenu

Ce document explique à l'aide d'exemples comment exécuter à l'aide de Matlab plusieurs types de calculs et cela inclu la résolution d'équations différentielles ordinaires. Une description détaillée de Matlab (fonctions, commandes, librairies, ...) se trouve sous le menu d'aide de Matlab. Nous pouvons aussi obtenir de l'aide à partir de la fenêtre de commande de Matlab en tapant la commande help sujet après le prompt de Matlab suivi de la touche Enter. Le mot sujet peut être le nom d'une fonction, d'une commande ou d'une librairie. La commande help affiche les noms de fonctions en lettres majuscules (e.g. QUADL, ODE113, ...). Les noms de fonctions doivent être tapés en lettres minuscules dans la fenêtre de commande de Matlab (e.g. quadl, ode113, ...).

Presque toute l'information fournie sur ce site est aussi valide pour Octave. La présentation des résultats d'un calcul avec Octave peut de temps à autre être différente de la présentation des mêmes résultats avec Matlab. Un petit nombre de fonctions de Matlab ne se retrouvent pas dans Octave. Nous mentionnons une de ces fonctions dans la section portant sur la résolution d'équations différentielles ordinaires ci-dessous. Dans de tels cas, il y a normalement une fonction de Octave qui effectue le même ouvrage.

Pour chacun des exemples dans cette introduction à Matlab, nous donnons le code qui doit être exécuté et affichons le résultat après avoir exécuté le code dans Matlab.

Dans ce document, le texte en bleu est le code qui doit être tapé après le prompt dans Matlab.

Démarrer Matlab

Pour démarrer Matlab à partir d'un ordinateur géré par Linux/Unix, il suffit de taper matlab après le prompt d'un terminal suivi de la touche Enter. Pour un ordinateur géré par Windows, il suffit de cliquer sur l'icône Matlab ou de choisir Matlab dans le menu. Dans tous les cas, nous obtenons une nouvelle fenêtre avec le prompt de Matlab.

>>

Le curseur est positionné juste après le prompt de Matlab et attend que l'utilisateur tape ses instructions.

Opérations arithmétiques de base

Les opérations arithmétiques de base sont:

Opération Description
+ addition
- soustraction
* multiplication
/ division à droite
\ division à gauche
^ exponentiel
( ) parenthèses

Matlab effectue les opérations arithmétiques dans l'ordre de priorité suivant.

  1. Parenthèses
  2. Exponentiel
  3. Multiplications et divisions
  4. Additions et soustractions

Quand deux opérations sont au même niveau de priorité, Matlab exécute les opérations de gauche à droite. L'exponentiel est une exception car Matlab exécute ces opérations de droite à gauche.

Exemple: Pour calculer \(\displaystyle 16.07(42.5 + 387 / 23.8) + 3.6^2\), tapez

>>  16.07*(42.5+387/23.8) + 3.6^2

suivi de la touche Enter (nous ne répéterons plus suivi de la touche Enter mais cela doit toujours être exécuté) pour obtenir le résultat suivant.

ans = 

  957.2413

Le résultat est sauvegardé dans la variable ans.

Exemple: L'exemple suivant montre comment assigner le résultat du calcul précédent à la variable x .

>> x = 16.07*(42.5+387/23.8) + 3.6^2

x = 

   957.2413

Si nous ajoutons un point-virgule à la fin d'une commande, alors Matlab exécute la commande mais n'affiche pas le résultat.

>> x = 10 + pi;
>> x

x = 

   13.1416

Nombre de chiffres significatifs affichés

Le nombre de chiffres significatifs affichés sur l'écran peut être augmenté pour répondre au besoin de l'utilisateur. Par défaut, les nombres qui ne sont pas des entiers sont affichés dans un format court qui contient seulement cinq chiffres significatifs. Les calculs sont cependant fait en utilisant le nombre maximum de chiffres décimaux que Matlab peut utiliser.

Exemple: Le cosinus de \(3\) radians est donné par:

>> cos(3) 

ans = 

   -0.9900
Le cosinus de \(1.57\) radians est donné par:

>> cos(1.57) 

ans = 

   7.9633e-04

Si nous désirons avoir plus de chiffres significatifs, alors nous pouvons utiliser le format long qui contient seize chiffres significatifs. Pour changer au format long, il suffit d'exécuter la commande format long.

Exemple: Le cosinus de \(1.57\) radians dans le format long est donné par:

>> format long
>> cos(1.57) 

ans = 

      7.963267107332633e-04

Pour retourner au format court, il suffit d'exécuter la commande format short. Pour voir tous les formats possibles dans Matlab, il suffit d'exécuter la commande help format. Il est aussi possible de produire des affichages plus élégants à l'aide de la fonction sprintf.

Nombres complexes

Pour taper un nombre complexe dans Matlab, nous utilisons la notation traditionnelle:

>> z = 5 - 7i

z = 

   5.0000 - 7.0000i

La table des opérations arithmétiques sur les nombres réels présentée ci-dessus est aussi valide pour les nombres complexes.

Exemple: Le produit de \(5 + 3i\) est \(5 - 3i\) est donné par:

>> z = 5 - 3i;
>> zbar = 5 + 3i;
>> w1 = z * zbar

w1 = 

    34

La division de \(5 + 3i\) par \(5 -3i\) est donnée par:

>> w2 = z / zbar

w2 = 

   0.4706 - 0.8824i

Sauvegarder les sessions de Matlab

Par défaut, Matlab sauvegarde toutes les commandes dans la fenêtre pour l'historique des commandes.

Cependant, il est parfois utile de sauvegarder en partie ou en entier les commandes et résultats d'une session dans un fichier afin de les utiliser plus tard pour produire une session dans Matlab.

Pour sauvegarder une session sur Matlab (ou une partie d'une session), il suffit d'exécuter la commande diary. Après cela, Matlab sauvegarde toutes les commandes et résultats dans un fichier qui normalement porte le nom de diary. Pour sauvegarder les commandes et résultats dans un fichier appelé devoir1 par exemple, il suffit d'exécuter la commande diary devoir1. Après cela, toutes les commandes et résultats sont sauvegardés dans le fichier devoir1 qui se trouve dans le répertoire d'où Matlab a démarré. Pour arrêter de sauvegarder les commandes et résultats, il suffit d'exécuter diary off. Pour reprendre la sauvegarde des commandes et résultats dans le fichier devoir1, il suffit d'exécuter la commande diary on. Les nouvelles commandes et nouveaux résultats sont ajoutés au contenu déjà existant du fichier devoir1.

Matrices dans Matlab

En fait, toutes les valeurs numériques dans Matlab sont traitées comme des matrices de nombres complexes. Par exemple, le nombre \(5\) dans Matlab est une matrice de dimension \(1\times 1\).

Pour définir une matrice dans Matlab, il suffit de taper toutes les composantes de la matrice entre une pair de crochets (parenthèses carrées). La virgule et l'espace sont utilisés pour séparer les composantes d'une rangée, et le point-virgule et le changement de ligne sont utilisés pour séparer les rangées de la matrice.

Exemple: Pour définir dans Matlab la matrice

\[ A = \begin{pmatrix} 1 & \pi & 0 \\ 0 & 4 & 5 \end{pmatrix} \]

de dimension \(2\times 3\), il suffit de taper une des commandes suivantes:

>> A = [ 1 pi 0; 0 4 5 ] 

A = 

     1.0000    3.1416         0
          0    4.0000    5.0000

ou

>> A = [ 1 pi 0
0 4 5 ]

A = 

     1.0000    3.1416         0
          0    4.0000    5.0000

La commande size peut être utilisé pour obtenir les dimensions d'une matrice.

Exemple: Si nous utilisons la matrice \(A\) de l'exemple précédent, on obtient

>> size(A)

ans = 

      2     3

Les vecteurs sont des matrices spéciales

Les vecteurs sont des matrices avec une seule rangée ou colonne. Nous les appelons des vecteurs rangées et vecteurs colonnes respectivement.

Exemple: Le vecteur suivant est un vecteur colonne.

>> V = [1 ; 2 ; -5 ; 3]

V = 

      1
      2
     -5
      3

Ce vecteur est de longueur \(4\) (il a quatre composantes).

>> length(V) 

ans = 

      4

Exemple: Le vecteur suivant est un vecteur rangée de longueur \(4\).

>> U = [sin(2) , -5 , 0 , 1] 

U = 

     0.9093   -5.0000         0    1.0000

Algèbre matricielle

Toutes le opérations usuelles peuvent être exécutées par Matlab.

Opération Description
+ addition de matrices de même dimensions
- soustraction de matrices de même dimensions
* multiplication de deux matrices où le nombre de colonnes de la première matrice égale le nombre de rangées de la deuxième matrice
^ exponentiel d'un matrice carrée
( ) parenthèses

Il y a deux autres opérations sur les matrices.

Opération Description
/ \(A/B\) est \(A\) multiplié par l'inverse de \(B\) si cette dernière matrice est inversible et si le nombre de colonnes de \(A\) égale le nombre de rangées de \(B\).
\ \(A\backslash B\) est la matrice \(X\) qui est la solution (à l'aide de la méthode d'élimination de Gauss) de \(AX = B\) quand \(A\) est une matrice inversible de dimensions \(n \times n\) et \(B\) a \(n\) rangées. \(A\backslash B\) est la solution par la méthode du moindre carré de \(AX = B\) quand \(A\) est une matrice de dimension \(m \times n\) avec \(m \neq n\) et \(B\) a \(m\) rangées. Utilisez le menu d'aide pour obtenir plus d'information.

Exemple: En plus des matrices et vecteurs définis précédemment, nous considérons les matrices suivantes:

>> C = [-1 -2 0 ; 0 1 2 ; 1 0 3]

C =

      0     1     2
      1     0     3

>> B = [ -2 0 5
  2 3 -1
  0 1 2 ]

B = 

     -2     0     5
      2     3    -1
      0     1     2

Voici quelques opérations sur les matrices.

>> D = B + C

D = 

     -3    -2     5
      2     4     1
      1     1     5 

>> M = A * B 

M = 

     4.2832    9.4248    1.8584
     8.0000   17.0000    6.0000

>> W = U * V

W = 

    -6.0907

D'autres opérations sur les matrices peuvent être exécutées avec Matlab.

Exemple: L'inverse et le déterminant de la matrice \(B\) qui a été définie ci-dessus sont calculés par les commandes suivantes.

>> inv(B)

ans = 

   -1.7500   -1.2500    3.7500
    1.0000    1.0000   -2.0000
   -0.5000   -0.5000    1.5000 

>> det(B)

ans = 

    -4

Opérations sur les tableaux

Les opérations sur les tableaux sont des opérations sur les matrices qui agissent composante par composante.

  • .*  Multiplication de deux matrices de même dimensions. Les composantes des deux matrices ayant les mêmes indices sont multipliées.
  • .^  Exponentiel d'une matrice. L'exponentiel de chacune des composantes de la matrice est calculé.
  • ./  Division de deux matrices de même dimensions. Chaque composante de la première matrice est divisée par la composante de la deuxième matrice ayant les mêmes indices.

Exemple:

>> v1=[1 2 3];
>> v2=[2 2 2];
>> v1 .* v2

ans = 

     2     4     6

>> v1 ./ v2

ans = 

     0.5000    1.0000    1.5000 

>> A = [1 2 3 ; 3 2 1] 

A = 

     1     2     3
     3     2     1 

>> A.^2

ans = 

     1     4     9
     9     4     1

Toutes les fonctions définies par Matlab sont array smart. Cela veut dire que lorsque que l'argument d'une fonction est une matrice \(A\) alors la fonction est évaluée à chacune des composantes de la matrice \(A\).

Exemple: Si nous utilisons la matrice \(A\) définie ci-dessus et calculons \(sin(A)\), nous obtenons le résultat suivant. 

>> sin(A)

ans = 

    0.8415    0.9093    0.1411
    0.1411    0.9093    0.8415

Tracer en deux dimensions avec Matlab

Supposons que nous voulons tracer le graphe d'une fonction \(f\) définie sur un intervalle \([a,b]\).

La première étape est de créer une liste x dont les composantes forment une partition de l'intervalle \([a,b]\). Nous utilisons bien souvent \(N + 1\) points également distancés de l'intervalle \([a,b]\). Une façon de créer une telle liste est avec la commande x = a : h : b où h = (b-a)/N. Une autre façon de créer une telle liste est avec la commande x = linspace(a,b,N+1).

Exemple: On considère la fonction \(f\) définie par \(\displaystyle y = f(x) = x^3\) sur l'intervalle \([0,1]\). Les deux exemples suivants illustrent comment générer \(11\) points également distancés (\(10\) sous-intervalles) incluant les deux points limites de l'intervalle.

>> x = 0:0.1:1 

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 
 
     0.7000    0.8000    0.9000    1.0000

ou

>> x = linspace(0,1,11)

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 

     0.7000    0.8000    0.9000    1.0000

Pour évaluer la fonction \(f\) définie par \(\displaystyle f(x) = x^3\) aux \(11\) points que l'on vient de générer, une simple opération sur les tableaux suffit.

>> y = x.^3 

y = 

   Columns 1 through 7 

          0    0.0010    0.0080    0.0270    0.0640    0.1250    0.2160 

   Columns 8 through 11 

     0.3430    0.5120    0.7290    1.0000

Chacune des composantes de y est le cube de la composante corresponde de x. Finalement, nous fessons appel à la fonction plot de Matlab pour tracer le graphe de \(f\) sur l'intervalle \([0,1]\). La fonction plot utilise une interpolation linéaire entre les \(11\) points également distancés pour approcher le graphe de la fonction \(f\).

>> plot(x,y)

Après avoir pressé la touche Enter, une nouvelle fenêtre s'ouvre avec une figure contenant le graphe de la fonction.

Nous obtenons un graphe plus précis de la fonction en utilisant plus de points également distancés.

Il est possible de tracer le graphe de plus d'une fonction dans la même figure. La commande hold on après avoir produit la première figure force Matlab à tracer les graphes suivants dans la figure existante. La commande hold off retourne Matlab à son mode par défaut qui est de remplacer la présente figure par une nouvelle figure.

Exemple: À l'aide de la variable x définie ci-dessus et en assumant que la figure précédente existe toujours (i.e. elle n'a pas été fermée), Les commandes suivantes ajoutent la droite \(y = x + 2\) à la figure contenant le graphe de \(f\).

>> hold on
>> z = x + 2;
>> plot(x,z,'r')

La figure est maintenant

Dans l'exemple précédent, le résultat de l'expression z = x + 2 dans Matlab est d'additionner la valeur \(2\) à chacune des composantes de x et d'emmagasiner les résultats dans la variable z. La \(\displaystyle i^{e}\) composante de z est la somme de la \(\displaystyle i^{e}\) composante de x et de \(2\). C'est un des comportement anormal de Matlab.

L'option 'r' de la commande plot précédente force Matlab à tracer la droite \(y = x + 2\) en rouge.

Un titre et des étiquettes pour les axes peuvent être ajoutés à la figure à l'aide des fonctions title pour produire le titre, xlabel pour ajouter une étiquette à l'axe des \(x\) et ylabel pour ajouter une étiquette à l'axe des \(y\). L'exemple suivant montre comment utiliser ces fonctions.

Exemple: Supposons que les commandes suivantes font parties de la session qui a produit la figure précédente et que cette figure existe toujours (i.e. elle n'a pas été fermée).

>> title('sample plotting with MATLAB')
>> xlabel('x-axis')
>> ylabel('y-axis')

Le résultat de ces commandes est l'ajout du titre sample plotting with MATLAB et des étiquettes aux axes de la figure précédente pour obtenir la figure suivante.

Interpolationo

L'interpolation polynomiale peut être utilisée avec Matlab.

Exemple: Nous traçons l'interpolation linéaire de la fonction \(f\) associée aux données dans le tableau ci-dessous.

\[ \begin{array}{|l|r|r|r|r|r|} \hline x & 0 & 0.7854 & 1.5708 & 2.3562 & 3.1416 \\ \hline y & 0 & 0.5554 & 1.5708 & 1.6661 & 0.0000 \\ \hline \end{array} \]

Les données pour \(x\) et \(y\) sont représentées par deux vecteurs dans Matlab.

>> x = [ 0  0.7854  1.5708  2.3562  3.1416 ] 

x = 

         0    0.7854    1.5708    2.3562    3.1416 

>> y = [ 0  0.5554  1.5708  1.6661  0.0000 ]

y = 

         0    0.5554    1.5708    1.6661         0

Il est en fait plus facile de tracer l'interpolation linéaire de \(f\) que d'évaluer \(f\) à des points. Si nous assumons que la figure précédente n'est plus présente (ou que la commande hold off a été utilisée), alors la commande suivante trace l'interpolation linéaire de \(f\).

>> plot(x,y);

Le graphe de l'interpolation linéaire de \(f\) est représenté dans la figure ci-dessous.

L'interpolation linéaire de \(f\) peut être évaluée à plusieurs points à l'aide de la fonction interp1 de Matlab. Supposons que nous voulions évaluer l'interpolation linéaire de la fonction \(f\) aux points \(0, \pi/10 , \pi/5 , 3\pi/10, \ldots, \pi\). Nous pouvons représenter ces points dans Matlab à l'aide de la liste suivante.

>> z = linspace(0,pi,11)

z = 

   Columns 1 through 9 

       0    0.3142    0.6283    0.9425    1.2566    1.5708    1.8850   2.1991    2.5133 

   Columns 10 through 11 

       2.8274    3.1416

La commande suivante dans Matlab calcul la valeur de l'interpolation linéaire de \(f\) aux \(11\) points également distancés donnés par z.

>> w = interp1(x,y,z,'linear') 

w = 

   Columns 1 through 9 

       0    0.2222    0.4443    0.7585    1.1646    1.5708    1.6089    1.6470    1.3329 

   Columns 10 through 11 

       0.6665    0.0000

La \(\displaystyle k^{e}\) composante de w est la valeur de l'interpolation linéaire de la fonction \(f\) à la \(\displaystyle k^{e}\) composante de z. Les commandes suivantes tracent les points de coordonnées \((x,y)\) où \(x\) et \(y\) sont les \(\displaystyle k^{e}\) composantes de z et w respectivement pour \(k = 1, 2, \ldots, 11\).

>> hold on
>> plot(z,w,'or');

Le troisième argument de plot ci-dessus force Matlab à tracer seulement un cercle rouge pour chacun des points.

Il y a d'autres méthodes d'interpolation que linéaire (le défaut) comme cubique et spline. Pour utiliser ces méthodes, il suffit de suivre les même étapes que nous avons présentées dans l'exemple précédant mais en remplaçant linear par cubic ou spline. Le lecteur devrait essayé ces méthodes avec l'exemple précédent afin de comparer ces méthodes.

Intégration numérique

Il y a trois principales fonctions de Matlab pour l'intégration numérique d'une fonction: trapz, quad et quadl. La fonction trapz utilise la méthode des trapèzes pour estimer l'intégral d'une fonction .

Exemple: Nous utilisons la méthode des trapèzes pour estimer l'aire sous la courbe \(y = x \sin(x)\) pour \(0 < x < \pi\) avec \(10\) sous-intervalles. Nous utilisons les \(11\) points également distancés donnés dans la liste suivante.

>> x = linspace(0,pi,11)

x = 

  Columns 1 through 7 

          0    0.3142    0.6283    0.9425    1.2566    1.5708    1.8850 

  Columns 8 through 11 

    2.1991    2.5133    2.8274    3.1416

L'étape suivante consiste à évaluer \(x \sin(x)\) à chacune des composantes de la liste x (les composantes de x sont les points qui forment la partition de l'intervalle \([0.\pi]\).) 

>> y = x .* sin(x);

La somme pour la méthode des trapèzes est calculée avec la commande suivante. 

>> trapz(x,y) 

ans = 

    3.1157

La fonction quad est une version de la méthode adaptative de Simpson et la fonction quadl est une version de la méthode adaptative de Newton-Cotes. Afin d'utiliser ces deux fonctions, il faut être en mesure de définir de nouvelles fonctions à l'aide des fichiers m ou de définir des fonctions anonymes. Ce sont les sujets des deux prochaines sections.

Fichiers m

Matlab a une grande collection de fonctions mathématiques déjà définies. Il est aussi facile de créer nos propres fonctions. L'exemple suivant illustre comment créer une fonction.

Exemple: L'exemple suivant explique comment créer la fonction funct1 qui est définie par \(x \mapsto x \sin(x)\).

Premièrement, un fichier nommé funct1.m est créé à l'aide d'un éditeur de texte ascii. La première ligne contient l'énoncer function y = funct1(x), la deuxième ligne contient la formule y = x.*sin(x); et la dernière ligne l'énoncer end. Il n'y a rien de plus à ajouter à ce fichier.

Nous pouvons ajouter des commentaires au fichier m ci-dessus. Le texte sur une ligne qui suit le caractère % est ignoré par Matlab.

Voici le contenue du fichier m .

% y = funct1(x)
%
% This function takes one argument x and returns the result of the
% computation  x sin(x)
function y = funct1(x)
    y = x.*sin(x);
end

Si le fichier funct1.m est dans le répertoire à partir duquel Matlab a été démarré ou dans un répertoire inclus dans la liste des répertoires que Matlab lie au départ (voir le menu de Matlab), alors notre nouvelle fonction funct1 peut être utilisée comme toutes les autres fonctions de Matlab comme on le démontre dans l'exemple suivant.

Exemple: La valeur de \(x \sin(x)\) pour \(x=5\) est donnée par la commande suivante.

>> funct1(5) 

ans = 

    -4.7946

La commande help funct1 affiche les lignes (le premier groupe de lignes) qui débute par % et qui se trouvent avant la ligne function y = funct1(x) du fichier funct1.m. Un fichier m devrait toujours débuter avec des commentaires qui décrivent la fonction définie dans le fichier m, qu'est-ce que la fonction fait, et comment utiliser cette fonctions avec la liste et description de ses arguments.

>> help funct1

  y = funct1(x) 

  This function takes one argument x and returns the result of the
  computation  x sin(x)

La première ligne d'un fichier m est dans le format

function variables_dépendantes = nom_de_la_fonction(variables_indépendantes)

Le reste du fichier m définit la fonction en utilisant la même syntaxe que celle utilisée dans la fenêtre de commandes. Le point-virgule est nécessaire à la fin de chaque ligne autrement le résultat de la ligne sera affiché à chaque fois que le fichier m est exécuté. Il est fortement suggéré d'utiliser .* au lieu de *, ./ au lieu de /, etc pour créer une fonction qui est array smart.

Le nom du fichier m qui définie la fonction nom_de_la_fonction doit être nom_de_la_fonction.m. Le nom de la fonction doit satisfaire les règles suivantes:

  • Il doit débuter par une lettre (minuscule ou majuscule).
  • Il doit comprendre seulement des lettres, des nombres et le caractère de soulignement (_). Aucun autre symbole est accepté.
  • Les noms de fonctions qui existent déjà comme cos, log, sin, ... ne devraient pas être utilisé. Matlab n'affiche pas d'avertissement si de tels noms sont utilisés mais alors ces fonctions ne seront plus accessibles.

Les fichiers m peuvent être sauvegardés dans n'importe lequel des répertoires. Cependant, Matlab doit savoir où les fichiers m se trouvent. Matlab a une liste de l'emplacement des répertoires où il cherche les fichiers m. Pour vérifier si l'emplacement d'un répertoire contenant un fichier m est parmi la liste des répertoires que Matlab cherche pour les fichiers m, il suffit d'exécuter la commande path. Matlab affiche alors l'emplacement de tous les répertoires qu'il cherche. Le répertoire où un fichier m est sauvegardé peut être ajouté à la liste des répertoires cherchés par Matlab, s'il n'est pas déjà présent, à l'aide des commandes path(path, 'emplacement') ou addpath emplacement, où emplacement est l'emplacement complet du répertoire où le fichier m se trouve. Par exemple, supposons que le fichier m funct1.m se trouve dans le répertoire /home/utilisateur1/matlab, alors la commande path(path,'/home/utilisateur1/matlab') ajoute l'emplacement /home/utilisateur1/matlab à la liste des répertoires que Matlab cherche s'il n'est pas déjà inclus dans la liste.

Adresses des fonctions

Pour certaines fonctions de Matlab, le nom d'une fonction doit être donné parmi leurs arguments. Par exemple, la fonction quadl que l'on a introduite précédemment exige que le nom de la fonction qui doit être intégrée soit un des arguments. Au lieu de donner le nom de la fonction, il est souvent plus pratique de donner l'adresse de la fonction.

Pour obtenir l'adresse d'un fonction, il suffit d'ajouter le préfixe @ au nom de la fonction. Par exemple, @funct1 donne l'adresse de la fonction funct1 .

Nous pouvons maintenant donner un exemple pour les fonctions quad et quadl à l'aide de ce nouveau concept.

Exemple: Pour estimer l'aire sous la courbe \(y = x \sin(x)\) pour \(0 \leq x \leq \pi\), nous utilisons notre fonction funct1. Pour évaluer numériquement l'intégrale de \(x \sin(x)\) sur l'intervalle \(0 \leq x \leq \pi\), nous utilisons la commande suivante.

>> quadl(@funct1,0,pi)
ans = 

    3.1416

Le format minimal des fonctions quadl et quad est quadl(@Funct, a, b); où Funct est le nom de la fonction définie pour \(a \leq x \leq b\), l'intervalle d'intégration. Le résultat est une estimation de la valeur exacte avec une erreur relative d'au plus \(\displaystyle 10^{-3}\). Pour spécifier une différente borne supérieure sur l'erreur relative, il faut utiliser la commande quadl(@Funct,a,b,tol) où tol est la nouvelle borne sur l'erreur relative.

L'adresse d'une fonction peut être utilisée au lieu du nom de la fonction qu'elle représente.

Exemple: Les commandes suivantes illustrent comment l'adresse d'une fonction peut être manipulée et utilisée.

>> hand = @funct1;
>> hand(10)

ans = 

   -5.44021110889370 

>> funct1(10) 

ans = 

   -5.44021110889370 

>> hands = {hand, @sin};
>> hands{1}(10) 

ans = 

   -5.44021110889370 

>> hands{2}(10)
ans = 

   -0.54402111088937

hand contient l'adresse de la fonction funct1. Ainsi, hand(10) est identique à la commande funct1(10). La variable hands représente une liste (ordonnée) de deux adresses: l'adresse de la fonction funct1 et l'adresse de la fonction sin de Matlab qui est la fonction trigonométrique sinus. hands{1}(10) est équivalent à la commande funct1(10) et hands{2}(10) est équivalent à la commande sin(10).

Il est occasionnellement fastidieux de créer un fichier m pour définir une simple fonction qui sera utilisée seulement lors d'une session sur Matlab. L'adresse d'une fonction peut être utilisée pour éliminer le besoin de créer un fichier m.

Exemple: Nous voulons estimer la valeur de l'intégrale de \(\displaystyle f(x) = x^3 + 2 x^2 + 1\) pour \(3 \leq x \leq 5\).

Au lieu de créer un fichier m pour la fonction \(f\), nous définissons une fonction anonyme qui est seulement représentée par son adresse que nous sauvegardons dans une variable comme il est fait ci-dessous.

>>  f = @(x) x.^3 + 2* x.^2 + 1

f = 

    @(x) x .^ 3 + 2 * x .^ 2 + 1

Cette adresse peut alors être utilisée avec la fonction quadl. La commande suivante illustre comme cela est fait.

>> quadl(f,3,5) 

ans =  

     2.033333333333333e+02

Les fonctions suivantes pour manipuler les adresses de fonctions sont parfois utiles.

Commande Description
functions(adresse) Affiche la description de la fonction associée à l'adresse fournie comme argument.
func2str(adresse) Affiche le nom de la fonction associée à l'adresse fournie comme argument ou, si l'adresse est associée à une fonction anonyme, la formule qui définie la fonction.
str2func('nom_de_la_fonction') Fournie l'adresse de la fonction qui porte le nom nom_de_la_fonction.
isa(variable. 'function_handle') Retourne 1 (ou vrai) si la variable fournie comme premier argument contient une adresse et 0 (ou faux) si cette variable ne contient pas une adresse.

Équations différentielles ordinaires (EDO)

Trois des fonctions de Matlab pour résoudre les (systèmes d') EDO (non-raides) d'ordre un sont ode23, ode45 et ode113 (Octave n'a pas la fonction ode113 mais offre la fonction ode115s en remplacement). Ce sont des méthodes à pas variables dérivées des méthodes de Runge-Kutta. Ils font partis de la famille de solveurs d'EDO de Matlab. Pour obtenir de l'aide au sujet de ces solveurs et une liste des autres solveurs de Matlab pour résoudre les EDO, il suffit d'utiliser la commande help ode23 par exemple. Le nom ode23 peut être remplacé par tout autre nom de solveur d'EDO de Matlab.

Nous allons seulement expliquer la procédure pour utiliser le solveur ode45. Cependant, la procédure pour utiliser les autres solveurs d'EDO de Matlab est très semblable.

Le format de le solveur ode45 est [xx,yy] = ode45(@yprime ,[x_zero , x_final], y0, options) .

La fonction yprime (qui dépend de \(x\) et \(y\)) est le côté droit de l'EDO \(y'(x) = \text{yprime}(x,y)\). La valeur x_zero est le temps initial et la valeur x_final est le temps quand arrêter l'intégration numérique. L'expression y0 est un vecteur rangée avec les valeurs initiales de \(y\) à x_zero. Une solution est calculée pour chacune des conditions initiales.

Le vecteur xx et la matrice yy que ode45 retourne ont le même nombre de rangées. Le nombre de colonnes de la matrice yy est égale à la longueur du vecteur rangée y0. La \(\displaystyle i^{e}\) colonne de yy est l'estimé à chacune des valeurs de xx de la solution \(y\) de \(y'(x) = \text{yprime}(x,y)\) avec la condition initiale à x_zero donnée par la \(\displaystyle i^{e}\) composante de y0. La \(\displaystyle k^{e}\) rangée de yy est une approximation de la solution \(y\) de \(y'(x) = \text{yprime}(x,y)\) évaluée à la \(\displaystyle k^{e}\) composante de xx pour chacune des conditions initiales données par les composantes de y0 à x_zero.

Il y a un grand nombre d'options qui peuvent être fournies aux solveurs d'EDO de Matlab. Pour fournir une borne sur la tolérance relative, une borne sur la tolérance absolue, etc, nous devons premièrement définir une structure d'options comme celle ci-dessous.

>>  option = odeset('reltol', 0.001, 'abstol', [0.000001])

Seulement les bornes sur la tolérance relative et la tolérance absolue ont été incluses dans l'exemple précédent mais il y a beaucoup plus d'options qui peuvent être incluses selon le solveur d'EDO utilisé pour résoudre numériquement l'EDO.

Exemple: Nous voulons estimer la solution de l'EDO \(y'(x) = f(x,y) = x \sin(x)\) pur \(0 \leq x \leq \pi\) à l'aide du solveur ode45. La condition initial est \(y(0) = 0\) et la borne supérieure sur la tolérance relative est de \(\displaystyle 10^{-5}\). Nous avons déjà défini à l'aide du fichier m funct1.m une fonction \(x \mapsto x \sin(x)\). Cependant, cette fonction funct1 ne peut pas être utilisé avec le solveur ode45 car la fonction funct1 dépend seulement de \(x\). Le côté droit d'une EDO \(y'(x)= \ldots\) doit être une fonction de \(x\) et \(y\).

La fonction funct1 est redéfinie pour obtenir la nouvelle fonction funct2 définie dans le fichier funct2.m. Le fichier m contient les lignes de code suivantes:

% yprime = funct2(x,y)
%
% This function takes two arguments, x and y, and returns the
% result of the computation  x sin(x)
function yprime = funct2(x,y)
     yprime = x.*sin(x);
end

La seule option qui est fournie au solveur ode45 est la borne supérieure \(\displaystyle 10^{-5}\) pour la tolérance relative.

>> options = odeset('reltol',10^(-5));

Finalement, nous pouvons utiliser le solveur ode45 pour résoudre numériquement l'EDO \(y' = f(x,y)\) pour \(0 \leq x\leq \pi\) avec la condition initiale \(y(0) = 0\).

>> [xx,yy] = ode45('funct2',[0,pi],0,options)

Programmation

La version standard de Matlab n'a pas de fonctions pour exécuter les méthodes itératives. L'utilisateur doit donc programmer Matlab pour exécuter ces méthodes. L'exemple suivant illustre comment cela peut être fait pour la méthode du point fixe. L'approche est semblable pour d'autres méthodes itératives.

Exemple: Nous voulons utiliser la méthode du point fixe pour estimer la valeur de la solution de l'équation \(\displaystyle -(x^2/8) - x/4 + 1/2 = x\) dans l'intervalle \([0,1]\). Nous commençons les itérations avec \(x = 0.5\). Une solution possible pour ce problème est d'exécuter un petit fichier m qui contient le code suivant.

%  Starting value of x for the iteration:
x = 0.5; 

%  Number of iterations:
n = 20; 

% loop:

for i = 1:n
   x = -(x.^2/8) - x/4 + 1/2;
end  

% Return the final value of the iteration
x

Ce fichier m est nommé ,. Ce n'est pas une fonction mais un simple script que Matlab peut exécuter. Avec une plus profonde connaissance de Matlab, nous pouvons écrire des programmes beaucoup plus sophistiqués mais cet exemple est suffisant pour comprendre la base de la programmation dans Matlab.

Si nous exécutons fxpt1 dans Matlab, alors il exécute \(20\) itérations de la fonction \(\displaystyle x \mapsto -(x^2/8) - x/4 + 1/2\) à partir de \(x = 0.5\) et affiche la \(\displaystyle 20^{e}\) itération.

>> fxpt1

x = 

    0.3852

Cependant, le programme ci-dessus n'est pas pratique car nous devons modifier le fichier fxpt1.m à chaque fois que l'on change la fonction à itérer, la valeur initiale ou le nombre d'itérations.

La fonction fxpt2 définie dans le fichier accepte comme argument l'adresse de la fonction qui doit être itérée, la valeur initiale et le nombre d'itérations.

% y = fxpt2(funct,x0,n)
%
% This function returns the result of n iterations of the function
% y = funct(x) starting with the value x = x0 .
function y = fxpt2(funct,x0,n)
    y = x0
    for i=1:n
      y = feval(funct,y);
    end
end

Pour exécuter \(20\) itérations de la fonction \(\displaystyle x \mapsto -(x^2/8) - x/4 + 1/2\) à partir de \(x = 0.5\), nous définissons la fonction funct3 en créant le fichier m qui contient le code suivant.

% y = funct3(x)
%
% This function takes one argument x and return the result of the
% computation  -(x.^2/8) - x/4 + 1/2 .
function y = funct3(x)
   y = -(x.^2/8) - x/4 + 1/2;
end

La fonction fxpt2 peut être invoquée avec les arguments @funct3, 0.5 et 20.

>> fxpt2(@funct3,0.5,20) 

ans = 

    0.3852

Au lieu de définir funct3 à l'aide d'un fichier m, nous pourrions simplement définir une fonction anonyme comme il se suit. 

>> Hfunct3 = @(x) -(x.^2/8) - x/4 + 1/2;

De cette façon, il est maintenant facile de modifier la fonction qui doit être itérée .

Gestion de fichiers et Batch Mode dans Matlab

Matlab possède plusieurs commandes pour gérer les fichiers qui permet à l'utilisateur d'énumérer, de lire et de supprimer les fichiers m, de lire le contenu d'un répertoire, de changer le répertoire présentement utilisé, etc. Un résumé de certaines commandes est fourni dans le tableau ci-dessous.

Commande Description
what Affiche une liste de tous les fichiers m dans le répertoire présentement utilisé.
dir Affiche une liste de tous les fichiers dans le répertoire présentement utilisé.
type nom_do_fichier Affiche le contenu du fichier m nom_du_fichier.m.
delete nom_du_fichier Supprime le fichier m nom_du_fichier.m.
cd emplacement Remplacer le répertoire présentement utilisé par celui associé à l'emplacement donné.
cd Affiche le répertoire présentement utilisé .
which nom_de_la_fonction Affiche l'emplacement du fichier m nom_de_la_fonction.m.

Il est aussi facile d'exécuter un script de Matlab en batch mode sur un ordinateur dont le système d'opération est Linux/Unix. Par exemple, pour exécuter le script my_code.m en batch mode, il suffit d'exécuter la commande suivante après le prompt d'un terminal.

% nice +19 matlab -nosplash < my_code.m > my_code.log

La commande nice est une commande de Linux/Unix pour changer la priorité d'exécution du programme qui doit être exécuté. L'argument +19 abaisse la priorité d'exécution de telle sorte que le programme ne monopolise par l'unité de calcul de l'ordinateur. Le résultat du programme est emmagasiné dans le fichier my_code.log. L'option -nosplash annule l'affichage du message de bienvenue quand Matlab est démarré.
