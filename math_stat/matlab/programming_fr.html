Nous avons déjà introduit la programmation dans le document . Définir des fonctions est fondamental pour la programmation dans Matlab. Nous devons admettre que ce document est en voix de développement et que nous espérons ajouter plus d'information dans un avenir proche.

Fonctions itératives

La version standard de Matlab n'a pas de fonctions pour exécuter les méthodes itératives. L'utilisateur doit donc programmer Matlab pour exécuter ces méthodes. L'exemple suivant illustre comment cela peut être fait pour la méthode du point fixe. L'approche est semblable pour d'autres méthodes itératives.

Exemple: Nous voulons utiliser la méthode du point fixe pour estimer la valeur de la solution de l'équation \(\displaystyle -(x^2/8) - x/4 + 1/2 = x\) dans l'intervalle \([0,1]\). Nous commençons les itérations avec \(x = 0.5\). Une solution possible pour ce problème est d'exécuter un petit fichier m qui contient le code suivant.

%  Starting value of x for the iteration:
x = 0.5; 

%  Number of iterations:
n = 20; 

% loop:

for i = 1:n
   x = -(x.^2/8) - x/4 + 1/2;
end  

% Return the final value of the iteration
x

Ce fichier m est nommé ,. Ce n'est pas une fonction mais un simple script que Matlab peut exécuter. Avec une plus profonde connaissance de Matlab, nous pouvons écrire des programmes beaucoup plus sophistiqués mais cet exemple est suffisant pour comprendre la base de la programmation dans Matlab.

Si nous exécutons fxpt1 dans Matlab, alors il exécute \(20\) itérations de la fonction \(\displaystyle x \mapsto -(x^2/8) - x/4 + 1/2\) à partir de \(x = 0.5\) et affiche la \(\displaystyle 20^{e}\) itération.

>> fxpt1

x = 

    0.3852

Cependant, le script ci-dessus n'est pas pratique car nous devons modifier le fichier fxpt1.m à chaque fois que l'on change la fonction à itérer, la valeur initiale ou le nombre d'itérations.

Exemple (suite): La fonction fxpt2 définie dans le fichier accepte comme argument l'adresse ou le nom de la fonction qui doit être itérée, la valeur initiale et le nombre d'itérations.

% y = fxpt2(funct,x0,n)
%
% This function returns the result of n iterations of the function
% y = funct(x) starting with the value x = x0 .
function y = fxpt2(funct,x0,n)
    y = x0;
    for i=1:n
      y = feval(funct,y);
    end
end

Pour exécuter \(20\) itérations de la fonction \(\displaystyle x \mapsto -(x^2/8) - x/4 + 1/2\) à partir de \(x = 0.5\), nous définissons la fonction funct3 en créant le fichier m qui contient le code suivant.

% y = funct3(x)
%
% This function takes one argument x and return the result of the
% computation  -(x.^2/8) - x/4 + 1/2 .
function y = funct3(x)
   y = -(x.^2/8) - x/4 + 1/2;
end

La fonction fxpt2 peut être invoquée avec les arguments @funct3 ou 'funct3', 0.5 et 20.

>> fxpt2(@funct3,0.5,20) 

ans = 

    0.3852

Note: Si nous avions utilisé la ligne y = funct(y); au lieu de la ligne y = feval(funct,y); dans le script précédent. alors la fonction fxpt2 n'aurait accepté que les adresses de fonctions comme premier argument. En utilisant la fonction feval(), les noms de fonctions peuvent aussi être donnés comme premier argument de la fonction fxpt2.

Au lieu de définir funct3 à l'aide d'un fichier m, nous pourrions simplement définir une fonction anonyme comme il se suit. 

>> Hfunct3 = @(x) -(x.^2/8) - x/4 + 1/2;

De cette façon, il est maintenant facile de modifier la fonction qui doit être itérée.
