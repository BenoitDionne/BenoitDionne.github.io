Visual Representations

Content

One of the main quality of Matlab is its capability to visualize mathematical results. It could be plotting graphs of functions, representing data sets with charts, etc. The focus of this document is on the representation of function. This choice is motivated by our personal needs.

Two Dimensional Plotting in Matlab

Graph of a Function

Suppose that we want to plot the graph of a function \(f\) defined on an interval \([a,b]\).

  1. The first step is to create a list x of mesh points for the interval \([a,b]\). It is usual to take \(N + 1\) equally spaced points in the interval \([a,b]\). One way to create such a list is with the command x = a : h : b where h = (b-a)/N. Another way to create such a list is with the command x = linspace(a,b,N+1).
  2. The second step is to evaluate the function at each of the mesh points. To benefit from the matlab optimisation, the function must be an array smart function. The step can then be done with the simple command y = f(x).
  3. Finally, we use the command plot(x,y, options) to draw the graph. There are several options that can be used. We use some of them in the examples below. The reader should use the help for the function plot to get a full list of these options.

Example: We consider the function \(f\) defined by \(\displaystyle f(x) = x^3\) on the interval \([0,1]\). The following two examples show how to generate \(11\) equally spaced points (\(10\) subintervals) including the end points of the interval.

>> x = 0:0.1:1 

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 
 
     0.7000    0.8000    0.9000    1.0000

or

>> x = linspace(0,1,11)

x = 

   Columns 1 through 7 

          0    0.1000    0.2000    0.3000    0.4000    0.5000    0.6000 

   Columns 8 through 11 

     0.7000    0.8000    0.9000    1.0000

To evaluate the function \(f\) defined by \(\displaystyle f(x) = x^3\) at the \(11\) points generated above, a simple array operation can be used.

>> y = x.^3 

y = 

   Columns 1 through 7 

          0    0.0010    0.0080    0.0270    0.0640    0.1250    0.2160 

   Columns 8 through 11 

     0.3430    0.5120    0.7290    1.0000

Each component of y is the cube of the corresponding component in x. Finally, the following call to the Matlab function plot draws the graph of \(f\) over the interval \([0,1]\). The function plot use linear interpolation between the \(11\) equally spaced points to approximate the graph of the function \(f\).

>> plot(x,y)

After having pressed the Enter key, a new window pops up with a figure containing the graph of the function.

More equally spaced points will produce a more accurate graph of the function.

It is possible to include in the same figure the graphs of several functions. The command hold on after having produce the first figure tells Matlab to draw the following graphs in the existing figure. The command hold off returns Matlan to the default mode which is to replace the present figure by a new one.

Example: Using the definition of the variable x above and assuming that the previous figure exists (i.e. it has not been closed), the following commands add the straight line \(y = x + 2\) to the previous figure containing the graph of \(f\).

>> hold on
>> z = x + 2;
>> plot(x,z,'r')

The figure is now

In the previous example, the result of the Matlab expression z = x + 2 is to add the value \(2\) to each component of x and store the results in the variable z. The \(\displaystyle i^{th}\) component of z is the sum of the \(\displaystyle i^{th}\) component of x with \(2\). This is one of the unnatural behaviours of Matlab.

The option 'r' of the previous plot command tells Matlab to draw the line \(y = x + 2\) in red.

A title and axis labels can be added to the figure using the Matlab functions title to produce the title, xlabel to label the \(x\) axis and ylabel to label the \(y\) axis. The following example shows how to use these functions.

Example: Suppose that the following commands are parts of the session that produced the previous figure and that this figure is still existing (i.e. the figure has not been closed).

>> title('sample plotting with MATLAB')
>> xlabel('x-axis')
>> ylabel('y-axis')

The effect of these commands is to add the title sample plotting with MATLAB and the labels to the axes to the previous figure to get the following figure.

Drawing a Curve

Suppose that we want to draw a curve given by the parametric representation \( (x,y) = (f(t),g(t)) \) for \( a \leq t \leq b \).

  1. The first step is to create a list t of mesh points for the interval \([a,b]\). As we did for the graph of a function, it is usual to take \(N + 1\) equally spaced points in the interval \([a,b]\).
  2. The second step is to evaluate the parametric representation at each of the mesh points. As usual, we assume that the functions that define the components of the parametric representation are array smart functions. The step can then be done with commands x = f(t) and y = g(t).
  3. Finally, we use the command plot(x,y, options) to draw the curve.

Example: Suppose that we want to plot the curve with the parametric representation \( (x,y) = (\sin(t), t\cos(t)) \) for \(0 \leq t \leq 20 \).

The following Matlab commands draw this curve.

>> t = 0:0.05:20;
>> x = sin(t);
>> y = t.*cos(t);
>> plot(x,y,'b');
>> xlabel('x');
>> ylabel('y');

To mark the points on the curve with \(t\) an integer, we use the following commands.

>> hold on
>> t = 0:1:20;
>> x = sin(t);
>> y = t.*cos(t);
>> plot(x,y,'*b');

Interpolation

Polynomial interpolation can be used in Matlab.

Example: We draw the linear interpolation of the function \(f\) associated to the data in the table below.

x 0 0.7854 1.5708 2.3562 3.1416
y 0 0.5554 1.5708 1.6661 0.0000

The data for \(x\) and \(y\) are stored in two vectors in Matlab.

>> x = [ 0  0.7854  1.5708  2.3562  3.1416 ] 

x = 

         0    0.7854    1.5708    2.3562    3.1416 

>> y = [ 0  0.5554  1.5708  1.6661  0.0000 ]

y = 

         0    0.5554    1.5708    1.6661         0

It is in fact easier to draw the linear interpolation of \(f\) than to evaluate \(f\) at some points. Assuming that the previous figure has been closed (or that the command hold off has been used), the following command draws the linear interpolation of \(f\).

>> plot(x,y);

The linear interpolation of \(f\) can be evaluated at some points using the Matlab function interp1.

Example: Suppose that the points where the linear interpolation of \(f\) has to be evaluated are \(0, \pi/10 , \pi/5 , 3\pi/10, \ldots, \pi\). These points may be listed in Matlab as it follows. 

>> z = linspace(0,pi,11)

z = 

   Columns 1 through 9 

       0    0.3142    0.6283    0.9425    1.2566    1.5708    1.8850   2.1991    2.5133 

   Columns 10 through 11 

       2.8274    3.1416

The next Matlab command computes the value of the linear interpolation of \(f\) at the \(11\) equally spaced points in z.

>> w = interp1(x,y,z,'linear') 

w = 

   Columns 1 through 9 

       0    0.2222    0.4443    0.7585    1.1646    1.5708    1.6089    1.6470    1.3329 

   Columns 10 through 11 

       0.6665    0.0000

The \(\displaystyle k^{th}\) component of w is the value of the linear interpolation of the function \(f\) at the \(\displaystyle k^{th}\) component of z. The following commands plot the points with coordinates \((x,y)\) where \(x\) and \(y\) are the \(\displaystyle k^{th}\) components of z and w respectively for \(k = 1, 2, \ldots, 11\).

>> hold on
>> plot(z,w,'or');

The third argument in plot above tells Matlab to only plot a red circle at each point.

There are other methods of interpolation than linear (the default) like cubic and spline. To use these methods, it suffices to follow the steps in the previous example but substituting linear by cubic or spline. To compare these methods, the reader should try these methods with the previous example.

Three Dimensional Plotting in Matlab

Graph of a Function

The procedure to draw the graph of a real valued function of two variables is very similar to the procedure to draw a real valued function of one variable. Suppose that we want to plot the graph of a function \(f\) defined on the rectangle \([a,b]\times [c,d]\).

  1. The first step is to create mesh points. For a function of two variables, we use the command meshgrid. This function takes two lists of mesh points, a list x of mesh points for the interval \([a,b]\) and a list y of mesh points for the interval \([c,d]\), and returns two matrices. Suppose that x is a list of Nx mesh points and y is a list of Ny mesh points. Then [X,Y] = meshgrid(x,y) returns two matrices, X and Y, of dimensions Ny × Nx, where the list of mesh points x is repeated in each row of X and the list of mesh points y is repeated in each collumn of Y. Hence, the (i,j) componente of X and the (i,j) conponente of y gives the point (xj,yi) where xj is the jth mesh point of x and yi is the ith mesh point of y.
  2. The second step is to evaluate the function at each of the mesh points (xj,yi). As usual, we assume that the function function is array smart. The step can then be done with the command Z = f(X,Y). The matrix Z returned by the function is of dimension Ny × Nx where the (i,j) componente of Z is the value of f at the point (xj,yi).
  3. Finally, we use the command surf(X,Y,Z,options) to draw the graph.

Example: To plot the graph of the function \(f\) defined by \(f(x,y) = sin(x+y) x^2 y \) for \(-5 \leq x \leq 5\) and \(-3 \leq y \leq 3\), we use the following commands. 

>> [X,Y] = meshgrid(-5:0.1:5,-3:0.1:3);
>> Z = sin(X+Y).*X.^2.*Y;
>> surf(X,Y,Z); 
>> xlabel('x') , ylabel('y') , zlabel('z');

If we select the option Tools ⟹ GUI mode (on all axes) ⟹ Rotate on in the menu on the top of the window displaying the figure, we can then use the left button of our mouse to rotate the figure in the space. This is quite useful when we need to change the direction to look at the graph in order to get a better representation of the graph.

Drawing a Curve

The procedure to draw the graph of a real valued function of two variables is basically identical to the procedure to draw a real valued function of one variable. Suppose that we want to draw a curve given by the parametric representation \( (x,y,z) = (f(t),g(t),h(t)) \) for \( a \leq t \leq b \).

  1. The first step is to create a list t of mesh points for the interval \([a,b]\).
  2. The second step is to evaluate the parametric representation at each of the mesh points. As usual, we assume that the functions that define the components of the parametric representation are array smart functions. The step can then be done with commands x = f(t), y = g(t) and z = h(t).
  3. Finally, we use the command plot3(x,y,z,options) to draw the curve.

Example: Suppose that we want to plot the curve with the parametric representation \( (x,y) = (\sin(t), t\cos(t), t^2) \) for \(0 \leq t \leq 20 \).

The following Matlab commands draw this curve.

>> t = 0:0.05:20;
>> x = sin(t);
>> y = t.*cos(t);
>> z = t.^2;
>> plot3(x,y,z,'b');
>> xlabel('x');
>> ylabel('y');
>> zlabel('z');
>> grid on

More on Drawing

All types of plots that are available with Matlab are liste don the website . We are only going to present examples for some of them.

Example: To plot 10 level curves of the function \(f\) defined by \(f(x,y) = sin(x+y) x^2 y \) for \(-5 \leq x \leq 5\) and \(-3 \leq y \leq 3\), we use the following commands. 

>> [X,Y] = meshgrid(-5:0.1:5,-3:0.1:3);
>> Z = sin(X+Y).*X.^2.*Y;
>> contour(X,Y,Z,10,'ShowText','on'); 
>> xlabel('x') , ylabel('y');

We may select the level curve that we want to plot. For instance, suppose that we want the level curves qiven by \(f(x,y) = -2\) and \(f(x,y) = -6\). We can plot them with the following commands. 

>> contour(X,Y,Z,[-2,-6],'ShowText','on'); 
>> xlabel('x') , ylabel('y');

Example: To plot the curve defined by the equation in polar coordinates \( r = 1 + \cos(\theta) \), we use the following commands.

>> theta = 0:0.01:2*pi;
>> r = 1 +cos(theta);
>> polarplot(theta,rho);
