First Order ODE

In this section, we introduce some of the functions use to solve and display solutions of ordinary differential equations (ODE) of order one.

General Solutions

There are several methods to solve first-order ODE depending of their form: separable equations, homogeneous equations, linear ODE, reduction of order, ... Maple can solve almost all these type of ODE.

To find the general solution of the first-order ODE

> eq1:=diff(y(x),x)+y(x)=cos(x);
\[ eq1 := \frac{\text{d}}{\text{d}x} y(x) + y(x) = \cos(x) \]

we use the function dsolve( ) of Maple.

> dsolve(eq1,y(x));
\[ y(x) = \frac{\cos(x)}{2} + \frac{\sin(x)}{2} + e^{-x} \_C1 \]

In the solution given by Maple, _C1 is an arbitrary parameter.

The homogeneous ODE associated to eq1 above is

>  eq2 := lhs(eq1) = 0;
\[ eq2 := \frac{\text{d}}{\text{d}x} y(x) + y(x) = 0 \]

Its general solution is

> dsolve(eq2,y(x));
\[ y(x) = e^{-x} \_C1 \]

The term with _C1 in the solution of eq1 is the general solution of eq2. The rest of the solution of eq1 is a particular solution of eq1.

Examples: Here are a few more examples.

Consider the separable equation

>  eq3 := diff(y(x),x) = x^2*y(x)^2;
\[ eq3 = \frac{\text{d}}{\text{d}x} y(x) = x^2 y(x)^2 \]

Its solution is

> dsolve(eq3,y(x));
\[ y(x) = \frac{3}{-x^3 + 3\_C1} \]

Consider the homogeneous ODE of degree zero

> eq4:=(x^2+y(x)^2)*diff(y(x),x)+ x^2-y(x)^2= 0;
\[ eq4 := (x^2+y(x)^2) \frac{\text{d}}{\text{d}x} y(x) + x^2 - y(x)^2 = 0 \]

Its solution is

> dsolve(eq4,y(x));
\[ y(x) = RootOf \left(-\int^z \frac{1+\_a^2}{\_a^3 -\_a^2+\_a+1} \text{d}\_a + \ln(x) + \_C1\right) x \]

Maple seems to have some problems with this one. We will come back on it later.

Finally, we consider the linear ODE

> eq5:= diff(y(x),x) + x^2*y(x) = x^2;
\[ eq5 := \frac{\text{d}}{\text{d}x} y(x) + x^2 y(x) = x^2 \]

whose solution is

> dsolve(eq5,y(x));
\[ y(x) = 1+ e^{-\frac{x^3}{3}} \_C1 \]

Initial Value Problems

We consider the first-order linear ODE eq5 and use dsolve( ) to solve it with the initial condition y(2)=3. 

> sol1:=dsolve({eq5,y(2)=3},y(x));
\[ sol1 := y(x) = 1+ \frac{2 e^{-\frac{x^3}{3}}}{e^{-\frac{8}{3}}} \]

We can use plot( ) to draw the graph of this solution. We fist get the expression for the particular solution using rhs(sol1). 

> plot(rhs(sol1),x=1..5);

Note: If you need to evaluate the solution of an initial value problem at several points, it is advantageous to use the arrow operator to write the solution.. 

> yp:= s -> subs( x=s,rhs(sol1));  evalf(yp(1.5));
\[ \begin{split} &yp := s \mapsto subs( x=s, rhs(sol1)) \\ & \qquad 10.34474214 \end{split} \]

Numerical Solution

When we talk about a numerical solution, we obviously talk about an approximation of a real solution of the ODE.

Since a simple form for the solution of our famous homogeneous ODE of degree zero, eq4, seems to be out of reach, we will find a numerical solution to eq4 with the initial condition y(0)=2.

> yp := dsolve({eq4,y(0)=2},y(x),type=numeric);
\[ yp:=proc(x_rkf45) ... end proc \]

By default, the numerical method of integration used to solve the initial value problem is a Runge-Kutta-Fehlberg method of order 4 with error of order 5. We use the Maple function odeplot to graph this solution.

> with(plots): odeplot(yp,-4..4);

Since it is not always possible to find a simple form for the solution of an ODE, drawing the graph of the numerical solution of an initial value problem is often a good alternative. To get a qualitative view of the graphs of solutions of an ODE, one plots the slope field of the ODE.

Consider the first-order ODE $y'(x) = f(x,y(x))$. The right hand side $f(x,y(x))$ is the slope of the solution $y(x)$ at every point $(x,y(x))$; a point on the graph of the solution $y(x)$. The get the slope field of the ODE, we select many points of the plane. From each one of them, we draw an arrow of slope $f(x,y)$ centred at this points. Maple has a nice function to generate the slope field of an ODE.

Consider our troublesome homogeneous ODE of order one, eq4. Its slope field is drawn below.

> with(DEtools):  DEplot(eq4,y(x),x=-5..5,y=-5..5, arrows=small);

We can also draw on the slope field some solutions with initial conditions.

> DEplot(eq4,y(x),x=-5..5,y=-5..5, [[y(0)=1],[y(0)=-2],[y(0)=2]],linecolor=[red,blue,green], arrows=small);

It is possible to select different numerical algorithm, step size, error tolerance, ... for numerical integration and drawing slope fields.

Remark: Consider the ordinary defferential equation

>  eq3 := diff(y(x),x)+x^2*y(x)=x^2;
\[ eq3 := \frac{\text{d}}{\text{d} x} \,y(x) + x^{2}\,y(x)=x^{2} \]

We can draw its slope field and some solutions with given initial conditions.

>  DEplot(eq3,y(x),x=-10..10,y=-10..10,[[y(0)=1],[y(0)=-2],[y(0)=2]],linecolor=[red,blue,green],method=classical[foreuler],stepsize=.1);

There seems to be something wrong with the graphs of the solutions for $y(0)=-2$ and $y(0)=2$ when $x$ is greater than $8$. The solutions are not tangent to the slope field as the should be.

This is the danger with numerical integration. To get logical and more accurate results, we may have to adjust the step size or use an appropriate numerical method. It is therefore important to have a theoretical and qualitative understanding of the differential equation before diving into enormous computations. The problem here comes from the Euler method which is not a very accurate method of integration and the large step size. If we use the default method of integration (i.e. a Runge-Kutta-Fehlberg method), we get. 

>  DEplot(eq3,y(x),x=-5..5,y=-5..5,[[y(0)=1],[y(0)=-2],[y(0)=2]], linecolor=[red,blue,green]);

This is much better.
