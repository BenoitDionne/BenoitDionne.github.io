First Order ODE

This document introduces the reader to some of the functions of Maple used to solve and plot solutions of ordinary differential equations (ODE) of order one.

General Solutions

There are several methods to solve first-order ODE depending on their form: separable equations, homogeneous equations, linear ODE, etc. Maple can solve almost all these types of ODE.

To find the general solution of the following first-order ODE

> eq1:=diff(y(x),x)+y(x)=cos(x);
\[ eq1 := \frac{\text{d}}{\text{d}x} y(x) + y(x) = \cos(x) \]

it suffices to use the function dsolve() of Maple.

> dsolve(eq1,y(x));
\[ y(x) = \frac{\cos(x)}{2} + \frac{\sin(x)}{2} + e^{-x} \_C1 \]

In the solution given by Maple, the symbol _C1 is an arbitrary constant.

The homogeneous ODE associated to the ODE eq1 above is

>  eq2 := lhs(eq1) = 0;
\[ eq2 := \frac{\text{d}}{\text{d}x} y(x) + y(x) = 0 \]

Its general solution is given by the following command.

> dsolve(eq2,y(x));
\[ y(x) = e^{-x} \_C1 \]

The term with the symbol _C1 in the solution of the ODE given by eq1 is the general solution of the ODE given by eq2. The other terms of the solution of the ODE given by eq1 form a particular solution of the ODE given by eq1.

Examples: Here are a few more examples.

Consider the following separable ODE.

>  eq3 := diff(y(x),x) = x^2*y(x)^2;
\[ eq3 := \frac{\text{d}}{\text{d}x} y(x) = x^2 y(x)^2 \]

Its general solution is given by the following command.

> dsolve(eq3,y(x));
\[ y(x) = \frac{3}{-x^3 + 3\_C1} \]

Consider the following homogeneous ODE.

> eq4:=(x^2+y(x)^2)*diff(y(x),x)+ x^2-y(x)^2= 0;
\[ eq4 := (x^2+y(x)^2) \frac{\text{d}}{\text{d}x} y(x) + x^2 - y(x)^2 = 0 \]

Its general solution is given by the following command.

> dsolve(eq4,y(x));
\[ y(x) = RootOf \left(-\int^z \frac{1+\_a^2}{\_a^3 -\_a^2+\_a+1} \text{d}\_a + \ln(x) + \_C1\right) x \]

Maple seems to have some problems to solve this ODE. We will come back to it later.

Finally, we consider the linear following ODE.

> eq5:= diff(y(x),x) + x^2*y(x) = x^2;
\[ eq5 := \frac{\text{d}}{\text{d}x} y(x) + x^2 y(x) = x^2 \]

Its general solution is given by the following command.

> dsolve(eq5,y(x));
\[ y(x) = 1+ e^{-\frac{x^3}{3}} \_C1 \]

Initial Value Problems

We consider the first-order linear ODE \(\displaystyle y'(x) + x^2 y(x) = x^2\) and use the function dsolve() to solve this ODE with the initial condition \(y(2)=3\). The ODE is defined in Maple by The variable eq5 defined above contains the Maple implementation of this ODE.

> sol1:=dsolve({eq5,y(2)=3},y(x));
\[ sol1 := y(x) = 1+ \frac{2 e^{-\frac{x^3}{3}}}{e^{-\frac{8}{3}}} \]

We can use the function plot() to draw the graph of this solution. We retrieve the formula of this particular solution using the command rhs(sol1) before calling the function plot().

> plot(rhs(sol1),x=1..5);

Note: If we need to evaluate the solution of an initial value problem at several points, then it is preferable to use a procedure to write this solution. For instance, we can evaluate the solution given by sol1 at \(x = 1.5\) as it follows..

> yp:= s -> subs( x=s,rhs(sol1));  evalf(yp(1.5));
\[ \begin{split} &yp := s \mapsto subs( x=s, rhs(sol1)) \\ & \qquad 10.34474214 \end{split} \]

Numerical Solutions

When we talk about the numerical solution of an ODE, we obviously talk about an approximation of the real solution of the ODE.

Since it does not seem to be possible to find a simple form for the solution of our famous homogeneous ODE given by eq4, we seek a numerical solution to this ODE with the initial condition \(y(0)=2\).

> yp := dsolve({eq4,y(0)=2},y(x),type=numeric);
\[ yp:=proc(x\_rkf45) ... end proc \]

By default, the numerical method used to solve initial value problems is a Runge-Kutta-Fehlberg method of order 4 with error of order 5. We use the Maple function odeplot to graph the solution above.

> with(plots): odeplot(yp,-4..4);

Since it is not always possible to get a simple form for the solution of an ODE, drawing the graph of the numerical solution of an initial value problem is often a good alternative. To get a qualitative view of the graphs of solutions of an ODE, we may draw a slope field of the ODE.

Consider the first-order ODE \(y'(x) = f(x,y(x))\). The right hand side \(f(x,y(x))\) is the slope of the solution \(y\) at every point \((x,y(x))\); a point on the graph of the solution \(y\). The draw a slope field of the ODE, we select many points \((x,y)\) equally spaced of the plane and draw an arrow of slope \(f(x,y)\) from each one of them. Maple has a nice function to generate the slope fields of an ODE.

Consider our troublesome homogeneous ODE of order one given by eq4. A slope field of this ODE is drawn below.

> with(DEtools):  DEplot(eq4,y(x),x=-5..5,y=-5..5, arrows=small);

We can also draw the graphs of solutions associated to some initial conditions on top of the previous slope field some. In the figure below, we have included the graphs of the particular solutions associated to the initial conditions \(y(0)=1\), \(y(0)=-2\) and \(y(0)=2\). 

>  DEplot(eq4,y(x),x=-5..5,y=-5..5, [[y(0)=1],[y(0)=-2],[y(0)=2]],linecolor=[red,blue,green],
   arrows=small);
To write a Maple command on several lines, we must press Shift + Enter at the end of each line up to the last line where we only press Enter. Note that cutting and pasting to Maple the two-line command above works.

It is possible to select a different numerical method, step size, error tolerance, ... for the functions dsolve() and DEplot().

Example: Consider the ODE defined as it follows in Maple.

>  eq5 := diff(y(x),x)+x^2*y(x)=x^2;
\[ eq5 := \frac{\text{d}}{\text{d} x} \,y(x) + x^{2}\,y(x)=x^{2} \]

We have already solved this ODE in a previous example. We can draw a slope field of this ODE including the graphs of the particular solutions associated to the initial conditions \(y(0)=1\), \(y(0)=-2\) and \(y(0)=2\). We use the simple Euler method with a step size of \(0.1\).

>  DEplot(eq5,y(x),x=-10..10,y=-10..10,[[y(0)=1],[y(0)=-2],[y(0)=2]],linecolor=[red,blue,green],
   method=classical[foreuler],stepsize=.1);

There seems to be something wrong with the graphs of the particular solutions associates to the initial conditions \(y(0)=-2\) and \(y(0)=2\) when \(x\) is greater than \(8\). The graphs of the solutions are not tangent to the slope field as they should be.

This example illustrates the danger of using numerical integration. To get realistic and more accurate results, it is often necessary to adjust the step size or select a more appropriate numerical method. It is therefore important to have a theoretical and qualitative understanding of the ODE before diving into enormous computations. The problem here comes from the Euler method which is not a very accurate method of integration and the large step size. If we use the default method of integration (i.e. a Runge-Kutta-Fehlberg method) used by DEplot(), then we get the following result instead. 

>  DEplot(eq5,y(x),x=-5..5,y=-5..5,[[y(0)=1],[y(0)=-2],[y(0)=2]], linecolor=[red,blue,green]);

This is much better.
