Partial Differential Equations

Other Topics

The reader should not expect a full introduction to Partial Differential Equations (PDE) in this document. We only consider some standard PDE that students learn about in a first PDE course.

Heat Flow in a thin Rod - Insulated Ends

The heat equation for a thin rod of length \(L\) is

\[ \frac{\partial}{\partial t} u(x,t) = k^2 \frac{\partial^2}{\partial x^2} u(x,t) \]

with the initial condition \(u(x,0) = f(x)\) and the boundary conditions \(u_x(0,t) = u_x(L,t) = 0\). The ends of the rod are insulated. The value \(u(x,t)\) is the temperature at the position \(x\) of the rod at time \(t\). The constant \(\displaystyle k^2\) is the heat conductivity of the rod. For the heat equation to hold, we must also assume that the lateral side of the rod is insulated.

The classical method to solve this PDE involves separation of variables. Suppose that the solution of the heat equation is of the form \(u(x,t) = X(x) T(t)\). If we substitute this expression in the heat equation, then we get

\[ X(x) T'(t) = k^2 X''(x) T(t) \]

If divide both sides by \(X(x)T(t)\), then we get

\[ \frac{T'(t)}{T(t)} = k^2 \frac{X''(x)}{X(x)} \]

The left hand side is a function of \(t\) alone and the right hand side is a function of \(x\) alone. For both sides to be equal, they must be equal to a constant that we call \(\lambda\).

\[ \frac{T'(t)}{T(t)} = k^2 \frac{X''(x)}{X(x)} = \lambda \]

We get two ODE. The equation \(T' = \lambda T\) is a separable first order ODE and it is easy to solve. Its general solution is \(\displaystyle T(t) = D e^{\lambda t}\) for an arbitrary constant \(D\). The second ODE is \(\displaystyle X'' - (\lambda/k^2) X = 0\). This is a second order ODE with constant coefficients and it is also easy to solve.

Suppose that \(\lambda < 0\). The general solution of \(\displaystyle X'' - (\lambda/k^2) X = 0\) is

\[ X(t) = C_1 \cos(\sqrt{-\lambda} x/k) + C_2 \sin(\sqrt{-\lambda} x/k) \]

Since \(u_x(0,t) = X'(0) T(t) = 0\) for all \(t\), we must have \(X'(0)=0\) otherwise \(T(t)=0\) for all \(t\) and we end up with the trivial solution \(u)x,t) = X(x) T(t) = 0\) for all \(x\) and \(t\). This is certainly not true if \(f\) is nontrivial. Similarly, we get that \(X'(L) = 0\).

The condition \(X'(0)=0\) implies that \(C_2 \sqrt{\lambda} = 0\). So \(C_2 = 0\). We then get from \( X'(L)=0\) that \(C_1 \sqrt{-\lambda}\sin(\sqrt{-\lambda} L/k) = 0\). We cannot have \(C_1 = 0\) because we are looking for a nontrivial solution. So \(\sqrt{-\lambda}\, L/k) = n \pi\) for \(n\) a non-negative integer. Hence

\[ \lambda = - \frac{n^2 \pi^2 k^2}{L^2} \quad , \quad n = 0, 1 ,2 ,3, \ldots \]

We finally get

\[ X_n(x) = C_n \cos\left(\frac{n\pi x}{L}\right) \quad , \quad n = 0, 1 ,2 ,3, \ldots \]

The reader can verify that the cases \(\lambda=0\) and \(\lambda>0\) lead to the trivial solution.

If we substitute the value of \(\lambda\) in the function \(T\) above, we get

\[ T_n(t) = D_n e^{-n^2\pi^2 k^2 t/L^2} \]

All the functions of the form \(T_n(t) X_n(x)\) are solutions of the PDE and satisfy the boundary equations. There are infinitely many of them, one for each value of the non-negative integer \(n\).

We now look for a solution of the heat equation that is a sum of all functions \(X_n(x) T_n(t)\).

\[ u(x,t)= \sum_{n=0}^\infty X_n(x) T_n(t) = a_0 + \sum_{n=1}^\infty a_n \cos\left(\frac{n\pi x}{L}\right) e^{-n^2\pi^2 k^2 t/L^2} \]

where \(a_n = C_n D_n\).

We still have to determine the values of the \(a_n\). It is here that we finally use the initial condition \(u(x,0) = f(x)\). If we evaluate the series for \(u\) at \(t=0\), then we get that

\[ f(x) = a_0 + \sum_{n=1}^\infty a_n \cos\left(\frac{n\pi x}{L}\right) \]

This is the Fourier cosine series for \(f\). The coefficients are given by

\[ a_0 = \frac{1}{L} \int_0^L f(x) \text{d}x \qquad , \qquad a_n = \frac{2}{L} \int_0^L f(x) \cos(n\pi xx/L) \text{d}x \]

Example: Consider the heat equation defined in Maple by the following command.

> HE := diff(u(x,t),t) = k^2*diff(u(x,t),x$2);
\[ HE := \frac{\partial}{\partial t} u(x,t) = k^2 \frac{\partial^2}{\partial x^2} u(x,t) \]

The PDE is defined on the interval \([0,L]\), the boundary conditions are given by

> bconds := (D[1](u))(L, t) = 0, (D[1](u))(0, t) = 0;
\[ bconds := D_1(u)(L, t) = 0,\quad D_1(u)(0, t) = 0 \]

and the initial condition are given by

> icond := u(x, 0) = f(x);
\[ icond := u(x, 0) = f(x) \]

We assume that

> L := 3; k := sqrt(1.14);
\[ \begin{split} &L := 3 \\ &k := 1.067707825 \end{split} \]

We left the initial condition unspecified to clearly demonstrate that Maple use separation of variables as we did above.

>  pdsolve([HE, bconds, icond], u(x, t));
\[ u(x,t) = \frac{ \left(\int_1^3 f(x) \text{d}x \right)}{3} + \left( \sum_{n=1}^\infty \frac{ 2\left(\int_0^3 f(x) \cos\left(\frac{n \pi x}{3} \right)\text{d}x\right) \cos\left(\frac{n \pi x}{3}\right) e^{-\frac{19 n^2 \pi^2 t}{150}}}{3} \right) \]

We get the predicted solution. Given a function f, We could use the Maple function int() to compute the coefficients. However, there is a simpler way to get the coefficients. The function pdsolve() can also accept an initial condition. Suppose that the initial condition is given by the following command.

>  icond := u(x, 0) = x^2*(L-x)^2;
\[ icond := u(x, 0) = x^2 (L-x)^2 \]

Then

>  Sol := pdsolve([HE, bconds, icond], u(x, t));
\[ Sol := u(x,t) = \frac{27}{10} + \left( \sum_{n=1}^\infty \frac{1944(1+(-1)^n) \cos\left(\frac{n \pi x}{3} \right) e^{-\frac{19 n^2 \pi^2 t}{150}}}{n^4 \pi^4} \right) \]

The reader really has to have done these computations by hand to appreciate the work done by Maple.

The 3-D graph of this solution is given below.

>  U := (y, s) -> subs({t = s, x = y}, rhs(Sol));
\[ U:= (y,s) \mapsto subs({t = s, x = y}, rhs(Sol)) \] 
>  plot3d(U(x,t),x=0..L,t=0..1,axes=FRAME,style=PATCH, labels=['x','t','u'],
   orientation=[-130,45]);

The temperature in the rod settle rapidly to a uniform temperature of \(2.7\) degrees.

Heat Flow in a Rod - Other Cases

The reader who has already taken an introductory course on PDE knows that there are several other cases to consider for the heat equation according to the chosen boundary conditions. We do not plan to do a systematic studies of all the cases. We will only give another example where, this time, the end of the rod are kept at a constant temperature.

Example: Consider the heat equation defined in Maple by the following command.

> HE := diff(u(x,t),t) = k^2*diff(u(x,t),x$2);
\[ HE := \frac{\partial}{\partial t} u(x,t) = k^2 \frac{\partial^2}{\partial x^2} u(x,t) \]

The PDE is defined on the interval \([0,L]\), the boundary conditions are given by

> bconds := u(L, t) = 0, u(0, t) = 0;
\[ bconds := u(L, t) = 0,\quad u(0, t) = 0 \]

and the initial condition is given by

> icond := u(x, 0) = f(x);
\[ icond := u(x, 0) = f(x) \]

We assume, as in the previous example, that

> L := 3; k := sqrt(1.14);
\[ \begin{split} &L := 3 \\ &k := 1.067707825 \end{split} \]

The solution is given by the following command.

>  pdsolve([HE, bconds, icond], u(x, t));
\[ u(x,t) = \sum_{n=1}^\infty \frac{ 2\left(\int_0^3 f(x) \sin\left(\frac{n \pi x}{3} \right)\text{d}x\right) \sin\left(\frac{n \pi x}{3}\right) e^{-\frac{19 n^2 \pi^2 t}{150}}}{3} \]

This is the expected form of the solution if separation of variables is used. In this case, the initial condition is given by a Fourier sine series. If we specify the function f, then we can solve the heat equation with the function pdsolve. Suppose that the initial condition is given by the following command.

>  icond := u(x, 0) = x^2*(L-x)^2;
\[ icond := u(x, 0) = x^2 (L-x)^2 \]

Then

>  Sol := pdsolve([HE, bconds, icond], u(x, t));
\[ Sol := u(x,t) = \sum_{n=1}^\infty \frac{ 324\left((-1)^n \pi^2 n^2 - \pi^2 n^2 + 12(-1)^{1+n} + 12\right) \sin\left(\frac{n \pi x}{3}\right) e^{-\frac{19 n^2 \pi^2 t}{150}}}{n^4 \pi^4} \]

The 3-D graph of this solution is given below.

>  U := (y, s) -> subs({t = s, x = y}, rhs(Sol));
\[ U:= (y,s) \mapsto subs({t = s, x = y}, rhs(Sol)) \] 
>  plot3d(U(x,t),x=0..L,t=0..1,axes=FRAME,style=PATCH, labels=['x','t','u'],
   orientation=[-130,45]);

Eventually, the rod will reach a uniform temperature of \(0\) degree.

Vibrating String - Fixed Ends

The wave equation for the vibrating string of length \(L\) with both ends fixed is

\[ \frac{\text{d}^2}{\text{d} t^2} v(x,t) = c^2 \frac{\text{d}}{\text{d}t} v(x,t) \]

for \(0 \leq x \leq L\), with the boundary conditions \(v(0,t) = v(L,t) = 0\) and the initial conditions \(v(x,0) = f(x)\) and \(v_t(x,0) = g(x)\); the initial position and velocity respectively.

If we use the method of separation of variables to solve this problem, then we get

\[ v(x,t) = \sum_{n=1}^\infty \left( a_n \sin(n c \pi t/L) + b_n \sin(n c \pi t/L)\right)\sin( n \pi x /L) \]

where

\[ a_n = \frac{2}{L} \int_0^L f(x) \sin\left(\frac{n \pi x}{L}\right) \text{d} x \]

and

\[ b_n = \frac{2}{n \pi c} \int_0^L g(x) \sin\left(\frac{n\pi x}{L}\right) \text{d} x \] Example: We consider the wave equation defined by the following command.

> WE:=diff(v(x,t),t$2) = c^2*diff(v(x,t),x$2);
\[ WE := \frac{\text{d}^2}{\text{d} t^2} v(x,t) = c^2 \frac{\text{d}}{\text{d}t} v(x,t) \]

The PDE is defined on the interval \([0,L]\), the boundary conditions are given by 

> bconds := v(L, t) = 0, v(0, t) = 0;
\[ bconds := v(L, t) = 0,\quad v(0, t) = 0 \]

and the initial conditions are given by

> iconds := v(x, 0) = f(x), D[2](v)(x,0) = g(x);
\[ iconds := v(x, 0) = f(x), D_2(v)(x,0) = g(x) \]

We assume that

> L := 3; c := 1.1;
\[ \begin{split} &L := 3 \\ &c := 1.1 \end{split} \]

The solution of the wave equation is given by the following command.

>  pdsolve([WE, bconds, iconds], v(x, t));
\[ \begin{split} v(x,t) &= \sum_{n=1}^\infty \frac{1}{3 n \pi} \bigg( 2\sin\left(\frac{n \pi x}{3}\right) \bigg( \left(\int_0^3 \sin\left(\frac{n\pi x}{3}\right) f(x) \text{d}x \right) \cos\left(\frac{11 \pi t n}{30}\right) n \pi \\ & +\frac{30 \left( \int_0^3 \sin\left(\frac{n \pi x}{3}\right) g(x)\text{d}x\right) \sin\left(\frac{11 \pi t n}{30}\right)}{11}\bigg)\bigg) \end{split} \]

This is the form of the solution expected if separation of variables is used. If we specify the functions f and g, then we can solve the wave equation with the function pdsolve. Suppose that the initial condition is given by the following command.

If we simply release the string, then the initial conditions look somewhat like the following conditions.

>  iconds := v(x, 0) = x*(L-x)^3, D[2](v)(x,0) = 0;
\[ iconds := v(x, 0) = x (L-x)^3, D_2v(x,0) = 0; \]

Then

>  Sol := pdsolve([WE, bconds, iconds], v(x, t));
\[ Sol := v(x,t) = \sum_{n=1}^\infty \frac{ 972\left(n^2 \pi^2 -4 + 4 (-1)^n\right) \sin\left(\frac{n \pi x}{3}\right) \cos\left(\frac{11 \pi t n}{30}\right) } {n^5 \pi^5} \]

We may want to plot the 3-D graph of this solution using the function plot3d() as we did previously. However, for a reason still unknown to the author, Maple cannot do it. It is therefore the right time to introduce the numerical approach to solve PDE.

Numerical Solutions

To be honest, we should warn the reader that Maple does not have the best library to numerically solve PDE. However, it is good enough to solve the classical PDE seen in an introductory course on PDE.

> nSol := pdsolve(WE, {bconds, iconds}, numeric, spacestep = 1/30);
\[ nSol:=module() ... end\ module \]

The result of pdsolve() with the option numeric is an object that we have not introduced before. The result is a module. The reader should consult the information about the function pdsolve() in the help section of Maple for more details. This module contains many functions. We will use some of them below.

We could plot the 3-D graph of the solution but it is more instructive to draw the solution as a function of \(x\) for equally spaced fixed values of \(t\). This will represent snapshots of the form of the string evolving in time. If we do it every \(2\) seconds, then we get the following figure.

> plots[display](seq([nSol:-plot(t = 2*j, x = 0 .. 3)], j = 0 .. 10));

We can almost visualize the motion of the string in time. Maple can produce an event better visualization of the motion of the string. We can produce a movie of the string as it vibrates.

>  nSol:-animate(v(x, t), x = 0 .. 3, t = 0 .. 9, frames = 50, title = "time = %f",
   labels = ["x", "u"]);

To run this code in Maple, it suffices to select Animation -> Play to start the animation.

More

There is a lot more that we could say about PDE. First, as for the heat equation above, there are many cases to consider for the wave equation depending on the boundary conditions. Also, we have not mentioned at all the Laplace Equation. All the PDE that we have considered were depending on a single space variable on the real line. However, we could also consider the heat, wave and Laplace equations of several spacial variables on different domains: rectangles, disks, spheres, ... All of problems lead to very interesting results.

We leave the task of pursuing the study of PDE to the reader.
