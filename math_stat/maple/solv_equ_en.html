Solving Equations

Other Topics

In this document, we show how to use Maple to solve (systems of) nonlinear equations.

Roots of Polynomials

We start by finding the roots of the following polynomial.

> pe := x^3-x^2+5*x-6=0; spe := solve(pe,x);
\[ \begin{split} & pe := x^3 - x^2 + 5 x - 6 = 0 \\ & spe := \ldots \end{split} \]

We did not display the exact solutions given by Maple in the variable spe because it occupies several lines. The reader should run the commands above to get the long output.

The floating point representation (to \(10\) decimal places) of these roots is given by the following command.

> fspe:=evalf(spe);
\[ 1.157720809,-0.0788604043 + 2.275165423\,I,-0.0788604043 - 2.275165423\,I \]

To extract the values from this list, we may used the following commands. 

> x1 := fspe[1]; x2 := fspe[2]; x3 := fspe[3];
\[ \begin{split} & x1 := 1.157720809 \\ & x2 := -0.0788604043 + 2.275165423\,I \\ & x3 := -0.0788604043 - 2.275165423\,I \end{split} \]

Since we ended up looking for numerical approximations of the roots of the polynomial, we could have used the Maple function fsolve(). However, since there are complex roots, we must use the option complex to get approximations for all the roots.

> fsolve(pe,x,complex);
\[ -0.07886040443 - 2.275165422\,I, -0.07886040443 + 2.275165422\,I, 1.157720809 \]

Note: The package RootFinding is an advanced package to find the roots of complex valued analytic functions defined on \(\mathbb{C}\). It can be used if ever the function fsolve() cannot find all the complex roots. The function Analytic() of this package can be used to find all the roots of an analytic function. One of the arguments of this function is a rectangular region of the complex plane where to look for a root. The region is defined by the coordinates of two diagonally opposed corners of the rectangle. For instance, to find the complex root with a positive imaginary part of the polynomial above, we execute the following commands.

> with(RootFinding): Analytic(pe, x, -0.5 - 0*I .. 0 + 3*I);
\[ -0.0788604044301870 + 2.27516542234209\,I \]

Example: The goal is to find the points of intersection of the graphs of the following two functions.

> f1:=1/(x^2-8); f2:=x^2+4*x+2;
\[ \begin{split} & f1 := \frac{1}{x^2-8} \\ & f2 := x^2+4x+2 \end{split} \]

We first find the values of \(x\) where the graphs intersect.

> xs := evalf(solve(f1=f2,x));
\[ xs := 2.836678210, -.6331032006, -2.707918475, -3.495656534 \]

There are four real roots (see the figure below). We could instead have looked for the roots of the polynomial of degree four f2(x) / f1(x) - 1 = 0.

> plot1:=plot(f1(x),x=-4..4,-4..25,discont=true,color=red):
> plot2:=plot(f2(x),x=-4..4,-4..25,color=blue):
> with(plots):
> display({plot1,plot2});

We have used the option discont=true to produce the graph of the function defined by f1 because it is a discontinuous function. In fact, there are values of \(x\) where the function is not defined and has vertical asymptotes.

To determine the coordinates of the points of intersection, we compute the values of f2 (we could as well have chosen f1) at each of the values of the list xs.

> f2f := x -> x^2+4*x+2:
> ys := seq(f2f(xs[i]), i=1..4);
\[ ys := 21.39345611, -.131593139, -1.498851433, .23698846 \]

We get the following four intersection points.

> seq([xs[i], ys[i]], i = 1 .. 4);
\[ \begin{split} & [2.836678210, 21.39345611], [-0.6331032006, -0.131593139], \\ & \qquad \qquad [-2.707918475, -1.498851433], [-3.495656534, 0.23698846] \end{split} \]

We have used the Maple function seq() to generate the list of values above.

Systems of Nonlinear Equations

Example: We want to find the solutions of the following system of two nonlinear equations.

> eq1 := 2*x^2-x*y+y^2 = 1; eq2 := x^2+y^2=1;
\[ \begin{split} & eq1 := 2x^2-xy+y^2 = 1 \\ & eq2 := x^2+y^2 = 1 \end{split} \]

We plot these two curves in the plan to locate approximately their points of intersection. We assume that \(-3 \leq x , y \leq 3\).

> with(plots):
> imp1 := implicitplot(eq1,x=-3..3,y=-3..3,grid=[40,40],color=red):
> imp2 := implicitplot(eq2,x=-3..3,y=-3..3,grid=[40,40],color=blue):
> display({imp1,imp2});

There seems to be four points of intersection (i.e. the solutions of our system of linear equations). We first ask Maple to find them. 

> fsolve({eq1,eq2},{x,y});
\[ \{y = -1.000000000, x = 0.\} \]

Three of the solutions are missing. Using the fonction solve() does not give more information. The reader should try it. The function fsolve() uses an iterative method to find the solutions. To find the other solutions, we need to provide a small area where the function fsolve() will look for a solution.

> fsolve({eq1,eq2},{x,y},{x=0.6..0.8,y=0.6..0.8});
\[ \{x = .7071067812, y = .7071067812 \} \]

We get another solution. The other two solutions can be found using the same procedure or simply by using the fact that both equations are invariant with respect to the reflection through the origin (i.e. \((x,y) \mapsto (-x,-y)\) ). So the other solutions are just \(-1\) times the two solutions that we have found above.
