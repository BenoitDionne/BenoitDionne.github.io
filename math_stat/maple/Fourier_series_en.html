Fourier Series

Introduction

We do not plan to be overly rigorous in this section on Fourier series. For a rigorous introduction, the reader should consult one of the excellent textbooks in analysis.

The Fourier series of \(f [-L,L] \to \mathbb{R}\) is the series

\[ a_0 + \sum_1^\infty ( a_n \cos(n\pi x/L) + b_n \sin(n\pi x/L) ) \]

where

\[ a_0 = \frac{1}{2L} \int_{-L}^L f(x) \text{d}x \quad , \quad a_n = \frac{1}{L} \int_{-L}^L f(x) \cos(n\pi x/L) \text{d}x \]

and

\[ b_n = \frac{1}{L} \int_{-L}^L f(x) \sin(n\pi x/L) \text{d}x \]

If \(f\) is piecewise continuous on \([-L,L]\), we have that

\[ \frac{f(x^+) + f(x^-)}{2} = a_0 + \sum_1^\infty ( a_n \cos(n\pi x/L) + b_n \sin(n\pi x/L) ) \]

for all \(x \in [-L,L]\). In particular, if \(f\) is continuous at \(x\), then the series converges pointwise to \(f(x)\).

If \(f :\mathbb{R} \to \mathbb{R}\) is periodic of period \(2L\), the integrals above can be computed on any interval of the form \([a-L,a+L]\).

If \(f\) is an even function (i.e. \(f(-x) = f(x)\) for all \(x\)), then \(b_n = 0\) for all \(n\) and the Fourier series becomes the Fourier cosine series

\[ a_0 + \sum_1^\infty a_n \cos(n\pi x/L) \]

where

\[ a_0 = \frac{1}{L} \int_0^L f(x) \text{d}x \quad , \quad a_n = \frac{2}{L} \int_0^L f(x) \cos(n\pi x/L)\text{d}x \]

Note: We can always extend a function \(f:[0,L] \to \mathbb{R}\) to an even function defined on \([-L.L]\) by \(f(x) = f(-x)\) for \(x \in [-L,0]\).

If \(f\) is an odd function (i.e. \(f(-x) = -f(x)\) for all \(x\)), then \(a_n = 0\) for all \(n\), and the Fourier series becomes the Fourier sine series

\[ \sum_1^\infty b_n \sin(n\pi x/L) \]

where

\[ b_n = \frac{2}{L} \int_0^L f(x)\sin(n \pi x/L) \text{d} x \]

Note: We can always extend a function \(f:]0,L] \to \mathbb{R}\) to an odd function defined on \([-L.L]\) by \(f(x) = -f(-x)\) for \(x \in [-L,0[\) and \(f(0)=0\).

Computations of Fourier Series

Example 1: There exists some package in Maple to compute Fourier series. We present them below.

Consider the following piecewise continuous function

> fe := proc(x) local y: if type(x,numeric) then y:=abs(x)-floor(abs(x)/2)*2: if ( y < 1/2 or y > 3/2 ) then RETURN(1); else RETURN(0); fi; else 'fe'(x); fi; end proc;
\[ \begin{split} & fe := proc (x)\\ & \qquad local\ y: \\ & \qquad if\ type(x, numeric)\ then \\ & \qquad \qquad y := abs(x)-2*floor((1/2)*abs(x))\\ & \qquad \qquad if\ y < 1/2\ or\ 3/2 < y\ then\ RETURN(1)\ else\ RETURN(0)\ end\ if \\ & \qquad else \\ & \qquad \qquad ('fe')(x) \\ & \qquad end\ if \\ & end\ proc \end{split} \]

Another way to define fe is with the function piecewise. 

> fe := x -> piecewise( abs(x)-floor(abs(x)/2)*2 <= 1/2 or   abs(x)-floor(abs(x)/2)*2 > 3/2,1,0);
\[ fe := x \mapsto \begin{cases} 1 & \qquad |x| -2 \lfloor \frac{|x|}{2} \rfloor \leq \frac{1}{2} \text{ or } \frac{3}{2} < |x| -2 \lfloor \frac{|x|}{2} \rfloor \\ 0 & \qquad \qquad \text{otherwise} \end{cases} \]

The graph of this function is

> plot(fe(x), x = -4 .. 5, thickness = 3, discont = true, gridlines = true, view = [-4 .. 5, -.2 .. 1.2]);

From the graph of fe, we see that it is periodic of period \(2\) (so \(L=1\)) and it is an even function. We will approximate this function with a Fourier cosine series. Since we will need to integrate only on the interval \([0,1]\), we do not need the complete definition of fe, we can only consider 

> fe0L := x->piecewise(x<=1/2,1,0);
\[ fe := x \mapsto \begin{cases} 1 & \qquad x \leq \frac{1}{2} \\ 0 & \qquad \text{otherwise} \end{cases} \]

which is equal to fe on \([0,L]\). It is not necessary to consider fe0L but, if you have many computation to do, it is always nice to have the simplest form possible to do the job.

The coefficients of the Fourier cosine series are given by

> an:=proc(n) if (n=0) then RETURN( int(fe0L(x),x=0..1) ); else RETURN( 2*int(fe0L(x)*cos(n*Pi*x),x=0..1)); fi; end proc;
\[ \begin{split} & an := proc (n) \\ & \qquad if\ n = 0\ then \\ & \qquad \qquad RETURN(int(fe0L(x), x = 0 .. 1)) \\ & \quad else \\ & \qquad \qquad RETURN(2*(int(fe0L(x)*cos(n*Pi*x), x = 0 .. 1))) \\ & \qquad end\ if \\ & end\ proc; \end{split} \]

We compute and store the first \(11\) coefficients that we will use later.

> AN:= seq( evalf(an(i)),i=0..10);
\[ AN := .5000000000, .6366197722, 0., -.2122065907, 0., .1273239544, 0., -0.9094568174e-1, 0., 0.7073553024e-1, 0. \]

Note that the sequence AN starts a one. This will have an effect on the formula for the Fourier series. The Fourier cosine series (truncated after \(n+1\) terms) is 

> FCS:=(x,n)->sum(AN[j+1]*cos(j*Pi*x),j=0..n);
\[ FCS := (x, n) \mapsto \sum_{j=0}^{n} AN_{j+1} \cos(j\pi x) \]

We now draw, on the same figure, the graphs of fe( ) and the Fourier cosine series with \(n = 5\); the first six terms of the series.

> plot1:=plot(fe(x),x=-4..4,color=blue):
> plot2:=plot(FCS(x,5),x=-4..4,color=red):
> plots[display]({plot1,plot2},labels=[`x`,`y`]);

Note: We observe the Gibb's phenomena. No matter how many terms you keep in the Fourier series, near a point of discontinuity of the function, the difference between the function and the truncated Fourier series never decreases below a fixed value.

> plot3:=plot('FCS(x,10)',x=-4..4,color=red):
> plots[display]({plot1,plot3},labels=[`x`,`y`]);

Note: The value of the Fourier cosine series at a point where fe is discontinuous is about (fe(x-)+fe(x+))/2 as expected.

Example 2: We now consider the function

> ff := proc(x) local y: if type(x,numeric) then y:=x - floor(x/3)*3; if   ( y<3/2 ) then RETURN(3 - 2*y); else RETURN(0); fi; else 'ff'(x); fi; end proc;
\[ \begin{split} & ff := proc (x) \\ &\qquad local\ y;\\ &\qquad if\ type(x, numeric)\ then\\ &\qquad \qquad y := x-3*floor((1/3)*x); if\ y < 3/2\ then\ RETURN(3-2*y)\ else\ RETURN(0)\ end\ if\\ & else\\ & \qquad\qquad ('ff')(x)\\ & end\ if\\ & end proc \end{split} \]

The graph of this function is

> plot('ff(x)', x = -4 .. 5, thickness = 3, discont = true, gridlines = true, view = [-4 .. 5, -.2 .. 3.2]);

From the graph, we see that ff is a periodic function of period \(3\) but it is neither an odd nor an even function. We will use the full Fourier series to approximate ff.

As we did in the previous example, we could define a relatively simpler function ff0L which is equal to ff on the interval of integration \([-1.5,1.5]\). However, since ff(x) = 0 for \(x\in [-1.5,0]\), the integrals need to be computed on the interval \([0, 1.5]\) only. So, we may simply consider ff0L defined by

> ff0L := 3-2*x:

The Fourier coefficients are given by:

> an:=proc(n) if (n=0) then RETURN((1/3)*int(ff0L,x=0..1.5)); else RETURN((2/3)*int((ff0L)*cos(2*n*Pi*x/3) ,x=0..1.5)); fi; end proc;
\[ \begin{split} & an := proc(n)\\ &\qquad if\ n = 0\ then \\ &\qquad \qquad RETURN(1/3*int(ff0L, x = 0 .. 1.5))\\ &\qquad else \\ &\qquad \qquad RETURN(2/3*int(ff0L*cos(2/3*n*Pi*x), x = 0 .. 1.5)) \\ &\qquad end\ if\\ & end\ proc \end{split} \] 
> bn:=proc(n) RETURN((2/3)*int((ff0L)*sin(2*n*Pi*x/3), x=0..1.5)); end proc;
\[ bn := proc(n)\ RETURN(2/3*(int(ff0L*sin(2/3*n*Pi*x), x = 0 .. 1.5)))\ end\ proc \]

We compute and store the first \(21\) coefficients that we will use later.

> AN:=seq(evalf( an(i) ),i=0..10):
> BN:=seq(bn(i),i=1..10):

The Fourier series of ff (truncated after \(2n+1\) terms) is given by

> FS:=(x,n)-> sum(AN[j+1]*cos(2*j*Pi*x/3),j=0..n) + sum(BN[j]*sin(2*j*Pi*x/3),j=1..n);
\[ FS := (x, n) \mapsto \sum_{j=0}^n AN_{j+1} \cos\left(\frac{2j \pi x}{3}\right) )+ \sum_{j=1}^n BN_j \sin\left(\frac{2j\pi x}{3}\right) \]

We now draw, on the same figure, the graphs of ff and its Fourier series with \(n =10\).

> plot1:=plot(ff(x),x=-4..4,color=blue):
> plot2:=plot('FS(x,10)',x=-4..4,color=red):
> plots[display]({plot1,plot2},labels=[`x`,`y`]);
