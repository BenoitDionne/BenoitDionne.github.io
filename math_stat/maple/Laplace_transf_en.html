Laplace Transforms

We provide a very short introduction to the Laplace transform on Maple. In particular, how to use it to solve linear ODE with constant coefficients. We do not plan to give a rigorous presentation.

The Laplace Transform

The Laplace transform of a function \(f(t)\) is defined by

\[ F(s) = \mathcal{L}( f(t) ) = \int_0^\infty f(t) e^{-s t} \text{d} t \]

for the values of \(s\) where the integral converges. Maple can compute Laplace transforms for us. We need to load the library of integral transforms inttrans.

> with(inttrans):

The Laplace transform of \(f(t) = e^{-3 t}\sin(5 t)\) is compute as follows.

> ft := exp(-3*t)*sin(5*t); Fs:=laplace(ft,t,s);
\[ \begin{split} & ft := e^{-3t} \sin(5t) \\ & Fs := \frac{5}{(s+3)^2 + 25} \end{split} \]

The inverse Laplace transform of a function \(F(s)\) is a function \(f(t)\) such that \(\mathcal{L}( f(t) ) = F(s)\). We write \(\mathcal{L}^{-1}( F(s) ) = f(t)\). There is an integral formula to compute the inverse Laplace transform but we can live without it in this introduction.

The inverse Laplace transform of \(H(s) = \frac{1}{s^2-4}\) is computed as follows.

> Hs := 1/(s^2-4); ht:=invlaplace(Hs,s,t);
\[ \begin{split} &Hs := \frac{1}{s^2-4} \\ &ht := \frac{\text{sinh}(2 t)}{2} \end{split} \]

The Heaviside Function is define by

\[ H(t) = \begin{cases} 1 & \text{ if } t > 0 \\ 0 & \text{ if } t < 0 \end{cases} \]

It is the function Heaviside() in Maple. The Laplace transform of this function is 

> laplace(Heaviside(t),t,s);
\[ \frac{1}{s} \]

It is usual to shift the Heaviside Function such that the jump is at a value other than the origin.

> H4t := t->Heaviside(t-4); H4s := laplace(H4t(t),t,s);
\[ \begin{split} & H4t := t \mapsto Heaviside(t - 4) \\ & H4s := \frac{e^{-4s}}{s} \end{split} \]

The Heaviside function has some interesting properties. For instance, \(\mathcal{L}( H(t-a) f(t-a) ) = e^{-a s} F(s)\) where \(F(s) = \mathcal{L}( f(t) )\).

The Dirac Delta Function is defined by \(\delta(t) = 0\) for \(t \neq 0\) and \(\displaystyle \int_{-a}^a f(t) \delta(t) \text{d}t = f(0)\) for all functions \(f\) and all \(a > 0\). The Dirac Delta Function is not a function as one learns in a course on measure theory. It is denoted Dirac( ) in Maple.

> laplace(Dirac(t),t,s);
\[ 1 \]

Solving ODE with Laplace Transforms

Suppose that you want to solve the ODE

\[ y''(t) + 4 y(t) = \cos(2t) \]

with the initial conditions \(y(0)=2\) and \(y'(0)=3\). The idea is really simple. We apply the Laplace Transform on both sides of the ODE to transform it into an algebraic equation in \(Y(s) = \mathcal{L} ( y(t) )\). We solve this algebraic equation to find \(Y(s)\). Finally, we use the inverse Laplace transform to transform \(Y(s)\) into the solution \(y(t)\) that we are looking for. The following commutative diagram summaize the procedure used to solve ODE with Laplace transforms.

The ODE is transformed into an algebraic equation (no more derivatives) because the Laplace Transform eliminates the derivatives. In fact, \(\mathcal{L}( y'(t) ) = s Y(s)- y(0)\), \(\mathcal{L}( y''(t) ) = s^2 Y(s) - s y(0) -y'(0)\) and in general

\[ \mathcal{L}( y^{n}(t) ) = s^n Y(s) - s^{(n-1)} y(0) -s^{(n-2)} y'(0)- \ldots - y^{(n-1)}(0) \]

These formulae can be proved with integration by parts.

Example: Consider the ODE

> eq1 := diff(y(t),t$2) + 4*y(t)=cos(2*t);
\[ eq1 := \frac{\text{d}^2}{\text{d}t^2} y(t) + 4 y(t) = \cos(2t) \]

If we follow the procedure to solve ODE with Laplace transform, we have

> eq2 := laplace(eq1,t,s); Ys:=solve(eq2,laplace(y(t),t,s)); yt := invlaplace(Ys,s,t); yt := subs({y(0)=2,D(y)(0)=3},yt);
\[ \begin{split} & eq2 := s^2\,laplace(y(t),t,s) -D(y)(0) - s y(0) +4\,laplace(y(t),t,s) = \frac{s}{s^2 + 4} \\ & Ys := \frac{ y(0) s^3+ 4 s y(0) + D(y)(0) s^2 + 4 D(y)(0)+s}{ (s^2 + 4)^2} \\ & yt := y(0) cos(2 t) \frac{sin(2t) )t + 2*D(y)(0)}{4}\\ & yt := 2 cos(2 t) \frac{sin(2t) )t + 6}{4} \end{split} \]

All the work to solve the initial value problem in the previous example can be done with one Maple command.

> dsolve({eq1,y(0)=2,D(y)(0)=3},y(t),method=laplace);
\[ yt = 2 cos(2 t) \frac{sin(2t) )t + 6}{4} \]

Applications

Laplace transforms are often introduced when studying electrical circuit. Consider the following RLC circuit.

where \(R\) is the resistance (in ohms) of a resistor, \(L\) is the inductance (in henys) of an inductor, and \(C\) is the capacitance (in farads) of a capacitor. \(v_s(t)\) is the strength of the voltage source (in volts). According to Kirchoff's voltage law \(v_s + Ri = v_C + v_L\), where \(v_C\) is the voltage at the capacitor, \(v_L\) is the voltage at the inductor, and \(i\) is the current. The RLC circuit is governed by the ODE

>  eq3 := L*C*diff(v(t),t$2) + R*C*diff(v(t),t) + v(t)=VS(t);
\[ eq3 := L C \left( \frac{\text{d}^2}{\text{d}t^2} v(t)\right) + R C \left( \frac{\text{d}}{\text{d}t} v(t)\right) + v(t) = VS(t) \]

where \(v(t)\) is the voltage in the circuit at time \(t\) and \(VS = v_s\).

Suppose that R=2 ohms, C=0.15 farads, L=2 henys and VS(t) = Dirac(t).

> eq4 := subs({R=2, C=0.15, L=2, VS(t)=Dirac(t)},eq3);
\[ eq4 := 0.30 \frac{\text{d}^2}{\text{d}t^2} v(t) + 0.30 \frac{\text{d}}{\text{d}t} v(t) + v(t) = Dirac(t) \]

If the initial conditions are v(0)=1 and D(v)(0)=0, we have:
