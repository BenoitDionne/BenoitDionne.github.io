Introduction to Maple

This is a brief introduction to Maple. I hope that there is enough details to get you started with Maple in no time. There is a vast library of functions that you may want to explore. Use the Help menu in Maple for that. In the text below, Maple code is highlighted text in blue.

Basic Algebraic Operations

Consider the traditional basic polynomial:

> (x+y)^2;
\[(x + y)^2\]

The symbol % holds the result of the previous operation. So, you can use it to retrieve the result of the previous operation.

> expand(%);
\[ x^2 + 2 x y + y^2\]

We have used the command expand to compute the square. We can do any basic algebraic polynomial operations.

> %-4*x*y;
\[x^2 - 2 x y + y^2\] 
> factor(%);
\[ (x-y)^2\]

As expected, the command factor factorize the polynomial.

If we want to refer to the basic polynomial $(x+y)^2$, we do no have to rewrite it each time. We can assign $(x+y)^2$ to a variable.

> u:= (x+y)^2;
\[u := (x + y)^2\]

We can now do any basic polynomial operations with u.

> expand(u*x);
\[x^3 + 2 x^2 y + x y^2\]

Functions

There are basically two ways to define a function. Each way has its own advantages and disadvantages according to the use that you may want to make of the function. Consider the function $f(x) = \sin(x^2+1)$. The first way to define a function is as follows:

> f := sin(x^2+1);
\[ f := \sin(x^2 + 1)\]

To evaluate $f$ at $x=4$, we have to proceed as follows:

  > x:=4;
\[x := 4\] 
> f; evalf(f);
\[ \begin{split} & \sin(17)\\ &-.9613974919 \end{split} \]

We have used the function evalf to get the numerical approximation of $\sin(17)$. Don't forget that Maple always work in radians. To evaluate $f$ for other values of $x$, one has to repeat the previous two operations with the new value of $x$.

Another possibility is to use the Maple function subs.

> x:='x': f := sin(x^2+1);
\[f := \sin(x^2 + 1) \] 
> subs(x=4,f); subs(x=6,f);
\[ \begin{split} & \sin(17) \\ & \sin(37) \end{split} \]

We have used x := 'x'; to clear the value $4$ of $x$ left by the previous operations. If we had not done that, we will have had f := sin(4^2+1);, a constant value.

Using := to define explicitly a function is the right way to define a function if we want to add algebraic functions, compute derivative, ..., but this is not really the best way if we want to evaluate this functions at many points. Moreover, not all functions are given by algebraic, trigonometric, ... functions. The second way to define a function is to use a procedure. The simplest form of procedure is as follows:

> f:= x->sin(x^2+1);
\[f := x \mapsto \sin(x^2 + 1)\]

We can now easily evaluate $f$ at $x=4$ and $x=6$.

> f(4); evalf(f(4)) ; f(6); evalf(f(6));
\[ \begin{split} & \sin(17) \\ &-.9613974919 \\ & \sin(37)\\ &-.6435381334 \end{split} \]

Derivatives and integrals

Consider the function 
> f:=x/(y*x^2+1);
\[ f := \frac{x}{y x^2 + 1} \]

The first derivative of $f$ with respect to $x$ is diff(f,x). The second derivative of $f$ with respect to $x$ is diff(f,x$2), and so on for higher order derivatives. We can also compute the mixed derivatives. The mixed derivative of $f$ with respect to $x$ and $y$ of order two is diff(f,x,y). The reader has probably gotten the idea on how to compute derivatives.

The indefinite integral of $f$ is int(f,x). The definite integral of $f$ between $0$ and $4$ with $y = 4$ is 

>  y := 4; int(f, x = 0 .. 4); evalf(%);
\[ \begin{split} & y := 4 \\ & \frac{\ln(5)}{8} + \frac{\ln(13)}{8} \\ & 0.5217984086 & \end{split} \]

Graphs of Functions

Two Dimensional Plots

The graph of the function $x\sin(x)$ for $x$ between $0$ and $2\pi$ is given by 

> plot(x*sin(x),x=0..2*Pi, gridlines=true);

Sometime it is useful to plot the graph of two functions in the same figure. Suppose that we want to plot the graphs of $x \mapsto x\sin(x)$ and $x \mapsto x\cos(x)$ for $x$ between $-2\pi$ and $2\pi$ in the same figure. We first plot the graph of $x \mapsto x\sin(x)$ in red and store this graph. We end the Maple command with a colon instead of a semicolon to cancel the display of the result. We plot the graph of $x \mapsto x\cos(x)$ in blue and also store the result. Finally, we combine both plots on the same coordinate system using the function display() of the library plots.

> plot1:=plot(x*sin(x),x=-2*Pi..2*Pi,color=red):
> plot2:=plot(x*cos(x),x=-2*Pi..2*Pi,color=blue):
> plots[display]({plot1,plot2});

We could have used the command

>  plot([x*sin(x), x*cos(x)], x = -2*Pi .. 2*Pi, color = [red, blue]);

to obtain the same result. The advantage of the previous approach is the greater flexibility to mix graphs of different styles.

For the next example, suppose that we want to plot the points $(x,x^2)$ for $x=1,2,\ldots,20$. To do that, we have to provide a matrix or a list of points to the plot command. If we provide a matrix, the first column should be the $x$ coordinates of the points and the second column the corresponding $y$ coordinates. We select the option style = point to get the graph of the points only. By default, Maple draws a straight line from one point to the next one; this is the standard procedure used by Maple to plot the graph of a function.

>  a := seq(x, x = 1 .. 20): 
>  b := seq(x^2, x = 1 .. 20): 
>  plot(<<a>|<b>>, style = point, symbol = circle, gridlines=true);

We have also used the option symbol = circle to represent each point by a cycle. We could have used other symbols like box, cross, solidcircle, ...

Instead of a matrix, we may have used a list of points like in the following command.

>  plot([seq([x, x^2], x = 1 .. 20)], style = point, symbol = circle, gridlines=true);

Three Dimensional Plots

To plot the graph of the function $f(x,y) = x\sin(x)\sin(y)$ for $x$ and $y$ between $0$ and $4\pi$, we use the function plot3d().

> plot3d(x*cos(x)*sin(y),x=0..4*Pi,y=0..4*Pi,axes=FRAME,labels= [`x`,`y`,`z`],title = `x*cos(x)*sin(y)`);

Note the options that we have used. There are many more option. Please, consult the help menu of Maple to find all the information about the options available.

Two other methods to visualize a function of two variables is the contour and density plots. The Maple functions that we need are densityplot() and contourplot() in the library plots. 

> plots[densityplot](x*cos(x)*sin(y),x=0..4*Pi,y=0..4*Pi);

> plots[contourplot](x*cos(x)*sin(y),x=0..4*Pi,y=0..4*Pi,contours=15);

To end this section, we show that functions defined with a procedure can also be plotted. We illustrate this with the function $f(x,y) = \sin(x+y)+\cos(x+y)$.

> f:=(x,y)->sin(x+y)+cos(x+y):
> plot3d(f(x,y),x=0..2*Pi,y=0..2*Pi,axes=FRAME,labels=[`x`,`y`,`z`],title = `f(x,y)`,orientation=[20,45]);
