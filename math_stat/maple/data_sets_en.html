Manipulating Data Sets

In this section, we briefly explain how to manipulate date sets; in particular if you have a large among of data in a file that you would like to analyze.

Reading and Writing Files

The basic two functions are readdata() and writedata().

Suppose that we have a file data1.txt that contains the following lines. 

  1 2 3 4
  5 6 7 8
  10 20 30 40
  0.1 0.2 0.3 0.4

To read the file data1.txt, we use the function readdata(). The second argument 4 is the number of elements per row to be read. It doesn't have to match the number of elements per row in the file. You can read fewer element per row that there are per row in the file. By default, the data are assumed to be floating point numbers (float).

> A:=readdata(`data1.txt`,4);
\[ A := [[1., 2., 3., 4.], [5., 6., 7., 8.], [10., 20., 30., 40.], [.1, .2, .3, .4]] \]

A is not a matrix (or an array). It is a list. But A can be converted into a matrix.

  > B:=convert(A,'Matrix');
\[ \begin{bmatrix}1. & 2. & 3. & 4. \\ 5. & 6. & 7. & 8. \\ 10. & 20. & 30. & 40. \\ .1 & .2 & .3 & .4 \end{bmatrix} \]

If you read the file data1.txt, assuming that the data are integers, we get

  > C:=readdata(`data1`,integer,4); E := convert(C, 'Matrix')
\[ \begin{split} & C := [[1, 2, 3, 4], [5, 6, 7, 8], [10, 20, 30, 40], [0]] \\ & E := \begin{bmatrix} 1 & 2 & 3 & 4 \\ 5 & 6 & 7 & 8 \\ 10 & 20 & 30 & 40 \\ 0 & 0 & 0 & 0\end{bmatrix} \end{split} \]

As you can see, Maple did not read the non integer number (Maple did not even transform them to 0.)

Consider the array

  > A := array([ [1,-1,1],[2,-2,3], [-3,-2,-1],[0,0,1]]);
\[ A := \begin{pmatrix} 1 & -1 & 1 \\ 2 & -2 & 3 \\ -3 & -2 & -1 \\ 0 & 0 & 1 \end{pmatrix} \]

To store the array A into the file data2.txt, one use the function writedata(). 

> writedata("data2.txt",A,float);

Note: the Maple objects Matrix and Vector cannot be used with writedate(). But, you can use array, list, ...

Plotting Data

Example: The data file data3.txt contains the following two rows:

  600 800 1000 1500 2000 4000 6000 8000 10000 20000 30000 40000
  2 6 10 12 14 20 30 40 50 55 57 60

The first row has different fluid viscosity and the second row is the reduction in percent of the pumping speed associated to the viscosity of the first row. We first read these data from the file data3.txt.

> pData:=readdata(`data3.txt`,12);
\[ \begin{split} & pData := [[600., 800., 1000., 1500., 2000., 4000., 6000., 8000., 10000., 20000., \\ &\qquad \qquad 30000., 40000.], [2., 6., 10., 12., 14., 20., 30., 40., 50., 55., 57., 60.]] \end{split} \]

We use the Maple function plot() to plot the reduction in percent of the pumping speed as a function of the viscosity. To do so, we need to create a list of points of the form $[[x_1,y_1],[x_2,y_2],...]$ that we will give as arguments to plot().

> plist:=[seq([pData[1][i],pData[2][i]],i=1..12)];
\[ \begin{split} & plist := [[600., 2.], [800., 6.], [1000., 10.], [1500., 12.], [2000., 14.], [4000., 20.], \\ & \qquad \qquad [6000., 30.], [8000., 40.], [10000., 50.], [20000., 55.], [30000., 57.], [40000., 60.]] \end{split} \] 
> plot( plist, style=POINT, symbol=circle,labels=['viscosity','reduction']);

We may use a spline to approximate the function of the reduction in percent of pumping speed in terms of the viscosity. To use the Maple function spline(), we need to transform the list pData into a Matrix with the viscosity in the first column and the associated reduction in percent of pumping speed in the second column.

> with(LinearAlgebra):
> ptData := Transpose( convert(pData,'Matrix') );
\[ ptData := \begin{bmatrix} 12 x 2 Matrix \\ Data Type: anything \\ Storage: rectangular\\ Order: Fortran\_order \end{bmatrix} \]

When the matrix is too big to be displayed (according to Maple), you get only a description of the matrix. We know that it is a $12 \times 2$ matrix.

We define the spline that interpolate through all the data points that we have and plot it.

> pSpline:= x-> spline(Column(ptData,1), Column(ptData,2), x, cubic):
> plot(pSpline(x),x=600..40000);

I am guessing that a spline interpolation is not the right tool to fit through the data because the graph is not strictly increasing as expected.

Example: The components of a $n\times n$ matrix $A$ can be interpreted as the values of a function defined on the set $\{ (i,j) : 1 \leq i, j \leq n \}$; namely, $(i,j) \mapsto A(i,j)$. Consider the matrix defined in the data file data1.txt. 

> A:=readdata(`data1,txt`,4);
\[ A := [[1., 2., 3., 4.], [5., 6., 7., 8.], [10., 20., 30., 40.], [.1, .2, .3, .4]] \]

We define the list of points

\[ [ [ [1,1,A(1,1)],...[1,4,A(1,4)] ] , [ [2,1,A(2,1)],...[2,4,A(2,4)] ], ..., [ [4,1,A(4,1)],...[4,4,A(4,4)] ] ] \]

that we will feed to the Maple function surfdata() in the library plots.

> Alist:=[seq( [seq([i,j,A[i][j]],j=1..4)] , i=1..4)];
\[ \begin{split} & Alist := [[[1, 1, 1.], [1, 2, 2.], [1, 3, 3.], [1, 4, 4.]], [[2, 1, 5.], [2, 2, 6.], [2, 3, 7.],\\ & [2, 4, 8.]], [[3, 1, 10.], [3, 2, 20.], [3, 3, 30.], [3, 4, 40.]], [[4, 1, .1], [4, 2, .2], \\ & [4, 3, .3], [4, 4, .4]]] \end{split} \] 
> with(plots):
> surfdata(Alist, axes=frame, labels=[x,y,z]);
